Methodology

Ring assignment by latency from the cursor — milliseconds (Ring 0) to minutes (Ring 7). Maturity scored 0–5 by triangulation of three signals: tools installed, tools actively used, and recent incidents attributable to ring failure.

Linked artefacts

Failure modes in this atlas link to lesson docs in memory/ and .planning/. Notable: split-brain deploy, Phase 84 dual-surface, Phase 81 type cascade.

Maintenance

Edit RINGS[] and GAPS[] in the script block — all visual derivation flows from there. Review quarterly or when any ring's maturity shifts by ±0.5.
