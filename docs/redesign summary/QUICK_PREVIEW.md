## ⚡ Animations You'll Experience

### 1. **Page Load Cascade** (Staggered Fade-In)
```
Time: 0ms     ▓▓▓▓ Header appears
      100ms   ▓▓▓▓ Progress indicators pop in
      200ms   ▓▓▓▓ Template banner fades in
      300ms   ▓▓▓▓ Products section slides in
      400ms   ▓▓▓▓ Customer section slides in
      500ms   ▓▓▓▓ Delivery section slides in
      600ms   ▓▓▓▓ Dates section slides in
      700ms   ▓▓▓▓ Summary panel appears

Total duration: 700ms (smooth, not rushed)
```

### 2. **Adding a Product** (Scale + Slide)
```
CLICK!
  ↓
[Product Button Press]
  ↓
  ⏱ 50ms: Button scales down (0.95)
  ⏱ 100ms: Button springs back (1.0)
  ⏱ 150ms: New line item card appears
          - Opacity: 0 → 1
          - X position: -20px → 0
          - Scale: 0.95 → 1.0
  ⏱ 300ms: Card settles with spring physics

Result: Smooth, natural, satisfying ✨
```

### 3. **Template Expand/Collapse**
```
COLLAPSED:
┌──────────────────────────────────────┐
│ ✨ Quick Start...              [+]  │
└──────────────────────────────────────┘

CLICK!
  ↓
  ⏱ Icon rotates 180° (300ms)
  ⏱ Content height: 0 → auto
  ⏱ Spring physics makes it bouncy

EXPANDED:
┌──────────────────────────────────────┐
│ ✨ Quick Start...              [×]  │

│                                      │
```

## 🚀 What to Test First

### Quick Test Checklist
```
1. Open the form
   → See smooth cascade animation
   → Check progress indicators appear

2. Click template banner
   → Should expand/collapse smoothly
   → Icon rotates 180°

3. Add a product
   → Line item card slides in
   → Quantity controls work
   → Price updates in summary (right side)

4. Hover over line item
   → Shadow increases
   → Delete icon fades in
   → Border changes to terracotta

5. Search for customer
   → Dropdown appears with suggestions
   → Can create new customer

6. Toggle delivery
   → Address field appears smoothly
   → Switch back hides it

7. Submit without complete info
   → Validation warnings appear
   → Button stays disabled

8. Complete all fields
   → Warnings disappear
   → Button enables with gradient
```
