## 3. Findings (fixed inline)

### P1 (Critical) — `finalize:396` type-break under optional `orderId`
`finalize` does `const order = await ctx.db.get(invoice.orderId)`. Once `orderId` is `Id | undefined`, this fails type-check. The generic "fix guards as needed" was too weak. **Fixed:** Task A1 Step 6 now names `mutations.ts:396` and supplies the exact guard (`invoice.orderId ? await ctx.db.get(invoice.orderId) : null`), with a grep to confirm no other deref.

### P2 (Improvement) — `weeklyQty` re-keyed instead of derived
Spec I2 says `weeklyQty` is derived from `scheduleTemplate`. The first draft accepted it as an explicit `createSubscription` arg (drift risk: caller could pass a `weeklyQty` inconsistent with the template). **Fixed:** removed the arg; `weeklyQty` is computed in-handler from `scheduleTemplate`.
