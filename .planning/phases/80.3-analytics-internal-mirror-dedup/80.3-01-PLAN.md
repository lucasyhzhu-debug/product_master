### Wave 2: Tests [PARALLEL, after Wave 1]

**Mandatory test-file preamble (applies to all Wave-2 tasks):**

1. **Boilerplate source:** mirror `convex/externalData/__tests__/revenue-invariants.test.ts` (lines 15-56) for `convexTest(schema)` setup, `TestT` type, and `t.run(async (ctx) => ctx.db.insert(...))` seeding pattern.
2. **File-level `@fileoverview`:** document purpose + link to debug session + original staff-review spec. Template in RESEARCH Refinement section.
3. **Deterministic timestamps:** `const NOW = 1713400000000` (no `Date.now()`) per Phase 73 lesson.
4. **Two seed helpers at top of file (REQUIRED — do not skip, these are prerequisites for the assertions below):**
   - `seedMinimalBomProduct(t, { ballType: "BIG_BALL" | "MID_BALL" })` — inserts `componentTypes` (category=`production`, code=ballType), `menuProducts`, and `menuProductComponents` with `quantity=1`. Returns the new `menuProductId`. Without this helper, `unitsForOrderItem` returns 0 for every seeded item and units-based assertions false-fail.
   - `seedDirectOrderWithMirror(t, { menuProductId, overrides? })` — **direct-DB seed, NOT via `syncInternalOrders` action**. Inserts (a) native `orders` row with `status="Complete"` (or any `REVENUE_COUNTABLE_STATUSES` value), (b) `orderItems` row linked to `menuProductId`, (c) mirror `externalRevenue` with `source="internal"`, `externalTransactionId` = order number, matching `revenueGross`/`revenueNet`, (d) mirror `externalRevenueItems` with `source="internal"` and `linkedMenuProductId`. This is decoupled from `syncInternalOrders`' upstream action deps so 80.2's changes to `externalData/mutations.ts` don't break 80.3 tests.
5. **Gobiz seed helper** (used by Test 12b only): `seedGobizRevenue(t, { menuProductId })` — direct insert into `externalRevenue[source="gobiz"]` + child `externalRevenueItems[source="gobiz", linkedMenuProductId]`. No `orders` rows — gobiz has no native twin.
