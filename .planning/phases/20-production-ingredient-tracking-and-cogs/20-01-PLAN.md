Add two new tables to convex/schema.ts after the existing componentTypes table:

1. **productionComponentLinks** -- Links production components to sub-components (hierarchical BOM):
   ```
   parentComponentId: v.id("componentTypes")    // Parent production component
   childComponentId: v.id("componentTypes")     // Child sub-component
   quantityPerUnit: v.number()                  // Qty of child per 1 unit of parent
   unit: v.string()                             // Unit (g, ml, pcs)
   sortOrder: v.number()
   ```
   Indexes: `by_parent` on [parentComponentId], `by_child` on [childComponentId]

2. **productionComponentIngredients** -- Links production components to direct ingredients:
   ```
   componentTypeId: v.id("componentTypes")      // Parent production component
   ingredientId: v.id("ingredients")            // Direct ingredient
   quantityPerUnit: v.number()                  // Qty per 1 unit of parent
   unit: v.string()                             // Unit (g, ml, pcs)
   sortOrder: v.number()
   ingredientName: v.optional(v.string())       // SNAPSHOT from ingredients.name
   cachedLineCost: v.optional(v.number())        // CACHE: ingredientCost * quantityPerUnit
   ```
   Indexes: `by_component` on [componentTypeId], `by_ingredient` on [ingredientId]

3. **Extend componentTypes** with new optional fields (add after existing fields, before indexes):
   ```
   batchSize: v.optional(v.number())            // e.g., 100g for marshmallow, 45g for Mid Ball
   batchSizeUnit: v.optional(v.string())        // "g", "ml", "pcs"
   cogsMode: v.optional(v.union(v.literal("manual"), v.literal("calculated")))

   cogsCacheUpdatedAt: v.optional(v.number())   // When cache was last updated

   ```

Place the new tables in a clearly commented section: `// Production Component Recipes (Hierarchical BOM)`

<task type="auto">
  <name>Task 2: Hierarchy traversal utility with circular reference detection</name>
  <files>convex/lib/hierarchyTraversal.ts</files>
  <action>
Create `convex/lib/hierarchyTraversal.ts` with three exported functions:

1. **wouldCreateCycle(ctx, parentId, childId, maxDepth=3)** -- Returns boolean. Checks if adding childId as sub-component of parentId would create a cycle. Algorithm: if parentId === childId return true. Then DFS from childId's descendants checking if parentId appears. Use `productionComponentLinks.by_parent` index to walk children.

2. **traverseHierarchy(ctx, componentTypeId, quantityMultiplier, visited, maxDepth)** -- Returns `IngredientUsage[]`. Recursive function that:
   - Checks maxDepth (throw if <= 0 with "Maximum nesting depth (3) exceeded")
   - Checks visited set (throw if circular with "Circular reference detected: {id}")
   - Fetches direct ingredients from productionComponentIngredients.by_component
   - For each ingredient: calculate totalQuantity = quantityPerUnit * quantityMultiplier, get cost from ingredients table costPerBaseUnit, use `calculateLineCost` from costCalculator.ts
   - Fetches sub-components from productionComponentLinks.by_parent
   - For each sub-component: calculate childUnits using batchSize conversion (if child has batchSize > 0: childUnits = (quantityPerUnit * quantityMultiplier) / batchSize, otherwise just quantityPerUnit * quantityMultiplier)
   - Recurse with new Set(visited) to avoid cross-branch false positives
   - Return aggregated IngredientUsage[]

3. **collectLeafIngredients(ctx, componentTypeId)** -- Convenience wrapper that calls traverseHierarchy with quantityMultiplier=1, empty visited set, maxDepth=3. Returns IngredientUsage[].

Types to define:
```typescript
interface IngredientUsage {
  ingredientId: Id<"ingredients">;
  ingredientName: string;
  totalQuantity: number;
  unit: string;
  unitCost: number;    // costPerBaseUnit from ingredients table
  lineCost: number;    // calculated via calculateLineCost
}
```

Import types from `../_generated/dataModel` and `../_generated/server`. Import `calculateLineCost` from `./costCalculator`. Use `QueryCtx | MutationCtx` for ctx parameter type (import from `../_generated/server`).
  </action>
