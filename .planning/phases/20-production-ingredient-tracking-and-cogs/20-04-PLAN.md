**useProductionRecipes.ts** -- Create hooks wrapping the new backend:
- `useProductionRecipe(componentTypeId)` -- calls `useQuery(api.productionRecipes.getRecipeForComponent, { componentTypeId })` (skip if no componentTypeId)
- `useProductionCogs(componentTypeId)` -- calls `useQuery(api.productionRecipes.calculateCogs, { componentTypeId })` (skip if no componentTypeId)
- `useProductionComponentsWithTiers()` -- calls `useQuery(api.productionRecipes.getComponentsWithTiers)`
- Mutation hooks: `useAddSubComponent()`, `useRemoveSubComponent()`, `useAddIngredient()`, `useRemoveIngredient()`, `useUpdateIngredientQuantity()`, `useUpdateSubComponentQuantity()`
- Export all hooks from the file. Do NOT register in `src/hooks/convex/index.ts` yet -- that happens in Plan 06.

**RecipeEditorModal.tsx** -- Main modal component:
- Props: `componentType: ComponentType | null, open: boolean, onClose: () => void`
- Uses shadcn Dialog (DialogContent with max-w-2xl, max-h-[85vh] with overflow-y-auto)
- Header: Component name + code badge + batchSize display
- Body: Two stacked sections (SubComponentSection + IngredientSection), both always visible even when empty
- Footer: COGSPreview component showing live cost calculation
- No stock display anywhere in the modal (per user decision)
- Uses useProductionRecipe(componentType._id) to load recipe data
- Show loading skeleton while recipe data loads

**SubComponentSection.tsx** -- Sub-component management:
- Shows list of linked sub-components with: name, quantity, unit, line cost
- "Add Sub-component" button opens a dropdown/combobox showing all production componentTypes (excluding self and any that would create circular references)
- Include "Create new" option at bottom of dropdown (opens inline form: name, batchSize, batchSizeUnit -- creates component then adds link)
- Each row has quantity input + unit display + remove button
- Quantity is per single parent component (not per batch) -- label clearly as "per 1 {parentName}"
- Respect original unit of the sub-component

**IngredientSection.tsx** -- Direct ingredient management:
- Shows list of direct ingredients with: name, quantity, unit, line cost
- "Add Ingredient" button opens dropdown/combobox showing all ingredients from ingredients table
- Include "Create new" option at bottom of dropdown (opens inline form matching packaging BOM pattern: name, brand, unitType, volumePurchased, price, shipping)
- Each row has quantity input + unit selector + remove button
- Quantity per single parent component -- label "per 1 {parentName}"
- Respect ingredient's original unit (baseUnit)

**COGSPreview.tsx** -- Live COGS display:
- Uses useProductionCogs(componentTypeId) for real-time calculation
- Shows: "Calculated COGS: Rp {amount}" with formatCurrency
- If cogsMissingCount > 0: amber warning "COGS incomplete -- {N} ingredients missing cost data"
- If component has cogsMode="manual": show "Manual COGS: Rp {manualUnitCostIdr}" with note "(switch to Calculated to use recipe costs)"
- If no ingredients and no sub-components: show "COGS: not set (add ingredients to calculate)"

All components use: shadcn/ui primitives (Dialog, Button, Input, Badge, Select), Lucide icons (Plus, Trash2, AlertTriangle), Sonner toast for success/error, formatCurrency from utils.
