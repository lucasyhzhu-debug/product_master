       The approach: Replace the current `<Route index element={<RoleBasedRedirect />} />` logic. Two options:

       **Option A (preferred):** Keep `RoleBasedRedirect` but for manager/admin, redirect to a `/home` route where HubPage is rendered inside Layout. Then:

       - Change the index route to: `<Route index element={<RoleBasedLanding />} />`

       **Best approach:** Use the existing pattern. Add HubPage as a standard route inside `<Route element={<Layout />}>`:
       ```
       <Route path="home" element={
         <ProtectedRoute requiredPermission="canAccessDashboard">
           <HubPage />
         </ProtectedRoute>
       } />
       ```
       Then update `RoleBasedRedirect`:
       - kitchen → `/kitchen`
       - order_staff → `/orders`
       - manager/admin → `/home`

       This keeps the index route (`/`) as the redirect dispatcher, and `/home` as the actual hub page route with proper Layout wrapping.
