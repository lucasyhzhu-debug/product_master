## Decisions Made
- **Current stock via getStockOverview**: Used the existing `getStockOverview` query inline in FGAdjustStockDialog rather than adding a stockByLocation prop from parent ProductStockCard. This avoids prop-drilling complexity and the query was already confirmed to return `{menuProduct, location, quantity}` shape.
- **productNameMap pre-load in fulfillFromInventory**: Built the name map in step 3 (alongside shortage checks) rather than calling `ctx.db.get` again in step 4 deduction loop. Avoids redundant DB reads since step 3 already fetches every menuProduct.
- **Category toggle edit-only**: The Production/Packaging toggle is shown only when `editingComponent` is truthy. New components created via this manager are always production (business rule: packaging components are created via PackagingComponentsManager).
- **category arg via spread**: The componentTypes update handler destructures `{ id, cogsMode, ...updates }` and then patches with `updates`. Adding category to args means it's automatically included in the patch when present — no explicit handler change needed.
