**convex/invoices/queries.ts:**
- `getByOrder` -- protectedQuery, `roles: ["admin", "manager"]`, args: `{ orderId: v.id("orders") }`. Query invoices with `.withIndex("by_order", q => q.eq("orderId", args.orderId))`. **convex/invoices/mutations.ts:**

Define an allowlist constant at the top of the file for invoiceable statuses:
```typescript
/** Order statuses that allow invoice creation. Allowlist (not blocklist) to prevent
 *  silently allowing future status additions. */
const INVOICEABLE_STATUSES = new Set([
  "PaymentReceived",
  "BeingPrepared",
  "AwaitingDelivery",
  "Complete",
] as const);
```

- `createDraft` -- protectedMutation, `roles: ["admin", "manager"]`, args: `{ orderId: v.id("orders") }`. Handler:
  1. Read the order document. Throw ConvexError if not found.
  2. Check order status is in INVOICEABLE_STATUSES (allowlist). Throw ConvexError if invalid: `"Cannot create invoice for order with status '${order.status}'. Order must be PaymentReceived or later."`.
  3. Check no existing draft for this order: query invoices.by_order, filter status="draft". If exists, throw ConvexError "Draft invoice already exists for this order".
  4. Read customer by order.customerId. Throw ConvexError if not found.
  5. Read businessSettings singleton (`.first()`).
  6. Read bank account: if settings?.defaultBankAccountId is set, read the bank account document. **Guard against missing bank account**: if no settings exist OR settings has no defaultBankAccountId OR the bank account document is not found, throw ConvexError: `"No bank account configured. Please set a default bank account in Business Settings before creating invoices."`. Extract bankName, bankAccountNumber (from `accountNumber` field), bankAccountName (from `name` field on the bankAccounts doc).
  7. Build order items from `orderItems` table (query by orderId): map to `{ productName, variant, qty, unitPrice, lineTotal }`. For each item, resolve product name from menuProducts table. **Edge case**: if order has zero items, throw ConvexError: `"Cannot create invoice for an order with no items."`.
  8. Calculate subtotal from line totals. Resolve discount: if order has `orderLevelDiscount` + `orderLevelDiscountType`, compute discountAmount (IDR) and discountLabel (e.g., "10%" for percentage, omit for flat). Handle 100% discount edge case: finalTotal may equal deliveryFee only (this is valid per business rules -- zero-total orders are allowed).
  9. Snapshot paymentStatus and paymentMethod from the order as read-only data for the invoice record. These are snapshotted at creation time and reflect the order's payment state.
  10. Insert invoice record with status="draft", all seller/buyer/order snapshots, `generatedBy: ctx.user._id`, `updatedAt: Date.now()`. Return the new invoice ID.

- `updateDraft` -- protectedMutation, `roles: ["admin", "manager"]`, args: `{ invoiceId: v.id("invoices"), ...partial update fields (all optional) }`. The partial fields include: buyerName, buyerCompany, buyerNpwp, buyerAddress, buyerPhone, poNumber, dueDate, notes, items, subtotal, discountAmount, discountLabel, deliveryFee, finalTotal, sellerName, sellerAddress, sellerPhone, sellerEmail, sellerNpwp, bankName, bankAccountNumber, bankAccountName. **NOTE: paymentStatus and paymentMethod are NOT included as editable fields** -- they are snapshotted from the order at draft creation time and should not be user-editable. Handler: get invoice, verify status="draft" (throw ConvexError if final). Patch with provided fields + `updatedAt: Date.now()`.

- `discardDraft` -- protectedMutation, `roles: ["admin", "manager"]`, args: `{ invoiceId: v.id("invoices") }`. Get invoice, verify status="draft" (throw ConvexError if not). Delete with `ctx.db.delete`.

- `finalize` -- protectedMutation, `roles: ["admin", "manager"]`, args: `{ invoiceId: v.id("invoices") }`. Handler:
  1. Get invoice, verify status="draft" (throw ConvexError if not).
  2. Generate invoice number using helper `getNextInvoiceNumber(ctx)`:
     - Import `getWibComponents` from `convex/lib/periodRange.ts`.
     - Get current WIB time components: `const { year, month } = getWibComponents(Date.now());`. Note: `getWibComponents` returns `{ year, month, day, dayOfWeek }` only -- no hours/minutes/seconds.
     - Build prefix: `${String(year).slice(-2)}${String(month + 1).padStart(2, "0")}` (month is 0-indexed in getWibComponents).
     - Query `invoiceCounters.by_prefix` with `.first()` (use `.first()`, NOT `.unique()` -- `.unique()` throws if a duplicate row exists due to a bug, whereas `.first()` gracefully handles it and is the safer choice).
     - If counter exists: increment `lastNumber`, patch counter.
     - If not: insert new counter with `lastNumber: 1`.
     - Format: `INV-${prefix}-${String(sequence).padStart(3, "0")}`.
  3. Patch invoice: `status: "final"`, `invoiceNumber`, `generatedAt: Date.now()`.
  4. Customer write-back: Read customer by orderId->customerId path. If invoice has buyerCompany, buyerNpwp, or buyerAddress that differ from customer record, patch customer with new values (only set fields that have values).
  5. Return `{ invoiceId, invoiceNumber }`.
