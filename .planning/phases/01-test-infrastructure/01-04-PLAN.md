**Test structure (15 tests in 4 describe blocks):**

**1. Percentage discount calculation (4 tests):**
- 10% discount on 100K order = 10K discount (final: 90K)
- 25% discount on 200K order = 50K discount (final: 150K)
- 100% discount (free order) on 50K order = 50K discount (final: 0)
- Percentage discount rounds correctly (e.g., 15% of 100,333 = 15,049.95 → 15,050)

**2. Fixed discount calculation (3 tests):**
- 50K fixed discount on 200K order (final: 150K)
- Fixed discount equal to order total (100K off 100K order = free, final: 0)
- Fixed discount greater than order total capped at order total (150K off 100K order = final: 0, not negative)

**3. Minimum order validation (4 tests):**
- Order below minimum (80K order, 100K minimum) rejects voucher (expect error via `expect().rejects.toThrow()`)
- Order exactly at minimum (100K order, 100K minimum) accepts voucher
- Order above minimum (120K order, 100K minimum) accepts voucher
- Voucher with no minimum accepts any order total

**4. Expiry and usage limits (4 tests):**
- Expired voucher (validUntil < Date.now()) rejects (expect error)
- Not-yet-valid voucher (validFrom > Date.now()) rejects (expect error)
- Valid voucher (validFrom < Date.now() < validUntil) accepts
- Usage limit enforcement:
  - Create voucher with usageLimit: 2
  - Use voucher on order 1 (success)
  - Use voucher on order 2 (success)
  - Use voucher on order 3 (reject, limit reached)
  - Verify usage count via verifyVoucherUsage helper

```typescript
test('10% percentage discount calculates correctly', async () => {
  const t = convexTest(schema);

  // ARRANGE: Create 10% voucher
  const voucherId = await createVoucher(t, {
    code: 'SAVE10',
    discountType: 'percentage',
    discountValue: 10,
    validFrom: Date.now() - 86400000, // Valid from yesterday
    validUntil: Date.now() + 86400000, // Valid until tomorrow
  });

  // ACT: Create 100K order with voucher
  const { orderId, originalTotal, discountedTotal } = await createOrderWithVoucher(t, {
    voucherCode: 'SAVE10',
    orderTotal: 100000,
  });

  // ASSERT: Discount is 10K, final total is 90K
  const order = await t.run(async (ctx) => ctx.db.get(orderId));
  expect(order?.voucherDiscount).toBe(10000);
  expect(order?.finalTotal).toBe(90000);
});
```
