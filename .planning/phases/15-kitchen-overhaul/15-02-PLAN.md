    **IMPORTANT -- Use existing shadcn/ui components (NO custom primitives):**
    Available in `src/components/ui/`: Card, Badge, Button, Skeleton, Tooltip, Separator, Popover, Sheet.
    - StatCard → build on shadcn `Card` + `CardContent`
    - Urgency indicators → use Tailwind color classes (green/amber/red), NOT custom CSS
    - Loading state → use shadcn `Skeleton`
    - Gear icon → use Lucide `Settings` icon in a shadcn `Button variant="ghost"`
    Do NOT create custom card primitives.

    **Create StatCard.tsx:**
    Small, compact stat card for the dashboard header:
    ```typescript
    interface StatCardProps {
      label: string;                    // e.g., "Min Target"
      value: string | number;           // e.g., "85"
      subtitle?: string;               // e.g., "(4 orders)"
      urgency?: 'green' | 'amber' | 'red' | 'default';
      onClick?: () => void;            // For tap-to-expand behavior
      expanded?: React.ReactNode;      // Expanded content (Big/Mid breakdown)
    }
    ```
    - Built on shadcn `Card` with compact padding (`p-3`)
    - Label: small muted text at top
    - Value: large bold number
    - Subtitle: small muted text below value
    - Urgency coloring applied to the value text:
      - `default`: normal text color
      - `green`: `text-green-600`
      - `amber`: `text-amber-600`
      - `red`: `text-red-600 font-bold`
    - If `onClick` provided, card is tappable with hover/active state
    - If `expanded` provided and card is in expanded state, show the expanded content below the main value

    **Create DashboardHeader.tsx:**
    Sticky bar with 4 stat cards:
    ```typescript
    interface DashboardHeaderProps {
      minTarget: number;
      minTargetOrderCount: number;
      maxTarget: { total: number; big: number; mid: number };
      remainingBalls: { total: number; big: number; mid: number };
      ordersLeft: number;
      hasOverdueOrders: boolean;
      onOpenConfig: () => void;
      canConfigure: boolean;
      isLoading?: boolean;
    }
    ```

    Layout:
    - Container: `sticky z-20 bg-background/95 backdrop-blur-sm border-b px-4 py-3`
    - **Do NOT set a fixed `top` value here** -- the parent (KitchenViewV2) will control positioning. Just use `sticky` with no `top` so it naturally sticks below whatever is above it, OR accept a `className` prop for the parent to inject `top-[56px]` or similar.
    - Grid: `grid grid-cols-2 gap-2` on mobile, `grid-cols-4 gap-3` on desktop (`md:grid-cols-4`)
    - Gear icon: Positioned in the top-right corner of the header (absolute within the sticky container). Only visible when `canConfigure=true`. Uses Lucide `Settings` icon in shadcn `Button variant="ghost" size="icon"`. Calls `onOpenConfig`.

    **4 Stat Cards:**
    1. **Min Target Today:** Label "Min Target", value = `minTarget`, subtitle = `(${minTargetOrderCount} orders)`. Urgency = `default`.
    2. **Max Production Target:** Label "Max Target", value = `maxTarget.total`. No urgency. Tappable to show breakdown: "Big: {big} / Mid: {mid}" in expanded area.
    3. **Remaining Balls:** Label "Remaining", value = `remainingBalls.total`. Urgency calculation (Claude's discretion per user decision):
       - `green`: remainingBalls.total <= maxTarget.total AND !hasOverdueOrders
       - `amber`: remainingBalls.total > maxTarget.total OR (remainingBalls > 0 AND any orders due today incomplete)
       - `red`: hasOverdueOrders is true
       Tappable to show breakdown: "Big: {big} / Mid: {mid}" in expanded area.
    4. **Orders Left:** Label "Orders Left", value = `ordersLeft`. Urgency = `default`.

    **Loading state:** When `isLoading=true`, render 4 shadcn `Skeleton` cards in the same grid layout (each ~h-20 rounded).

    **Combined ball total by default; tap to see breakdown (per locked decision):**
    Use `useState` for `showBreakdown` boolean. When tapped (StatCard onClick), toggle between showing just the total number and showing "Big: X / Mid: Y" below the total.
  </action>
