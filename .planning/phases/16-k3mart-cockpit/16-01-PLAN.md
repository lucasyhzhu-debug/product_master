    2. Add `COMMERCIAL_DATES_2026` array with:
       - Sequential dates: `2026-01-01` ("1.1"), `2026-02-02` ("2.2"), `2026-03-03` ("3.3"), ..., `2026-12-12` ("12.12")

       - Singles' Day: `2026-11-11` ("11.11 Singles' Day")
       - Note: Some sequential dates overlap with public holidays (e.g., 01-01 is New Year). The public holiday takes precedence for naming but the day still counts as a sales date for demand patterns.
    3. Add `commercialDateMap: Map<string, string>` (date -> event name).
    4. Add `getCommercialDateName(date: string): string | undefined` function.
    5. Add `getDayType(date: string): "weekday" | "weekend" | "holiday" | "sales_date"` classifier function:
       - If public holiday → "holiday"
       - If commercial/sales date → "sales_date"
       - If Saturday or Sunday → "weekend"
       - Otherwise → "weekday"
    6. Add `getEventName(date: string): string | undefined` -- returns holiday name OR commercial date name (holiday takes precedence).
    7. Add `getDemandMultiplier(date: string): number` -- per user decision:
       - weekday: 1.0 (baseline)
       - weekend: 2.5
       - holiday: 2.5 (same as weekend)
       - sales_date: 2.5 (same as weekend)
    8. Export all new functions.

    - Weekday rate = baselineWeeklyTotal / 5
    - Weekend/holiday/sales rate = weekdayRate * 2.5
