## Decisions Made

- **Inlined Wave 1 shared types.** Plan depends_on [02, 05], but this worktree is a parallel Wave 2 executor and Wave 1 Plans 02/05 had not been merged. Created ChannelAdapter + ChannelSaleEvent inline (copied verbatim from Plan 02 action block). When Wave 1 merges, the files will be identical (no conflict resolution needed).
- **Pure helper over inline arithmetic.** The items variance check could have been 3 lines of inline code inside createSettlement, but extracting to `assertItemsMatchTotalRevenue` makes it testable without convex-test infrastructure (pure, ctx-free). Tests cover 5 cases including message format for debuggability.
- **K3Mart R9 counters return from action but do not land on externalSyncLogs yet.** Wave 1 Plan 01 adds `itemsDeducted` + `itemsSkipped` schema fields to externalSyncLogs. Until that lands, the counters are tracked locally and surface in the action's return value for observability. When Plan 01 schema ships, a one-line patch will pipe them to updateSyncLog.
- **Grabfood stub preserves all existing scaffolding.** Added new exports at the end of adapter.ts without touching any of the existing token refresh, order accept/reject/mark-ready, menu push, 401 handling code. Net-zero risk to the grabfood code that runs today.

## Issues Encountered

- **`ctx.runMutation` from a public mutation** — The plan snippet for Task 7.3 called `ctx.runMutation(internal.externalData.mutations.saveRevenueItems, ...)` from inside `createSettlement`, which is a regular (public) `mutation`. A preamble comment in `convex/externalData/mutations.ts:780` reads "public mutations cannot use ctx.runMutation." However, `convex/bigsellerOrders/mutations.ts:288` shows an existing public mutation (`backfillBigsellerItems`) using the same pattern, and `npm run type-check` + `npm run build` both pass. The comment appears to predate current Convex API capabilities. Shipped as written in the plan. If Convex runtime rejects the call in production, the fix is to convert createSettlement to internalMutation-wrapped-with-public-wrapper or to export `saveRevenueItemsImpl` from externalData/mutations.ts and call it inline.
