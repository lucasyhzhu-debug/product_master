**Key question:** when K3Mart post-74.5.1 has a child with (qty=txn.qty, totalPrice=txn.total), does the existing `childItems.length > 0` branch count it correctly? YES — the child carries the same qty + revenue as the parent's `quantitySold` / `revenueGross`. The else-branch synthesis would have produced the SAME item. So the refactor is byte-equivalent on the happy path.

**Risk cases:**
1. Historical K3Mart parents WITHOUT children — fall through to else-branch as today. Unchanged.
2. New K3Mart parents WITH a child — fall into if-branch. Must produce equivalent analytics to the else-branch (byte-equivalent).
3. A K3Mart parent with `linkedMenuProductId` set but the child's `linkedMenuProductId` is null (or vice versa) — edge case that could mis-attribute.

RESEARCH Caveat 1 says: **Verify K3Mart's new child rows don't double-count.** The child's qty and revenue are IDENTICAL to the parent's (not additive) — so if the report sums child + parent, it doubles. Audit: does `unitEconomics.ts` ever sum both? Per the current code at line 186-230, NO — it's an `if/else`, not a sum. So the CODE is safe against double-counting.

**What can still break:** any DOWNSTREAM aggregator that accesses `revenue.revenueGross` directly AND `externalRevenueItems.totalPrice` in the same pipeline. Those are separate queries — the reconciliation task is to grep for them.

```typescript
import { internalAction, mutation } from "../_generated/server";
import { v } from "convex/values";
import { requireRole } from "../lib/auth";
import { internal } from "../_generated/api";
import type { Id } from "../_generated/dataModel";

/**
 * One-shot routing seed migration (Phase 74.5.1).
 *
 * Populates `channelRouting` from `externalOutlets.linkedStorageLocationId` — the
 * implicit GoFood routing source pre-74.5. Idempotent: re-running skips outlets
 * whose routing row already exists.
 *
 * Does NOT modify externalOutlets. The field is deprecated in 74.5.1 (stop writing);
 * actual field drop is deferred to 999.6 per CONTEXT §Deferred Ideas.
 */
export const seedChannelRoutingFromOutlets = internalAction({
  args: { triggeredBy: v.string() },
  handler: async (ctx, args): Promise<{ seeded: number; skipped: number; alreadyExists: number }> => {
    const outlets = await ctx.runQuery(
      internal.migrations.channelRoutingSeed.listOutletsWithLinkedLocation,
      {},
    );

    let seeded = 0;
    let skipped = 0;
    let alreadyExists = 0;

    for (const outlet of outlets) {
      if (!outlet.linkedStorageLocationId) { skipped++; continue; }

      const existing = await ctx.runQuery(
        internal.migrations.channelRoutingSeed.findExistingRoute,
        { source: outlet.source, outletId: outlet._id },
      );

      if (existing) { alreadyExists++; continue; }

      await ctx.runMutation(
        internal.migrations.channelRoutingSeed.insertSeedRoute,
        {
          source: outlet.source,
          outletId: outlet._id as Id<"externalOutlets">,
          storageLocationId: outlet.linkedStorageLocationId as Id<"storageLocations">,
          triggeredBy: args.triggeredBy,
        },
      );
      seeded++;
    }

    return { seeded, skipped, alreadyExists };
  },
});

// Internal helper queries + mutation

import { internalMutation, internalQuery } from "../_generated/server";

export const listOutletsWithLinkedLocation = internalQuery({
  args: {},
  handler: async (ctx) => {
    return await ctx.db
      .query("externalOutlets")
      .filter((q) => q.neq(q.field("linkedStorageLocationId"), undefined))
      .collect();
  },
});

export const findExistingRoute = internalQuery({
  args: {
    source: v.union(
      v.literal("bigseller"), v.literal("consignment"), v.literal("gobiz"),
      v.literal("grabfood"), v.literal("internal"), v.literal("k3mart"),
      v.literal("shopee"), v.literal("tiktok"),
    ),
    outletId: v.id("externalOutlets"),
  },
  handler: async (ctx, args) => {
    return await ctx.db
      .query("channelRouting")
      .withIndex("by_source_outlet_product", (q) =>
        q.eq("source", args.source).eq("outletId", args.outletId).eq("menuProductId", undefined),
      )
      .first();
  },
});

export const insertSeedRoute = internalMutation({
  args: {
    source: v.union(
      v.literal("bigseller"), v.literal("consignment"), v.literal("gobiz"),
      v.literal("grabfood"), v.literal("internal"), v.literal("k3mart"),
      v.literal("shopee"), v.literal("tiktok"),
    ),
    outletId: v.id("externalOutlets"),
    storageLocationId: v.id("storageLocations"),
    triggeredBy: v.string(),
  },
  handler: async (ctx, args) => {
    return await ctx.db.insert("channelRouting", {
      source: args.source,
      outletId: args.outletId,
      menuProductId: undefined,
      storageLocationId: args.storageLocationId,
      isDefault: false,
      notes: `Seeded from externalOutlets.linkedStorageLocationId on ${new Date().toISOString()}`,
      updatedBy: `migration:${args.triggeredBy}`,
      updatedAt: Date.now(),
    });
  },
});

// Admin-facing trigger mutation

export const runRoutingSeed = mutation({
  args: { token: v.string() },
  handler: async (ctx, args): Promise<{ scheduled: true }> => {
    const user = await requireRole(ctx, args.token, ["admin"]);
    await ctx.scheduler.runAfter(
      0,
      internal.migrations.channelRoutingSeed.seedChannelRoutingFromOutlets,
      { triggeredBy: user.name },
    );
    return { scheduled: true };
  },
});
```

This file uses static imports (Pitfall #8). Uses the `externalSource` union as an explicit validator (not importing the `externalSource` helper — explicit literals for clarity here; alternatively `import { externalSource } from "../lib/externalSource"` and use it).

Prefer the import form — cleaner:

```typescript
import { externalSource } from "../lib/externalSource";
// ... use externalSource directly as the validator in all 3 internal functions
```
