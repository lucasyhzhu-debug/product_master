# Phase 74.5.1 Plan 03: resolveChannelRoute helper + channelRouting CRUD mutations Summary

One-liner: 5-tier channel-routing resolver + admin-gated CRUD mutations + admin-gated list/preview queries, all exposed from `convex/productInventory/channelRouting.ts` + `convex/productInventory/channelRoutingQueries.ts`.

## What Shipped

### `convex/productInventory/channelRouting.ts` (262 lines)

- **`CHANNEL_ROUTING_NOT_CONFIGURED`** (exported string constant `"CHANNEL_ROUTING_NOT_CONFIGURED"`). UI/tests match via `err.message.startsWith(CHANNEL_ROUTING_NOT_CONFIGURED)`.
- **`resolveChannelRoute(ctx, {source, outletId?, menuProductId?})`** — 5-tier precedence helper. Accepts `QueryCtx | MutationCtx`. Returns `Id<"storageLocations">` or throws `Error("CHANNEL_ROUTING_NOT_CONFIGURED: ...")`.
  - Tier 1: `by_source_outlet_product` index hit
  - Tier 2: `by_source_outlet`, filter `menuProductId === undefined`
  - Tier 3: `by_source_product`, filter `outletId === undefined`
  - Tier 4: `by_source`, filter `isDefault && outletId === undefined && menuProductId === undefined`
  - Tier 5: throw (no silent fallback)
- **`createRoutingRule`** mutation — admin-gated. Validates `isDefault` (requires both outlet+product unset) and rejects duplicate `(source, outletId, menuProductId)` tuples.
- **`updateRoutingRule`** mutation — admin-gated. `source`/`outletId`/`menuProductId` immutable; re-validates `isDefault` against the stored outlet/product fields.
- **`deleteRoutingRule`** mutation — admin-gated hard delete.
- All mutations set `updatedBy = user.name`, `updatedAt = Date.now()`.

### `convex/productInventory/channelRoutingQueries.ts` (156 lines)

- **`listRoutingRules({token})`** — admin-gated. Collects all `channelRouting` rows, joins with `storageLocations`/`externalOutlets`/`menuProducts` for display names (fallback `(deleted)` for orphaned FKs). Sorts by `source` asc, `updatedAt` desc within source.
- **`previewRouteResolution({token, source, outletId?, menuProductId?})`** — admin-gated. Calls `resolveChannelRoute` inside try/catch:
  - On success: returns `{ok: true, tier: 1|2|3|4, storageLocationId, storageLocationName}`. Tier determined by re-walking the precedence (stable-signature tradeoff — see Decisions).
  - On `CHANNEL_ROUTING_NOT_CONFIGURED` throw: returns `{ok: false, tier: 5, errorCode, message}` so UI renders inline error instead of a query rejection.
  - Any other throw surfaces normally.
