# Phase 74.5.1 Plan 02: Types — ChannelSaleEvent + ChannelAdapter contract Summary

**One-liner:** Created the two pure-type contract artifacts (ChannelSaleEvent canonical event + generic ChannelAdapter<TRawPayload> interface) under `convex/integrations/_shared/` that close the contract loop for every downstream adapter refactor and contract test in Phase 74.5.1.

## What Was Built

Two new TypeScript modules under `convex/integrations/_shared/` — zero runtime logic, pure type declarations consumed by every adapter refactor in Waves 2+ and by the Wave 0 contract test.

### `convex/integrations/_shared/channelSaleEvent.ts` (50 lines)

Canonical event shape emitted by every adapter's `normalize()` function. Eleven readonly fields:

| Field | Type | Purpose |
|-------|------|---------|
| `source` | `ExternalSource` | 8-source literal, routing Tier input |
| `occurredAt` | `number` | Business epoch ms (not `Date.now()`) — preserves historical timestamp on backfill |
| `externalTransactionId` | `string` | Platform transaction ID (SP-xxx, GoFood order no, etc.) |
| `externalItemId` | `string?` | Per-item ID; optional (K3Mart collapsed-period has none) |
| `outletId` | `Id<"externalOutlets">?` | Feeds routing Tier 1/2 |
| `menuProductId` | `Id<"menuProducts">?` | Post-SKU resolution; feeds routing Tier 1/3 + deduction |
| `externalProductCode` | `string?` | Audit/debug |
| `externalProductName` | `string?` | Audit/display |
| `quantity` | `number` | Must be > 0 for deduction |
| `unitPrice` | `number` | Per-unit price (IDR) |
| `totalPrice` | `number` | Line total (cross-check vs unitPrice × quantity) |

Imports: `Id` from `../../_generated/dataModel`, `ExternalSource` from `../../lib/externalSource` — both static per CLAUDE.md Pitfall #8.

### `convex/integrations/_shared/channelAdapter.ts` (32 lines)

Generic interface `ChannelAdapter<TRawPayload = unknown>` with three readonly members:

- `source: ExternalSource` — single-source literal per adapter.
- `fetch?: (args: unknown) => Promise<TRawPayload>` — optional; omitted for webhook/DB-driven adapters (internal, consignment).
- `normalize: (payload: TRawPayload) => ChannelSaleEvent[] | Promise<ChannelSaleEvent[]>` — pure transform, side-effect-free, testable in isolation.

Grabfood adapter per D74.5.1-L5 will throw `Not implemented — requires orders:read OAuth scope` from `normalize()`; other four will produce real events.

## Decisions Made

1. **`normalize()` allows Promise return.** Per plan spec, signature is `ChannelSaleEvent[] | Promise<ChannelSaleEvent[]>` — supports future async normalize paths (e.g., internal adapter may need Convex ctx access once wrapped).
2. **`fetch()` marked optional.** Internal adapter reads Convex orders table (no HTTP fetch); consignment adapter is admin-UI triggered. Making fetch optional keeps the interface non-violating for these cases.
3. **All 10 fields on ChannelSaleEvent are `readonly`.** Prevents downstream mutation bugs (once emitted, events are immutable records).
4. **`externalItemId` optional.** K3Mart collapsed-period rows and some consignment rows lack per-item identifiers — mandatory would force adapter hacks.
