**Page (src/pages/HistoricalImportPage.tsx):**

Build a linear wizard page (~300-400 lines) with these states as a discriminated union:

```typescript
type WizardState =
  | { step: "upload" }
  | { step: "validating" }
  | { step: "review"; result: CsvParseResult }
  | { step: "importing"; total: number; completed: number; batchIndex: number }
  | { step: "complete"; totalCreated: number; totalAmount: number }
  | { step: "error"; message: string; completedSoFar: number };
```

Key implementation details:

1. **Upload state:**
   - File input accepting `.csv` (styled drop zone)
   - "Download Template" button: generates `import-template.csv` with header row (`date,amount,description,vendorName,accountCode,receiptUrl`) via Blob + URL.createObjectURL + synthetic anchor click
   - "Download CoA Reference" button: generates `chart-of-accounts-reference.csv` from `useQuery(api.accounts.queries.list, { activeOnly: true })` with proper CSV quoting via `escapeCsv` helper
   - Use `PageHeader` component with title "Historical Expense Import"

2. **Validating state:** Brief transitional state while `parseAndValidateCsv` runs. Set state to "review" with result when done.

3. **Review state:**
   - Error table (row number + error message) -- if errors > 0, "Confirm Import" button disabled
   - Warning list (duplicates) -- informational only
   - Summary cards: valid rows count, error count, total amount (formatted with `formatCurrency`)
   - Summary table by GL account: code, name, entry count, subtotal
   - Summary table by period (YYYY-MM): month, entry count, subtotal
   - "Confirm Import" button (disabled if errors > 0)
   - "Re-upload" button to go back to "upload" state

4. **Importing state:**
   - Generate `importBatchId` via `crypto.randomUUID()` before first batch
   - Chunk validRows into batches of `MAX_BATCH_SIZE` (50)
   - Sequential loop: `for (const batch of batches) { await mutateAsync({ importBatchId, rows: batch }); }`
   - DO NOT use Promise.all -- sequential prevents counter races
   - Progress bar (use `@radix-ui/react-progress` already in package.json) with text: "Creating entries... 150/350 (batch 3 of 7)"
   - Track `completedBatches` in state for resume-from-failure
   - On batch failure: transition to "error" state with message and completedSoFar

5. **Complete state:**
   - Success message: "{N} journal entries created successfully"
   - Total amount imported (formatted)
   - Link to `/financials` to verify entries in P&L

6. **Error state:**
   - Error message display
   - Number of entries already committed
   - "Retry from failed batch" button (re-enters importing state from failedAtBatch)

Reference existing pages for patterns:
- `src/pages/AccountsManager.tsx` -- admin page pattern
- `src/pages/ExpenseSubmit.tsx` -- form with file upload
- Use `toast.error` from sonner for unexpected errors

Export as named export: `export function HistoricalImportPage() { ... }`
