    **Rewrite OrderManager.tsx:**
    Strip the existing order list/form split-screen layout. Replace with:

    2. `<KanbanBoard />` component filling the remaining viewport

    4. Loading state: show 6 skeleton columns with 3 placeholder cards each
    5. The page is already in a `fullWidth` Layout route in App.tsx -- keep this

    **Create KanbanBoard.tsx:**
    Horizontal scrolling container with 6 columns:
    ```
    Draft | Awaiting Payment | Payment Received | Being Prepared | Awaiting Delivery | Complete
    ```
    - Container: `overflow-x-auto flex gap-4 p-4 h-[calc(100vh-header)]` (snap scrolling on mobile)
    - Mobile: `snap-x snap-mandatory` with each column `snap-center min-w-[85vw]`
    - Desktop: columns flex with `min-w-[280px] max-w-[320px]`
    - Pass `onCardClick` handler that opens the slide-over with the selected order
    - State: `selectedOrderId` for slide-over

    **Create KanbanColumn.tsx:**
    Single column component:
    - Header: column title + order count badge (e.g., "Payment Received (3)")
    - Column background: subtle `bg-muted/30` rounded container
    - Scrollable card list inside column: `overflow-y-auto` with max-height
    - For "Complete" column: add "Show cancelled" toggle (off by default). When off, filter out orders with status "Cancelled". Show toggle only if there are cancelled orders.
    - Forward action button at bottom of column (except Complete and Cancelled)
    - Backward action button at top of column (except Draft)

    **Create KanbanCard.tsx:**
    Order card component (Claude has discretion on visual hierarchy per user decision):
    - **Top row:** Customer name (bold, truncate) + Order # (mono, smaller)
    - **Due date row:** Day name + date ("Sat, Feb 17") with urgency coloring:
      - Default: normal text
      - Due tomorrow: `text-amber-600 bg-amber-50` badge
      - Due today: `text-red-600 bg-red-50` badge
      - Overdue: `text-red-700 bg-red-100 font-bold` badge
      - Use `date-fns` for day calculations (already in dependencies)
    - **Price row:** Discounted total prominent (large text) + if discount exists: discount badge (e.g., "-Rp 50k" in a small pill) + struck-through gross price (smaller, line-through)
    - **Items section:** ALL line items (no truncation, card grows). Each item: `{quantity}x {productName}` in compact text
    - **Footer:** "by {creatorName}" in muted small text
    - **Expedited badge:** If order.expedited is true, show amber/orange "EXPEDITED" badge at top-right + `border-amber-400 border-2` on the card
    - Card click handler: calls `onCardClick(orderId)`
    - Card styling: white bg, subtle shadow, rounded-lg, hover state

    **Update useOrders.ts hook:**
    Add `useKanbanOrders()` hook that wraps `useQuery(api.orders.queries.listForKanban)`.
    Return typed column data or undefined while loading.
