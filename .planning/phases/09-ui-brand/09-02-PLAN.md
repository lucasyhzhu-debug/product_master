In `src/App.tsx`, create a second route group for full-width pages that uses Layout but skips PageContainer. The approach:

**Simplest approach:** Create two route groups under `<Route path="/">`:
1. `<Route element={<Layout />}>` — standard pages with PageContainer
2. `<Route element={<Layout fullWidth />}>` — full-width pages

Add a `fullWidth?: boolean` prop to Layout. When `fullWidth` is true, skip the `PageContainer` wrapper:

```tsx
interface LayoutProps {
  fullWidth?: boolean;
}

export function Layout({ fullWidth = false }: LayoutProps) {
  // ... existing code

```

Then in App.tsx, move kitchen and orders into a full-width route group:


Both route groups share the same `<Route path="/">` parent (no path on layout routes — they're layout routes).

Wait — React Router v7 supports layout routes without paths. The correct structure:

```tsx
<Route path="/">
  {/* Role-based redirect */}
  <Route index element={<RoleBasedRedirect />} />

  {/* Full-width layout (no PageContainer) */}
  <Route element={<Layout fullWidth />}>
    <Route path="kitchen" element={...} />
    <Route path="orders" element={...} />
  </Route>

  {/* Standard layout (with PageContainer) */}
  <Route element={<Layout />}>
    <Route path="orders/:id" element={...} />
    {/* ... all other routes ... */}
  </Route>

  {/* Redirects */}
  <Route path="restock" element={<Navigate to="/k3mart-cockpit" replace />} />
  ...
</Route>
```

Note: The `index` route and redirect routes need to be outside both layout routes since they don't render within Layout. Actually, `RoleBasedRedirect` needs Layout too (it renders a redirect, but the Layout wrapper provides the shell while loading). Let me reconsider.

Actually, `RoleBasedRedirect` just returns `<Navigate>` — it doesn't render UI. It can be outside Layout. The redirect routes also don't render UI. So the structure above is correct.

But wait — currently the `<Route path="/" element={<Layout />}>` wraps everything. We need to change to pathless layout routes INSIDE `<Route path="/">`. The `path="/"` route should NOT have an element — it's just a path grouping. Layout routes are pathless children.

Correct App.tsx structure:
```tsx
<Routes>
  <Route path="/login" element={<PublicOnlyRoute><Login /></PublicOnlyRoute>} />

  <Route path="/">
    <Route index element={<RoleBasedRedirect />} />

    {/* Full-width pages (no PageContainer) */}
    <Route element={<Layout fullWidth />}>
      <Route path="kitchen" element={<ProtectedRoute requiredPermission="canAccessKitchen"><KitchenViewV2 /></ProtectedRoute>} />
      <Route path="orders" element={<ProtectedRoute requiredPermission="canAccessOrders"><OrderManager /></ProtectedRoute>} />
    </Route>

    {/* Standard pages (with PageContainer) */}
    <Route element={<Layout />}>
      <Route path="orders/:id" element={...} />
      <Route path="sales" element={...} />
      {/* ... all other standard routes ... */}
    </Route>

    {/* Redirects (no layout needed) */}
    <Route path="restock" element={<Navigate to="/k3mart-cockpit" replace />} />
    <Route path="inventory/components" element={<Navigate to="/components/production" replace />} />
    <Route path="components/packaging" element={<Navigate to="/inventory" replace />} />
  </Route>

  <Route path="*" element={<Navigate to="/login" replace />} />
</Routes>
```
