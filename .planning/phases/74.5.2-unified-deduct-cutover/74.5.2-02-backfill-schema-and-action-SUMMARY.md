### `convex/productInventory/backfill.ts` (174 LOC)

```typescript
// Constants
const BATCH_SIZE = 200;       // D-16: chunk size per page
const MAX_ITERATIONS = 500;   // 100K row runaway cap

// Chunked worker — processes one 200-item page per invocation.
export const backfillOnePage = internalMutation({
  args: { source: externalSource },
  handler: async (ctx, args): Promise<{
    itemsProcessed: number;
    deducted: number;
    skipped: number;
  }>;
});

// Ceremonial scheduler wrapper — loops backfillOnePage until zero items or MAX_ITERATIONS.
export const backfillChannelDeductions = internalAction({
  args: { source: externalSource, triggeredBy: v.string() },
  handler: async (ctx, args): Promise<{
    totalDeducted: number;
    totalSkipped: number;
    iterations: number;
    hitCap: boolean;    // dashboard/logs diagnostic; admin UI does not consume
  }>;
});

// Admin trigger — schedules the action, returns immediately.
export const runChannelBackfill = mutation({
  args: { source: externalSource, token: v.string() },
  handler: async (ctx, args): Promise<{ scheduled: true }>;
});

// Preflight — returns pending count (capped 5000) + per-source blocking audit issues.
export const getChannelBackfillPreflight = query({
  args: { source: externalSource, token: v.string() },
  handler: async (ctx, args): Promise<{
    pendingItems: number;       // capped at 5000; UI displays "5000+" above cap
    blockingAuditIssues: number;
  }>;
});
```

### Contract Enforcement

| Requirement | Implementation |
| --- | --- |
| Admin-only trigger | `requireRole(ctx, args.token, ["admin"])` on both `runChannelBackfill` and `getChannelBackfillPreflight` |
| Flag-independence (D74.5.2-L13) | No read of `channelDeductionEnabled`; calls `processChannelSaleInternal` directly |
| Timestamp preservation (D-16) | Delegates to `buildEventFromRow` which sets `occurredAt = revenue.transactionDate ?? revenue.periodStart ?? revenue._creationTime` |
| Silent-drop guard (D74.5.2-L4) | `!item.linkedMenuProductId` → `skipped++; continue;` WITHOUT `ctx.db.patch` — re-processable once SKU mapped |
| Idempotency (D-19) | `inventoryDeductedAt` patched ONLY on `result.deducted === true`; index narrows to un-deducted on re-run |
| Runaway protection | `MAX_ITERATIONS = 500` × `BATCH_SIZE = 200` = 100K item hard cap; `hitCap: true` surfaces in action return for dashboard inspection |
| Per-source audit gate (D-17) | Preflight query filters `channelAuditIssues` by `source` + `resolvedAt=undefined` + `severity=block` |
| Missing-revenue defensive skip | `if (!revenue) { skipped++; continue; }` — orphan items don't crash the batch |
