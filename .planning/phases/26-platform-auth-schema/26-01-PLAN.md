1. **Create `convex/lib/jwt.ts`:**
   ```typescript
   /**
    * Decode a JWT payload without verification (we validate by test-fetching instead).
    * Shared utility — used by K3Mart login, BigSeller paste flow, and any future JWT-based auth.
    */
   export function decodeJwtPayload(token: string): Record<string, unknown> {
     const parts = token.split(".");
     if (parts.length !== 3) {
       throw new Error("Invalid JWT format");
     }
     // base64url -> base64 -> decode
     const base64 = parts[1].replace(/-/g, "+").replace(/_/g, "/");
     const json = Buffer.from(base64, "base64").toString("utf-8");
     return JSON.parse(json);
   }
   ```

2. **Update `convex/platformCredentials/actions.ts`:**
   - Remove the local `decodeJwtPayload` function definition

   - Verify all existing usages (K3Mart `performK3MartRefresh`) still work

This extraction is required because Plan 02's BigSeller adapter also needs `decodeJwtPayload`. Having it in a shared location prevents duplication and makes it testable.

<task type="auto">
  <name>Task 3: Create registry-driven credential health query</name>
  <files>convex/platformCredentials/queries.ts</files>
  <action>
Add a new query `getHealthStatusAll` to `convex/platformCredentials/queries.ts` that returns health status for ALL platforms by iterating the registry.

**CRITICAL (staffreview fix): This query MUST require auth.** It exposes credential metadata (token expiry, last activity, credential existence). The existing queries (`getCredentialStatus`, `getCredentialStatusForManagers`) both require role-based auth. An unauthenticated health query would be a security regression.

The query should:

1. **Args:** `{ token: v.string() }` — admin session token for auth check
2. **Auth:** Call `requireRole(ctx, args.token, ["manager", "admin"])` — matching `getCredentialStatusForManagers` pattern
3. Import `PLATFORMS`, `PlatformId`, `HealthCheckType` from `convex/integrations/registry.ts`
4. For each platform in `PLATFORMS`:
   - If `healthCheckType === 'always_green'`: return `{ status: 'green', label: 'Connected' }`
   - If `healthCheckType === 'last_sync'`: look up the most recent `externalSyncLogs` entry for that platform's source; return green if synced within 48h, yellow if 2-7 days ago, red if >7 days or never synced
   - If `healthCheckType === 'token_expiry'`: look up `platformCredentials` for that `platformId`; calculate days remaining from `tokenExpiresAt`; compare against `yellowThresholdDays` and `redThresholdDays` from registry
5. **Return type — explicitly defined for Plan 03 consumption:**
   ```typescript
   type PlatformHealthStatus = {
     platformId: PlatformId;
     platformName: string;          // from registry: PLATFORMS[id].name
     authStrategy: AuthStrategy;    // from registry: needed by IntegrationHealthCard to determine action button
     category: PlatformCategory;    // from registry: needed for icon selection
     status: 'green' | 'yellow' | 'red' | 'disconnected';
     label: string;                 // e.g., "Connected", "7 days remaining", "Not configured"
     lastActivity: number | null;   // last sync timestamp (ms) or null
     daysRemaining: number | null;  // for token_expiry platforms, null otherwise
     hasExpiry: boolean;            // from healthConfig
     reconnectSteps: string[];      // from registry: for help dialogs
   };
   ```
   Return `Array<PlatformHealthStatus>`. This shape is the SINGLE prop interface that Plan 03's `IntegrationHealthCard` will consume — it replaces the old `syncHealth` + `credentialStatus` dual-prop pattern.
6. Handle the "no credential exists" case: return `disconnected` status with appropriate label
7. For GrabFood specifically: check if a `platformCredentials` record exists with `platformId: "grabfood"` — if yes and it has `email` (client_id) populated, return green; otherwise return `disconnected` with label "Client credentials not configured"

This replaces any hardcoded per-platform status logic in favor of a single registry-driven query. The frontend (Plan 03) will consume this query directly, passing each array element as props to `IntegrationHealthCard`.
  </action>
