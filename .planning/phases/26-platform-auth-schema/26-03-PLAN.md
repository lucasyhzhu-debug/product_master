**IntegrationHealthCard.tsx changes:**

**CRITICAL (staffreview fix): Redesign the prop interface.** The old component accepted `syncHealth: SyncHealthData` + `credentialStatus: CredentialStatus` as separate props. The new `getHealthStatusAll` query (Plan 01 Task 3) returns a flat `PlatformHealthStatus` object with all needed fields. The component MUST accept the new shape.

1. **Define new prop interface:**
   ```typescript
   interface IntegrationHealthCardProps {
     health: PlatformHealthStatus;  // Single prop from getHealthStatusAll array element
     onAction?: () => void;         // Primary action handler (refresh, paste, configure)
   }
   ```
   Where `PlatformHealthStatus` is the return type from `getHealthStatusAll`:
   ```typescript
   type PlatformHealthStatus = {
     platformId: string;
     platformName: string;
     authStrategy: string;       // 'password_grant' | 'paste_token' | 'client_credentials' | 'pos_login' | 'session_auth'
     category: string;           // 'delivery' | 'marketplace' | 'pos' | 'internal'
     status: 'green' | 'yellow' | 'red' | 'disconnected';
     label: string;
     lastActivity: number | null;
     daysRemaining: number | null;
     hasExpiry: boolean;
     reconnectSteps: string[];
   };
   ```
   This replaces the old `syncHealth` + `credentialStatus` dual-prop pattern with a single `health` prop.

2. **Remove old status derivation logic** — `getOverallStatus()` and related helpers that did `platformId === "k3mart"` comparisons. The `status` field is now pre-computed by the query.

3. **Derive UI behavior from `authStrategy`** (read from `health.authStrategy`):
   - `'password_grant'` (GoBiz): "Refresh Token" primary button
   - `'paste_token'` (BigSeller): "Paste Token" primary button
   - `'client_credentials'` (GrabFood): "Test Connection" or no button (just status)
   - `'pos_login'` (K3Mart): keep existing "Configure" button behavior
   - `'session_auth'` (Internal, Consignment): no action button — always connected

4. **Derive icon from `category`** (read from `health.category`):
   - `'pos'`: Store icon (Lucide)
   - `'delivery'`: Globe icon
   - `'marketplace'`: ShoppingBag icon
   - `'internal'`: Database icon

5. Show expiry countdown badge for platforms where `health.hasExpiry === true`, using `health.daysRemaining` and `formatCountdown` from `src/lib/formatters.ts`

6. Show status badge using `health.status` — use CSS variable tokens for colors per CODE_STYLE.md
