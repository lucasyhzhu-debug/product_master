  **A. Create `src/hooks/convex/useGoFoodDepot.ts`:**
  Hook wrapping all depot-related Convex queries:
  - `useGoFoodDepotSeedCheck()` -- calls `api.gofoodDepot.isSeedRequired`
  - `useGoFoodDepotOutlets()` -- queries `externalOutlets` filtered by source="gobiz"
  - `useGoFoodDepotStock(outletId)` -- calls `api.gofoodDepot.getDepotStock` with outletId (uses "skip" pattern when no outletId)
  - `useGoFoodRestockSuggestions(outletId)` -- calls `api.gofoodDepot.getRestockSuggestions` (skip when no outletId)
  - `useGoFoodOutletMappings(outletId)` -- calls `api.gofoodDepot.getOutletProductMappings` (skip when no outletId)
  Export all from `src/hooks/convex/index.ts`.

  **B. Create `src/components/gofoodDepot/SeedWarningBlocker.tsx`:**
  Full-page blocker component (per context: "nothing else loads until the seed is run"):
  - Centered warning card with AlertTriangle icon
  - "Finished Goods Inventory Not Initialized" heading
  - Lists unlinked outlet names
  - Instructions: "Run the seedFinishedGoodsLocations migration from the Convex dashboard to initialize."
  - No dismiss button -- this is a hard blocker

  **C. Create `src/pages/GoFoodDepotManager.tsx`:**
  Page layout following K3Mart Cockpit pattern:
  - Call ALL hooks at top (before any conditional returns) -- CRITICAL: React hooks order rule
  - If `seedRequired` is true, render `<SeedWarningBlocker>` (after hooks)
  - Outlet selector at top: dropdown or horizontal tabs for the 3 GoBiz outlets
  - Selected outlet state in component (default to first outlet)
  - Single scrollable page with stacked sections:
    1. Header: outlet name + "Last synced: [time]" from `outlet.lastSyncAt`
    2. Low-stock alert banner (conditionally rendered when any product < 5 remaining)
    3. DepotCockpitTable (stock levels, inline edit, restock suggestions)
    4. DepotMappingSection (product mappings)
  - PageHeader component with title "GoFood Depot Management"

  **D. Add route in `src/App.tsx`:**
  Add route `/gofood-depot` pointing to `GoFoodDepotManager` with `ProtectedRoute` (permission: `canAccessDashboard` -- Manager, Admin roles).
  Add navigation link in the sidebar/header if applicable (follow existing pattern in the app).

  <action>
  **A. Create `src/components/gofoodDepot/DepotCockpitTable.tsx`:**
  K3Mart Cockpit-style data table per outlet. Columns:
  1. **Product** -- menu product name
  2. **Remaining** (PRIMARY -- large font, most prominent) -- current stock at this depot from productInventory
  3. **Sold Today** (SECONDARY) -- from externalRevenue/externalRevenueItems for today at this outlet
  4. **Restock Tomorrow** -- from restock suggestions, with Tooltip on hover showing `breakdown` text
  5. **Available Elsewhere** -- total stock at other locations (from productInventory overview), so admin knows what can be transferred
  6. **Actions** -- "Move stock here" button (opens DepotStockTransferDialog)

  **Inline stock editing:**
  - The "Remaining" cell is inline editable: click to enter edit mode (input field appears), save on blur/Enter
  - This calls `adjustStock` mutation on productInventory (existing mutation)
  - Visual cue: pencil icon beside the number, input styling on focus
  - Optimistic update: UI updates immediately, Convex reactive query confirms

  **Low-stock highlighting:**
  - Rows where remaining < 5 get red/orange background highlight
  - Same threshold as `productInventorySettings.globalLowStockThreshold` (default 5)

  **B. Create `src/components/gofoodDepot/DepotMappingSection.tsx`:**
  Product mapping editor (section within depot page, not separate admin area):
  - Table/list of GoFood products for this outlet
  - Each row: GoFood product name | Linked menuProduct (dropdown select) | Active toggle
  - Unmapped products (no menuProduct linked) flagged with orange warning icon + "Unmapped" badge
  - **Explicit Save button** at bottom (not auto-save per context requirement)
  - Save calls `saveOutletProductMappings` mutation
  - Success toast on save via Sonner
  - If this outlet has no mappings yet, auto-call `initOutletMappingsFromPrevious` on first load (silent, shows pre-filled mappings that admin can edit before saving)

  **C. Create `src/components/gofoodDepot/DepotStockTransferDialog.tsx`:**
  Dialog/modal for moving stock to this depot:
  - Triggered by "Move stock here" button in cockpit table
  - Form fields:
    - Source location (dropdown of all storage locations with available stock)
    - Quantity (number input)
    - Shows "Available at source: N" for validation
  - Submit blocked if quantity > available at source
  - Calls `transferStock` mutation from plan 01
  - Success toast on completion
  - Auto-closes dialog on success
  </action>
