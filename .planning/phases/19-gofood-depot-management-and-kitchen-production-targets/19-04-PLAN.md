  **A. Rewrite `src/components/inventory/FinishedGoodsTab.tsx`:**

  **Grouping toggle** (toggle button group at top of data section, below hero):
  - **Product-grouped** (default): one card/row per menuProduct. Inside each card, show a sub-list of locations with quantity at each. Each location row has inline "Move To" and "Receive From" actions.
  - **Location-grouped**: one section per storageLocation. Inside each section, list all menuProducts with quantities. Each product row has inline "Move To" and "Receive From" actions.
  - Toggle updates the view dynamically; underlying data is the same flat list transformed client-side.

  **Per-row stock movement inline actions:**
  Each product-at-location row has two mini-action buttons:
  - **"Move To -->"** -- opens an inline form or popover:
    - Destination location (dropdown of other locations)
    - Quantity (number input, max = current quantity at this row's location)
    - "Transfer" button -- calls `transferStock` mutation
  - **"<-- Receive From"** -- opens an inline form or popover:
    - Source location (dropdown of other locations that have stock for this product)
    - Quantity (number input, max = available at source)
    - "Transfer" button -- calls `transferStock` mutation

  Both inline forms validate against available stock. Show "Available: N" next to quantity input.

  **Zero-stock rows:**
  - All locations shown by default even with zero stock
  - Zero-stock rows styled distinctly: greyed text, dimmed background, lower opacity
  - NOT hidden by default

  **"Move Stock" button in page header/toolbar:**
  Opens the global `StockTransferModal`.

  **B. Create `src/components/inventory/StockTransferModal.tsx`:**
  Global Move Stock modal (accessible from page header or per-product):
  - Form:
    - Source location (dropdown)
    - Destination location (dropdown, excludes source)
    - Product(s) (multi-select or repeated rows, one or more products)
    - Quantity per product (number input, validated against source stock)
  - "Transfer All" button -- calls `transferStock` for each product in sequence
  - Shows available stock per product at source location
  - Over-transfer blocked with clear message: "Available: N at [source]"
  - Success toast via Sonner on completion
  - Auto-close on success
  </action>
