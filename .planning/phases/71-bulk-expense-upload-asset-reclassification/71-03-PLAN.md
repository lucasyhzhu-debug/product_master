## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CSV file -> browser | Untrusted file content rendered in editable table |
| browser -> bulkCreateExpenses | Client sends resolved IDs and trust flag |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-71-09 | Tampering | CSV content in editable cells | mitigate | All cell values rendered as text content (not innerHTML). React's JSX escapes by default. No eval of cell values. |
| T-71-10 | Elevation of Privilege | Trust toggle visibility | mitigate | Frontend hides toggle for non-approvers AND backend re-checks role (T-71-01). Defense in depth. |
| T-71-11 | Denial of Service | Very large CSV upload | accept | Papa Parse handles large files. Table renders all rows (no virtualization). If >500 rows, may be slow but functional. Batch size of 50 prevents mutation timeout. |
</threat_model>
