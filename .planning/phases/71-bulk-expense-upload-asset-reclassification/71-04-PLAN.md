Extend the existing DisposeAssetDialog to support "Reclassify to Expense" disposal type with target account and owner fields.

Purpose: When an asset should be reclassified as an operating expense (e.g., equipment that was capitalized but should have been expensed), the user selects "Reclassify to Expense" in the dispose dialog. The dialog shows the target expense account (auto-mapped from asset category with override) and an owner dropdown. On confirm, the backend creates the expense record and compound JE (from Plan 01).
