## Dark Mode Design System (from src/index.css)

CSS variable mappings — these auto-adapt via .dark class:
- bg-white → bg-card (or bg-background)
- text-gray-600 / text-gray-500 → text-muted-foreground
- text-gray-900 / text-gray-800 → text-foreground
- border-gray-200 / border-gray-100 → border-border
- bg-gray-100 / bg-gray-50 → bg-muted

Do NOT add dark: to semantic tokens (bg-card, text-muted-foreground, etc.) — they already adapt.
ONLY add dark: to hardcoded Tailwind values (bg-white, bg-gray-N, text-gray-N, border-gray-N).

WhatsApp dark mode colors (for TemplateEditor preview only):
- Chat background: dark:bg-[#0d1117]
- Sent bubble: dark:bg-[#005c4b]
- Bubble text: dark:text-[#e9edef]
- Timestamp: dark:text-[#8696a0]
- Double-tick: text-[#53bdeb] (unchanged in both modes)
- "Using sample data" badge: dark:bg-white/10
