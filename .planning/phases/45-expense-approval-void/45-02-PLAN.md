  <action>
    **Extend `src/hooks/convex/useExpenses.ts`** -- add new hooks below existing ones (do NOT modify existing hooks):

    **New query hooks** (all use `useSessionQuery` from `convex-helpers/react/sessions`):
    - `usePendingForApproval()` -- wraps `api.expenses.queries.listPendingForApproval` with empty args `{}`
    - `useRejectionChain(expenseId: Id<"expenses"> | undefined)` -- wraps `api.expenses.queries.getRejectionChain` with skip pattern when expenseId is undefined

    **New mutation hooks** (all use `createMutationHook` factory):
    - `useApproveExpense` -- wraps `api.expenses.mutations.approveExpense` with success: "Expense approved", error: "Failed to approve expense"
    - `useRejectExpense` -- wraps `api.expenses.mutations.rejectExpense` with success: "Expense rejected", error: "Failed to reject expense"
    - `useVoidExpense` -- wraps `api.expenses.mutations.voidExpense` with success: "Expense voided", error: "Failed to void expense"

    **Update `src/hooks/convex/index.ts`** barrel export to include the 5 new hooks.

    **Create `src/components/expenses/FraudFlags.tsx`:**
    - Props: `{ duplicateWarning?: string; lateSubmission?: boolean; rejectionCount?: number }`
    - Renders inline badges (flex row with gap-2):
      - If `duplicateWarning` is truthy: amber outline Badge with AlertTriangle icon + "Duplicate" text, tooltip/title showing the full warning string
      - If `lateSubmission` is true: amber outline Badge with Clock icon + "Late (>14 days)" text
      - If `rejectionCount` > 0: destructive Badge with "Nx rejected" text (e.g., "2x rejected")
    - Returns null if no flags are active
    - Import Badge from `@/components/ui/badge`, AlertTriangle and Clock from `lucide-react`

    **Create `src/components/expenses/ApprovalActions.tsx`:**
    - Props: `{ expenseId: Id<"expenses">; amount: number; onActionComplete?: () => void }`
    - Uses `useAuth()` to get current user role
    - Three action buttons:
      - **Approve** (green): opens a Dialog if amount >= 500K (comment textarea required) or approves directly if < 500K (comment optional). Calls `useApproveExpense`. Button disabled during mutation.
      - **Reject** (red/destructive): always opens a Dialog with required reason textarea. Calls `useRejectExpense`. Button disabled during mutation.
      - **Void** (gray/outline, only visible to admin): opens a Dialog with required reason textarea. Calls `useVoidExpense`. Only rendered when `ctx.user.role === "admin"`.
    - All dialogs use shadcn Dialog + DialogContent + DialogHeader + DialogTitle + DialogFooter
    - Each dialog has a Textarea for comment/reason and Cancel/Confirm buttons
    - After successful action, call `onActionComplete()` if provided
    - Import `formatCurrency` from `@/lib/utils` for threshold messaging
    - Note: The DoA enforcement is at the backend. The frontend just needs to show/hide buttons and require comment when amount >= 500K. The backend will reject unauthorized attempts.

    **Create `src/components/expenses/RejectionChain.tsx`:**
    - Props: `{ expenseId: Id<"expenses"> }`
    - Uses `useRejectionChain(expenseId)` hook
    - If loading (undefined), show Skeleton
    - If empty array, return null (no rejection history)
    - Renders a timeline-style list of prior rejections:
      - Each item shows: rejection reason, rejected date (formatted via `utcToWibDateStr`), and "Revision N" label
      - Visual: vertical line connecting rejection items, using border-left with padding
    - Import from `@/lib/dateUtils` for date formatting
