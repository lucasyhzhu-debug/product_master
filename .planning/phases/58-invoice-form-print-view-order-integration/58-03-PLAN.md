Create the 3-state invoice sidebar card for Order Detail.

**IMPORTANT: Do NOT follow the RESEARCH.md code example for auth handling.** The RESEARCH.md example shows `useAuth()` being called inside InvoiceSidebarCard -- this is wrong. The parent (OrderDetail) handles the `isManagerOrAdmin` role-check and conditionally renders this component. This component focuses on invoice-state logic only.

**Props:**
```typescript
interface InvoiceSidebarCardProps {
  orderId: Id<"orders">;
  orderStatus: string;
}
```

**Hook calls inside the component:**
- `const invoices = useInvoicesByOrder(orderId);` -- reactive query
- `const discardDraft = useDiscardInvoiceDraft();`
- `const navigate = useNavigate();`

**Visibility logic (render null if not applicable):**
```typescript
const INVOICEABLE_STATUSES = new Set(["PaymentReceived", "BeingPrepared", "AwaitingDelivery", "Complete"]);
const canCreate = INVOICEABLE_STATUSES.has(orderStatus);
const canView = canCreate || orderStatus === "Cancelled"; // Cancelled: view only, no create
if (!canView) return null; // Don't render for Draft or AwaitingPayment
if (invoices === undefined) return null; // Loading state
```

**Cancelled order handling (two distinct cases):**
- Cancelled + no invoices (no draft, no finals): `return null` -- card is not rendered at all, since there is nothing to view and creating new invoices is disallowed
- Cancelled + existing invoices: render the finalized state (State 3 below) but WITHOUT the "+ New Invoice" button. Show View/Re-print for existing invoices.

NOTE: The `isManagerOrAdmin` check is NOT needed inside this component. The parent (OrderDetail) handles role-based conditional rendering of this component. The component focuses on invoice-state logic only.

**Derive state:**
```typescript
const draft = invoices.find(inv => inv.status === "draft");
const finals = invoices.filter(inv => inv.status === "final");
const latestFinal = finals[0]; // Already sorted by _creationTime desc
const olderFinals = finals.slice(1);
```

**State 1 -- No Invoice (no draft, no finals):**
```
Card with FileText icon header "Invoice"
"No invoice generated for this order"
[Generate Invoice] button (brand-colored, full-width)
  -> navigates to /orders/${orderId}/invoice
Button hidden if !canCreate (covers Cancelled case, though Cancelled + no invoices returns null above)
```

**State 2 -- Draft Saved (draft exists):**
```
Card with FileText icon header "Invoice"
Badge: "Draft"
"Last edited: {formatDateTimeId(draft.updatedAt)}"
[Continue Editing] button -> navigates to /orders/${orderId}/invoice
[Discard] button (outline, small) -> shows ConfirmDialog, on confirm calls discardDraft.mutate({ invoiceId: draft._id })
```

**State 3 -- Finalized (has at least one final invoice):**
```
Card with FileText icon header "Invoice"
Latest invoice: Badge with invoice number (e.g., "INV-2603-001"), generation date
Buyer info summary (company or name)
[View] button -> navigates to /orders/${orderId}/invoice/${latestFinal.invoiceNumber}
[Re-print] button -> navigates to same URL (print view has print button)
If canCreate: [+ New Invoice] link/button -> navigates to /orders/${orderId}/invoice (creates new draft for revision)

If olderFinals.length > 0:
  Expandable section: "N older invoice(s)"
  On expand: show compact list of older invoice numbers with dates
  Each clickable -> navigates to /orders/${orderId}/invoice/${inv.invoiceNumber}
```

**Styling:**
- Use shadcn `Card`, `CardHeader`, `CardTitle`, `CardContent`, `Button`, `Badge`
- FileText icon from lucide-react in the card header
- ConfirmDialog from `@/components/shared` for discard confirmation
- Use `useState` for older invoices expand/collapse toggle
- Discard confirmation text: "Discard this invoice draft? This cannot be undone."

Import: `useInvoicesByOrder`, `useDiscardInvoiceDraft` from `@/hooks/convex`, `useNavigate` from `react-router-dom`, `formatDateTimeId` from `@/lib/dateUtils`, shadcn Card/Badge/Button, `FileText`/`Plus`/`Printer`/`Eye`/`Trash2` from lucide-react, `ConfirmDialog` from `@/components/shared`.
