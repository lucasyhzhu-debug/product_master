   **Create Form section** (Card):
   - Title: "New Payroll Entry"
   - Fields:
     - Recipient Name: Text input (required) -- who is being paid (contractor name or staff name)
     - Employee Type: Select with options "Contractor" / "Staff" (values: "contractor" / "staff")
     - Frequency: Select with options "Weekly" / "Monthly" (values: "weekly" / "monthly")
     - Amount: Number input (IDR). Use `formatCurrency` from `src/lib/utils.ts` for display
     - Period Start: Date input (HTML date input or shadcn DatePicker). Convert to/from UTC epoch ms using `wibDateStrToUtcMs` / `utcToWibDateStr` from `src/lib/dateUtils.ts`
     - Period End: Date input (same conversion pattern)
     - Description: Textarea
     - Attachment: Optional file upload. Use `usePayrollUploadUrl` to generate signed URL, then upload file and store the fileId. Follow the ReceiptUpload component pattern from expense submission but simplified (no SHA-256 hash needed for payroll)

   **History List section** (Card):
   - Title: "Payroll History"
   - Filter: Employee Type select ("All" / "Contractor" / "Staff") -- pass to `usePayrollEntries` hook
   - Table or card list showing payroll entries:
     - Columns: Payroll # (PAY-MMDD-NNN), Recipient Name, Employee Type (badge), Frequency, Amount (formatCurrency), Period (start - end dates formatted), Description, Status (badge: green "Active" / red "Voided"), Created (date + user name)
     - Sort: newest first (already sorted by query)
   - For active entries: "Void" button that opens a Dialog with:
     - Text: "Void payroll entry {payrollNumber}?"
     - Warning: "This will create a reversing journal entry."
     - Void Reason: Textarea (required)
     - Confirm button: calls `voidPayroll` mutation
   - For voided entries: Show void reason, voided by, and voided date in muted text
   - Empty state: "No payroll entries found" message
