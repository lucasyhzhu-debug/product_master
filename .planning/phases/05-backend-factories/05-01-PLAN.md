**Step 1: Install convex-helpers**

Run `npm install convex-helpers` in the project root.

**Step 2: Create `convex/lib/functions.ts`**

Create the auth wrapper file with these exports:

1. `protectedMutation` -- uses `customMutation` from `convex-helpers/server/customFunctions` with:
   - `args: SessionIdArg` from `convex-helpers/server/sessions` (adds `sessionId: v.string()` to all wrapped mutations)
   - `input` function that: receives `(ctx, { sessionId }, { roles }: { roles: UserRole[] })` as metadata parameter
   - Calls `getSessionUser(ctx, sessionId)` from `./auth`
   - Throws `ConvexError("Unauthorized")` if: user is null, user.isActive is false, or `!roles.includes(user.role as UserRole)`
   - Returns `{ ctx: { ...ctx, user }, args: {} }` so handlers get `ctx.user` typed as `Doc<"users">`
   - Generic "Unauthorized" error only -- no role details per locked decision

2. `protectedQuery` -- same pattern using `customQuery` from convex-helpers

3. `publicMutation` -- re-export of `mutation` from `../_generated/server`
4. `publicQuery` -- re-export of `query` from `../_generated/server`

Import `UserRole` type from `./auth`. Import `Doc` from `../_generated/dataModel`.

**CRITICAL TYPE SAFETY:** The `input` function's return type determines `ctx` in the handler. Ensure the user field is properly typed. If TypeScript cannot infer `ctx.user` as `Doc<"users">`, explicitly annotate the return type of the input function.

**Step 3: Create `convex/lib/queryHelpers.ts`**

Create query helper functions with these exports:

1. `listAll<T extends TableNames>(ctx: QueryCtx, table: T, options?)` -- Lists documents with optional `limit` (default 100), `order` ("asc" | "desc", default "desc"), and `filter` callback. Uses `ctx.db.query(table).order(order).take(limit)` for unfiltered, or `.collect()` + filter + slice for filtered queries.

2. `getById(ctx: QueryCtx, id: GenericId<TableNames>)` -- Simple `ctx.db.get(id)` wrapper. Returns `Doc<T> | null`.

3. `textSearch<T extends TableNames>(ctx: QueryCtx, table: T, searchQuery: string, fields: (keyof Doc<T>)[], limit?)` -- In-memory text search: collects all docs, filters by case-insensitive substring match on specified fields, slices to limit (default 20).

Import types from `../_generated/server` and `../_generated/dataModel`. Use `TableNames` and `Doc` generics for full type safety.

**Step 4: Create `tests/helpers/authTestHelper.ts`**

```typescript
export async function createTestSession(
  t: any,  // TestConvex type from convex-test
  options?: { role?: "kitchen" | "order_staff" | "manager" | "admin"; name?: string }
```

Implementation:
- Generate a unique sessionId: `test-session-${Date.now()}-${Math.random().toString(36).slice(2)}`
- Use `t.run(async (ctx) => { ... })` to insert a user into "users" table with fields: `name` (from options or `"Test ${role}"`), `pinHash` ("test:hash"), `role` (from options or "admin"), `isActive` (true), `failedAttempts` (0), `createdAt` (Date.now())
- Insert a session into "sessions" table with: `userId`, `token` (the sessionId), `expiresAt` (Date.now() + 8 hours), `createdAt` (Date.now())
- Return the sessionId string

This helper will be used by entity tests after mutation wrapping adds auth requirements.

**Step 1: Update `src/main.tsx`**

Add `SessionProvider` from `convex-helpers/react/sessions` wrapping `AuthProvider` inside `ConvexProvider`.

The component tree should be:
```
ConvexProvider
  SessionProvider (storageKey="malo_session_id")
    AuthProvider
      App
```

Import `SessionProvider` from `convex-helpers/react/sessions`. Add the `storageKey="malo_session_id"` prop so it reads/writes the sessionId from that localStorage key.

**IMPORTANT:** If `SessionProvider` does not support a `storageKey` prop (check convex-helpers types during implementation), use the default storage key that convex-helpers uses, and adapt AuthContext to write to that key instead. The critical requirement is: the value stored must be the auth token from the login response.

Keep the fallback `else` branch (when convex is null) as-is.

**Step 2: Update `src/contexts/AuthContext.tsx`**

Add session ID synchronization:

1. Add a constant: `const SESSION_ID_KEY = "malo_session_id";` (must match the SessionProvider storageKey)

2. In the `login` callback, after `localStorage.setItem(AUTH_STORAGE_KEY, JSON.stringify(authSession))`:
   - Add `localStorage.setItem(SESSION_ID_KEY, authSession.token);`
   - This syncs the auth token to the key that SessionProvider reads

3. In the `logout` callback, after `localStorage.removeItem(AUTH_STORAGE_KEY)`:
   - Add `localStorage.removeItem(SESSION_ID_KEY);`

4. In the `useEffect` that loads from localStorage on mount:
   - After setting `setSession(parsed)`, also ensure: `localStorage.setItem(SESSION_ID_KEY, parsed.token);`
   - In the expiry `else` branch, also: `localStorage.removeItem(SESSION_ID_KEY);`

5. In the session validation `useEffect` (where server says session is invalid):
   - Add `localStorage.removeItem(SESSION_ID_KEY);` alongside `localStorage.removeItem(AUTH_STORAGE_KEY);`

This ensures the convex-helpers SessionProvider always has the current auth token value, and `useSessionMutation` / `useSessionQuery` will automatically inject it as `sessionId` in args.
