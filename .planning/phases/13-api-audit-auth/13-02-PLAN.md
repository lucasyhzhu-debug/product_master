Create `docs/apiS/INTEGRATION_REFERENCE.md` as the single reference document for all external API integrations. Read all source files listed in context to extract accurate details. Structure as follows:

**Document structure:**

1. **Overview** -- Table of all integrations: Platform, Data Types, Automation Status, Token Lifespan, Cron Schedule
2. **K3 Mart Integration**
   - Base URL: `https://consapi.k3mart.id/api/v1/`
   - Auth method: Bearer token from email/password login
   - Endpoints used (from config.ts): vendor-profile/get, vendor-profile/get-outlet, product-detail/get, stock-flow/add, stock-flow/list, stock-flow/detail, dashboard/get, stock-flow/cancel
   - Token refresh: Auto-refresh every 12h via cron (`refreshK3MartTokenCron` in platformCredentials/actions.ts)
   - Sync flow: Discover outlets -> snapshot stock -> sync sales revenue
   - SOP: How to set up credentials (settings page), what to do on token failure
3. **GoBiz (GoFood) Integration**
   - Base URL: `https://api.gobiz.co.id/`
   - Auth method: Bearer token from browser cookie paste (access_token + refresh_token)
   - Endpoints: journals/search (transaction-level), cosmo/v1/orders/search (item details)
   - Token refresh cascade (3 methods, in order):
     1. Cookie refresh via micro-app/auth endpoint
     2. Token rotate via analytics-backend/api/auth/token/rotate
     3. API refresh via auth/token/refresh
   - Auto-refresh: Every 30 min via cron (autoRefreshGoBizToken)
   - Revenue sync: 7x daily at WIB business hours (autoSyncGoBizRevenue)
   - Multi-outlet: Crystal (G347061572) + Goldfinch (G293156297) via merchant_id filter
   - SOP: Initial setup (paste from DevTools), what to do when chain breaks (re-paste both tokens)
   - Dashboard API (proxy/63): _msearch endpoint for 5-metric aggregates (documented but not primary sync method)
4. **Internal Orders Sync**
   - Source: Own Convex database (orders table)
   - No external API -- queries confirmed/completed orders and creates externalRevenue records
   - Sync: Manual trigger from settings page
   - Revenue calculation: Uses order totalAmount (gross) and finalTotal (net with discounts)
5. **Schema Reference** -- Key tables: externalOutlets, externalRevenue, externalRevenueItems, externalSyncLogs, externalProductMappings, platformCredentials
6. **Cron Schedule** -- Table of all crons with schedule, action, and purpose
7. **Troubleshooting** -- Common issues and resolutions (token expired, sync fails, missing data)

Reference the existing `docs/apiS/stock in stock out api documentation.md` for K3Mart stock-flow API details. Cross-reference the POC script (`scripts/gobiz_poc.mjs`) for GoBiz API request/response shapes.
