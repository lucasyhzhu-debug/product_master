**IntegrationHealthCard component:**
Create a reusable card component that displays the full health dashboard for one integration. Props: `{ platformId, platformMeta, syncHealth, credentialStatus, isAdmin, onSyncNow, onConfigure, isSyncing }`.

Card layout (per locked decisions):
1. **Header row**: Platform icon + name, status badge (green "Connected", amber "Warning", red "Error"), "Sync Now" button (admin only)
2. **Token status section** (for k3mart and gobiz only):
   - Status: "Active" / "Expired" / "No token"
   - If active and tokenExpiresAt is set: Live countdown "Token expires in Xm, next refresh in Ym"
   - Token countdown: Calculate from `tokenExpiresIn` (from credential status). Next refresh: `30 - ((Date.now() - lastRefreshAt) / 60000)` minutes
   - Use `useEffect` + `setInterval` (every 30 seconds per Claude's discretion) to update countdown
   - "Configure" button (admin only) opens the platform-specific dialog
3. **Last sync row**: "Last synced X min ago" with status icon (check/x), error message inline if failed (per decision: inline, no expandable section)
4. **Sync history** (last 24h): Scrollable list of sync log entries. Each entry shows:
   - Timestamp (relative: "2h ago")
   - Status badge (success/error/started)
   - Data summary: "X products synced" using `productsCount` from sync log
   - Duration: "took Xs" from `durationMs`
   - For errors: error message inline next to status badge
   - Use a max-height div with overflow-y-auto (Claude's discretion for scroll pattern)

Use shadcn/ui components: Card, Badge, Button, ScrollArea. Use Lucide icons: CheckCircle2, XCircle, AlertTriangle, RefreshCw, Clock, Settings2.

Style with Tailwind following existing brand patterns (teal accents, dark mode support). Status badges: green for success, red for error, amber for warning/stale.
