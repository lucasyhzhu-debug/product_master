   ```typescript
   interface VoidReasonDialogProps {
     title: string;
     description: string;
     open: boolean;
     onOpenChange: (open: boolean) => void;
     onConfirm: (reason: string) => Promise<void>;
     confirmLabel?: string;   // default: "Void Entry"
     confirmingLabel?: string; // default: "Voiding..."
   }
   ```
2. Implement using Dialog, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter from `@/components/ui/dialog`, Textarea from `@/components/ui/textarea`, and Button from `@/components/ui/button`.
3. Internal state: `reason` (string), `isSubmitting` (boolean).

**Error handling behavior (I3 -- critical):**
   - On submit: set `isSubmitting = true`, call `onConfirm(reason)` in a try/catch.
   - On success (promise resolves): reset reason to "", set `isSubmitting = false`, call `onOpenChange(false)` to close dialog.
   - On error (promise rejects): keep dialog OPEN, keep reason text preserved (user can retry or edit), set `isSubmitting = false`. The caller is responsible for showing the error toast in their try/catch around the mutation call.
   - On dialog close via X or overlay click (onOpenChange(false)): reset reason to "".
   - Disable submit button when `reason.trim()` is empty OR `isSubmitting` is true.
