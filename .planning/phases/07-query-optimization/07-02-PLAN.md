**Add `invalidateMenuProductCosts` to `convex/lib/costInvalidation.ts`:**

1. Add a new `internalMutation` called `invalidateMenuProductCosts`:
   - Args: `{ componentTypeId: v.id("componentTypes") }`
   - Logic:
     a. Find all `menuProductComponents` with matching `componentTypeId` using `by_component_type` index
     b. Get unique `menuProductId` values from the results
     c. For each affected menuProduct:
        - Fetch all its `menuProductComponents` via `by_menu_product` index
        - Fetch each component's `componentType` document
        - Calculate production-only COGS: `sum of (unitCostIdr * quantity)` for components where `category === "production"` ONLY (packaging excluded per user decision)
        - Patch the menuProduct with `{ unitCost: productionCost, unitCostStaleAt: undefined }` — clearing the stale marker
   - Import `internal` from `../_generated/server` for the `internalMutation` export

**Trigger cascade from `componentTypes/mutations.ts::update()`:**

2. In the `update` mutation handler, after the existing `ctx.db.patch(args.id, updates)` call:
   - Check if `args.unitCostIdr !== undefined` (cost is being changed)
   - If so, first mark affected menuProducts as stale:
     a. Query `menuProductComponents.by_component_type` for the component
     b. Get unique menuProductIds
     c. Patch each menuProduct with `{ unitCostStaleAt: Date.now() }`
   - Then schedule recalculation: `await ctx.scheduler.runAfter(0, internal.lib.costInvalidation.invalidateMenuProductCosts, { componentTypeId: args.id })`
   - Import `internal` from `../_generated/server`

The existing `menuProducts/mutations.ts::create()` and `update()` use `calculated.totalCost` for `unitCost`. Change: the `create` and `update` mutations should use `calculated.breakdown.production` (not `calculated.totalCost`) when setting `unitCost`. The function itself stays the same (it already returns breakdown). Just change the callers:
   - In `create` handler (line ~166): Change `unitCost = calculated.totalCost` to `unitCost = calculated.breakdown.production`
   - In `update` handler: Same change where unitCost is set from calculated result

4. Add `recalculateAllCosts` mutation to `menuProducts/mutations.ts`:
   - Args: `{ token: v.string() }`
   - Auth: `requireRole(ctx, args.token, ["admin"])`
   - Logic (following research example 4 closely):
     a. Fetch all menuProducts
     b. For each product, fetch its menuProductComponents via `by_menu_product` index
     c. For each component, fetch componentType to get `unitCostIdr` and `category`
     d. Calculate production-only cost: `sum of (unitCostIdr * quantity)` for `category === "production"` components
     e. Compare with existing `product.unitCost`
     f. If different (or unitCost was undefined), patch with new value and clear `unitCostStaleAt`
     g. Collect results: `{ productId, name, oldCost, newCost, delta }` for changed products
   - Return the results array
