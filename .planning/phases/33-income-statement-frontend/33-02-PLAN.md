**Confidence Indicator Component (inline in FinancialStatement.tsx):**

Create a `ConfidenceIndicator` component:

```tsx
import { Calculator, AlertTriangle } from "lucide-react";
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip";

type Confidence = "exact" | "calculated" | "inferred" | "missing";

function ConfidenceIndicator({ level }: { level: Confidence }) {
  if (level === "exact") return null; // No indicator for exact — clean number

  if (level === "calculated") {
    return (
      <Tooltip>
        <TooltipTrigger asChild>
          <Calculator className="h-3 w-3 inline ml-1 text-muted-foreground" />
        </TooltipTrigger>
        <TooltipContent>
          <p>Calculated: derived from BOM ingredient costs</p>
        </TooltipContent>
      </Tooltip>
    );
  }

  if (level === "inferred") {
    return (
      <Tooltip>
        <TooltipTrigger asChild>
          <span className="text-muted-foreground ml-0.5 text-xs">~</span>
        </TooltipTrigger>
        <TooltipContent>
          <p>Inferred: estimated from stock delta or indirect data</p>
        </TooltipContent>
      </Tooltip>
    );
  }

  // missing
  return (
    <Tooltip>
      <TooltipTrigger asChild>
        <AlertTriangle className="h-3 w-3 inline ml-1 text-amber-500" />
      </TooltipTrigger>
      <TooltipContent>
        <p>Missing: data source unavailable or product unmapped</p>
      </TooltipContent>
    </Tooltip>
  );
}
```

**Confidence rendering rules (from CONTEXT.md locked decisions):**
- `exact`: No indicator (clean number)
- `calculated`: Small calc icon (Calculator from lucide)
- `inferred`: `~` prefix before the number
- `missing`: Dash `--` with warning icon (AlertTriangle) instead of `Rp 0`
- Confidence shown at channel-total level only (not repeated on every cell in the row)
- When `confidence === "inferred"`, prefix the amount with `~` (e.g., `~ Rp 1.000.000`)
- When `confidence === "missing"` for COGS, display `-- ⚠` instead of `Rp 0` — visually distinct from actual zero cost

**Update PLRow to render confidence:**
- Add confidence indicator next to the amount in the "This Week" column
- For `inferred`: prepend `~` before the formatted currency
- For `missing` COGS: render `--` with AlertTriangle icon instead of `formatCurrency(0)`

**Delta rendering polish:**
Ensure delta column renders correctly for all P&L rows:
- Revenue rows: standard colors (green = up, red = down)
- Deduction rows: `invertColor` = true (increase in deductions is bad, show red for positive delta)
- COGS rows: `invertColor` = true (increase in COGS is bad)
- Gross profit row: standard colors
- Gross margin: show percentage point difference (e.g., "+0.2pp" or "-1.3pp"), not percentage change
- When `delta.percent` is null (previous was 0): show "New"
- When both values are 0: show "0%" with dash
