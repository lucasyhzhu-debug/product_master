**1. WeekNav.tsx** -- Reuse the `WeekNavigator` pattern from K3Mart cockpit.

- Left/right arrow buttons shift view by 7 days
- "Today" button centers on current week
- Display: "Feb 17 - Feb 23, 2026" format

**2. PlannerCell.tsx** -- Extend the `EditablePlannerCell` pattern.
- Props: `{ value: number; suggestedValue?: number; isReadOnly: boolean; isFaded?: boolean; isPast: boolean; onSave: (qty: number) => void }`
- Editable number input when not read-only and not past
- **Auto-save on blur** (call onSave when input loses focus, 300ms debounce like K3Mart)
- Read-only cells: show value with muted background
- Past cells: slightly dimmed styling (bg-muted/50)
- Faded cells (direct order production-start day): opacity-40, italic
- Empty: show "--" placeholder
- Keyboard: Enter confirms, Escape reverts, Tab moves to next cell
- Visual: compact cell (min-width 48px), text-center, border

**3. CapacityBar.tsx** -- Segmented capacity visualization (per research code example).
- Props: `{ segments: { channelKey: string; quantity: number; color: string }[]; capacity: number }`
- CSS flexbox bar with colored segments proportional to each channel's quantity
- Bar width scales relative to capacity (100% = at capacity)
- Over-capacity: bar extends beyond 100% with red indicator dot
- Show total number below/above the bar (e.g., "185/200")
- Tooltip on hover showing per-channel breakdown

**4. ChannelGroup.tsx** -- Collapsible channel section.
- Props: `{ channelKey: string; displayName: string; color: string; isEditable: boolean; outlets: OutletData[]; dates: string[]; todayStr: string; dailyTotals: Record<string, number>; onSaveCell: SaveCellFn; defaultExpanded?: boolean }`
- Channel header row: colored left border, channel name, expand/collapse chevron, subtotal row (sum per day across all outlets)
- Default: expanded. Click header to collapse (shows only subtotal row)
- Use Framer Motion for smooth expand/collapse animation (AnimatePresence + motion.div)
- When expanded: render outlet rows, each outlet has its product rows
- Outlet sub-header: indented, outlet name
- Product rows: most indented, product name + 7 day cells
- For direct orders channel: outlet name = order number + customer name, show production window visual (faded cell at dueDate-2, solid at dueDate)
- Subtotal row: bold, sum of all outlet/product values per day
