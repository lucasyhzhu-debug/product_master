  <action>
    Replace the stub page at `src/pages/ExpenseAnalytics.tsx` with the full analytics dashboard.

    **Period Selection (month + custom mode, no weekly):**
    - Default to current month (use `getCurrentWibMonth()` pattern from `useFinancials.ts`)
    - Two modes: "month" and "custom" (no "week" -- expense analytics is monthly granularity)
    - Month mode: navigation arrows (prev/next month) + "Today" button to reset, label shows "March 2026" format
    - Custom mode: two date inputs (start/end) using `<input type="date">` with WIB conversion
    - Compute `periodStart` and `periodEnd` from selected mode using `wibMidnightToUtc` (inline the function as done in useFinancials.ts -- `Date.UTC(year, month, day, -7, 0, 0, 0)`)
    - Period picker row at top of page below PageHeader

    **Layout (responsive grid):**
    ```
    Desktop (lg:grid-cols-3):
    Row 1: [OpExSummary] [PendingMetrics] [MonthlyTrend]
    Row 2: [SpendByEmployee (col-span-2)] [FraudFlags]

    Mobile (grid-cols-1):
    Stacked vertically in order: OpExSummary, PendingMetrics, MonthlyTrend, SpendByEmployee, FraudFlags
    ```

    **Data flow:**
    - Call `useOpExAnalytics(periodStart, periodEnd)` for OpEx data
    - Call `useExpenseMetrics(periodStart, periodEnd)` for employee/pending data
    - Call `useFraudFlags()` for fraud flags (no period -- uses fixed windows)
    - Pass data to sub-components. Each handles its own loading/empty state.

    **Page structure:**
    ```tsx

          <SpendByEmployeeCard data={metricsData} />

      </div>
    ```
