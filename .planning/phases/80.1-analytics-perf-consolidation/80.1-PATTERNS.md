## Shared Patterns

### S-01: Parallel-load + pure-reducer composite query (BACKEND)

**Source:** `convex/reports/incomeStatement.ts` lines 521-700
**Apply to:** All 3 new snapshot queries in `convex/reports/unitEconomics.ts`

**Formula:**
1. `const [a, b, c, ...] = await Promise.all([ctx.db.query(...), ...]);` — load everything at the top of the handler
2. Build lookup Maps from loaded data
3. Call pure reducers with pre-loaded data + lookups; never re-touch `ctx.db` in reducers
4. Return composite object

This is THE pattern to enforce. If a reducer needs additional data, the loader must fetch it first.

### S-02: Shadcn Card-based chart frame (FRONTEND)

**Source:** `src/components/ui/card.tsx` + the current `src/components/analytics/*.tsx` widgets
**Apply to:** Every `ChartFrame`-wrapped widget (R1 + R2 enforcement)

**Formula:**
1. `<Card>` outer shell from `@/components/ui/card`
2. `<CardHeader><CardTitle>{title}</CardTitle></CardHeader>` title slot
3. `<CardContent><div data-chart-frame style={{height}}>{children}</div></CardContent>` sized body slot
4. `loading` prop renders `animate-pulse rounded bg-muted` skeleton INSIDE the fixed-size frame (prevents layout shift)
5. NEVER inline `<Card className="h-64 animate-pulse" />` for loading state — always go through `ChartFrame loading` so the skeleton matches the final rendered height

### S-03: Loading-state sentinel (FRONTEND)

**Source:** `src/hooks/convex/useAnalytics.ts` + `src/components/analytics/*.tsx` (all widgets)
**Apply to:** All selector hooks + all migrated widgets

**Formula:**
- Hooks return `undefined` while loading (optional-chain propagates `undefined` from snapshot)
- Widget: `const data = useSkuSnapshot()?.unitsByTypeStackedBars;` → `if (data === undefined) return <ChartFrame title="..." loading>{null}</ChartFrame>`
- Do NOT throw or return `null` directly; `ChartFrame` needs to own the skeleton sizing

### S-04: Convex query dedup — no special orchestration needed

**Source:** Convex `useQuery` behavior, documented in PRD Task 13 post-rewrite
**Apply to:** `useAnalytics.ts` snapshot + selector pattern

Convex dedupes identical `useQuery(api.x.y, args)` calls within the same React tree. 13 widgets calling `useKpiAndChannelSnapshot()?.<field>` subscribe to ONE underlying snapshot. Do NOT add memoization, context providers, or manual deduping — trust Convex.

### S-05: Route-level lazy + Suspense (FRONTEND)

**Source:** `src/App.tsx` + `src/lib/lazyWithPreload.ts`
**Status:** ALREADY APPLIED to `/analytics`. Task 22 is a verification step, not a code change.

```typescript
// src/lib/lazyWithPreload.ts lines 11-17
export function lazyWithPreload<T extends React.ComponentType<unknown>>(
  factory: () => Promise<{ default: T }>
): PreloadableComponent<T> {
  const Component = lazy(factory) as PreloadableComponent<T>;
  Component.preload = () => { factory(); };
  return Component;
```
