# Phase 80.1 Plan 02: Chart Primitives + Widget Migration Summary

One-liner: Wave B frontend refactor — extracted shared chart primitives (ChartFrame, ChartTooltip, CHART_MARGIN, X_AXIS_STRING_LABEL_PROPS, truncateWithTooltip, formatCurrencyCompact), rewrote useAnalytics as 3 snapshot hooks + 12 backward-compatible selectors, migrated 8 Recharts widgets to enforce R1 (no-clip, hover-reveal) and R2 (WCAG-AA dark-popover tooltips with swatch-only category colors) through primitives.

## What Was Built

### Chart primitives (`src/lib/chartPrimitives.tsx`)

| Export | Kind | Purpose |
|--------|------|---------|
| `truncateWithTooltip(label, max=22)` | helper | Returns `{display, full}` — ellipsizes over limit, preserves full string for tooltip reveal |
| `formatCurrencyCompact(value)` | helper | Indonesian-compact currency: `Rp 15rb`, `Rp 1,2jt`, `Rp 1,5M`, `Rp 0`, `Rp 999` |
| `ChartTooltip` | component | Applies `bg-popover` + `text-popover-foreground` classes; category colors render as `data-tooltip-swatch` squares, value text has `data-tooltip-value` + no inline color |
| `ChartFrame` | component | Card + CardHeader + CardContent with fixed-height body (default 320px); loading renders `data-chart-skeleton`; error renders destructive-text message |
| `CHART_MARGIN` | const | `{top: 16, right: 48, bottom: 64, left: 64}` — 64px bottom/left prevents label clipping |
| `X_AXIS_STRING_LABEL_PROPS` | const | `{angle: -35, textAnchor: "end", interval: 0, height: 80, tick: {fontSize: 11}}` — spread onto string `<XAxis>` so every tick is visible |

### Hook rewrite (`src/hooks/convex/useAnalytics.ts`)

**3 snapshot hooks** (Convex dedupes identical useQuery calls across the React tree):

| Hook | Returns snapshot from |
|------|-----------------------|
| `useKpiAndChannelSnapshot()` | `api.reports.unitEconomics.kpiAndChannelSnapshot` |
| `useTimeSeriesSnapshot()` | `api.reports.unitEconomics.timeSeriesSnapshot` |
| `useSkuSnapshot()` | `api.reports.unitEconomics.skuSnapshot` |

**12 backward-compatible selector hooks** (preserves every legacy hook name — widgets keep working):

`useKpiSummary`, `useChannelEconomics`, `useChannelMomentum`, `useByWeekday(mode)`, `useRollingTrend`, `useDayHourHeatmap`, `useVolumeByType(g)`, `useTypeMixOverTime(g)`, `useSkuPareto(topN)`, `useSkuChannelMatrix(topN)`, `useUnitsPerTxnByChannel`, `useAovByChannel`

No sparkline-specific selector is added — sparkline data is already in `channelMomentum.channels[].{revenueSpark, unitsSpark, aovSpark}`.

### Widget migrations (8 Recharts widgets — all now using shared primitives)

| Widget | Data source | Notable |
|--------|-------------|---------|
| `SkuParetoChart` | `useSkuPareto(topN)` | R1/R2 screenshot subject — migrated FIRST. `truncateLabel` helper DELETED; replaced with `truncateWithTooltip(name, 22)`. Tooltip `labelFormatter` reveals `fullName`. Per-row cumulative% recomputed client-side over the sliced top-N |

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocker] `useByWeekday` signature preservation**
- **Found during:** Task 16 (WeekdayDualAxisChart migration)
- **Issue:** Plan Task 13 listed `useByWeekday = () => useTimeSeriesSnapshot()?.byWeekday` as a zero-arg selector. But `WeekdayDualAxisChart` calls `useByWeekday(mode)` with `mode: "weekday" | "rolling"` and the `timeSeriesSnapshot` carries BOTH `byWeekday` and `byWeekdayRolling` fields. Dropping the mode parameter would silently break the mode toggle.
- **Fix:** `useByWeekday(mode = "weekday")` dispatches between `snap.byWeekday` and `snap.byWeekdayRolling`. Total backward-compat selectors are effectively 12, not 11 — the plan's 11-count excluded the mode-dispatch variant.
- **Files modified:** `src/hooks/convex/useAnalytics.ts`
- **Commit:** 85c70438 (original rewrite), carried into 6950d1c1

**2. [Rule 2 - Critical functionality] `AovByChannel` and `UnitsPerTxnByChannel` compute aggregates client-side**
- **Found during:** Task 17 (AovByChannel + UnitsPerTxnByChannel migration)
- **Issue:** The new `useAovByChannel()` / `useUnitsPerTxnByChannel()` selectors return raw `channelEconomics` rows (fields: `gross, discount, fees, net, units, orderCount, takePct, revPerUnit`). The legacy wrappers returned precomputed `grossAov`/`netAov` and `unitsPerTxn` fields respectively.
- **Fix:** Both widgets now compute the per-row aggregates client-side from the channelEconomics totals (`gross / orderCount`, `net / orderCount`, `units / orderCount`). Zero guards preserve legacy semantics. No backend change needed — matches the legacy wrapper math exactly.
- **Files modified:** `src/components/analytics/AovByChannel.tsx`, `src/components/analytics/UnitsPerTxnByChannel.tsx`
- **Commit:** f798c712

### Plan Deviations (scope)

**3. [Scope] RollingTrendChart skips `X_AXIS_STRING_LABEL_PROPS`**
- **Original:** Plan Task 16 template says "apply `X_AXIS_STRING_LABEL_PROPS` to string X-axis" but notes "if X-axis is a time axis, use numeric defaults".
- **Fix chosen:** RollingTrendChart's X-axis is a dense daily time-series (30+ ticks typical). Forcing `interval: 0` with `angle: -35` would make every tick label overlap. Keeps Recharts auto-interval; applies only `tick: {fontSize: 11}`. Still uses `CHART_MARGIN` + `ChartFrame`.

**4. [Scope] WeekdayDualAxisChart conditionally applies `X_AXIS_STRING_LABEL_PROPS`**
- Weekday mode: 7 ticks, fits easily — applies full `X_AXIS_STRING_LABEL_PROPS` (rotation, interval=0, height=80).
- Rolling mode: up to 28 daily ticks — applies only `tick: {fontSize: 11}`, lets Recharts auto-skip.

**5. [Scope] RevPerUnitChart keeps a custom multi-line tooltip (not `ChartTooltip`)**
- **Original:** Plan Task 16 pseudocode uses `<Tooltip content={<ChartTooltip valueFormatter={formatCurrencyCompact} />} />` for every chart.
- **Fix chosen:** RevPerUnitChart's legacy tooltip shows 3 rows (Rev/Unit, Gross+Net+Take%). The single-value `ChartTooltip` can't express this richness without forcing awkward multi-entry payload hacks. Kept the custom tooltip but applied R2 token classes (`bg-popover`, `text-popover-foreground`, `data-chart-tooltip`, `data-tooltip-value`) inline. Same pattern used in `RollingTrendChart` and `WeekdayDualAxisChart`.

**6. [Scope] KpiRow + ChannelSparklineTable + TakeRateTable untouched**
- Task 18 audited all three for defects in (a) hardcoded `Rp` format, (b) fixed-color tooltip, (c) truncated text without hover reveal. None found:
  - KpiRow uses `formatCurrency` (Intl id-ID locale) — not hardcoded
  - ChannelSparklineTable has `.truncate` on channel name BUT already has `title={r.channel}` (hover reveal via title attribute)
  - TakeRateTable uses `formatCurrency`; no tooltip; no truncation
- Per plan Task 18 note: "If none of (a), (b), (c) are found, this task ends with ZERO file changes — that is a valid and expected outcome." No commit made for Task 18.
