**Create `convex/grabfoodOrders/mutations.ts`:**

1. `upsertOrder` (internalMutation):
   - Args: `{ order: v.any(), syncLogId: v.id("externalSyncLogs"), outletId: v.optional(v.id("externalOutlets")) }`
   - Dedup: Query `grabfoodOrders` by index `by_order_id` for `order.orderID`. If exists and `orderState` changed, patch. If exists and unchanged, return existing ID.
   - Insert new order: Map API fields to schema — `orderID`, `merchantID`, `shortOrderNumber`, `orderState`, `orderTime` (ISO string), `orderTimeMs` (parse to Unix ms), `currency` (string, e.g. "IDR"), `items` (array from API), `price` (object from API), `rawJson` (JSON.stringify full order), `syncLogId`, `outletId`, `createdAt: Date.now()`.
   - **IDR handling:** Store price values as-is. Add comment: `// IDR exponent=0: prices are whole rupiah, no division needed`
   - Revenue bridge: After insert, create `externalRevenue` record:
     - `source: "grabfood"` (uses schema.ts externalSource validator — NOT the old 3-literal sourceValidator)
     - `outletId` from args
     - `revenueGross: order.price?.subtotal ?? 0`
     - `revenueNet: subtotal - (grabFundPromo + merchantFundPromo + basketPromo)` (each defaults to 0)
     - `periodStart: orderTimeMs`, `periodEnd: orderTimeMs`
     - `dataOrigin: "api_revenue"`, `confidence: "exact"`
     - `externalTransactionId: order.orderID` (for dedup)
     - `transactionDate: orderTimeMs`, `transactionType: "sales"`
     - `syncLogId`
   - Patch order with `linkedRevenueId` after revenue insert.
   - Return order doc ID.

2. `upsertOrderBatch` (internalMutation):
   - Args: `{ orders: v.array(v.any()), syncLogId: v.id("externalSyncLogs"), outletId: v.optional(v.id("externalOutlets")) }`
   - Loops through orders array, calls the same upsert logic inline (not via separate mutation call — avoid nested runMutation).
   - Returns `{ inserted: number, updated: number, skipped: number }`.
   - Purpose: Batch processing to reduce mutation call count from sync action.

**Create `convex/grabfoodOrders/queries.ts`:**

1. `listOrders` (query):
   - Args: `{ token: v.string(), outletId: v.optional(v.id("externalOutlets")), fromMs: v.optional(v.number()), toMs: v.optional(v.number()), limit: v.optional(v.number()) }`
   - Auth: `requireRole(ctx, args.token, ["manager", "admin"])`
   - Query by `by_outlet` index if outletId provided, otherwise by `by_time` index.
   - Filter by date range if fromMs/toMs provided.
   - Order descending by `orderTimeMs`.
   - Limit to `args.limit ?? 100`.
   - Return orders array.

2. `getOrderStats` (query):
   - Args: `{ token: v.string(), outletId: v.optional(v.id("externalOutlets")) }`
   - Auth: `requireRole(ctx, args.token, ["manager", "admin"])`
   - Return `{ totalOrders: number, lastSyncedAt: number | null }` by counting orders and finding max `createdAt`.

**Add to `convex/integrations/grabfood/adapter.ts`:**

3. `syncOrders` (action):
   - Args: `{ token: v.string(), merchantID: v.string(), outletId: v.optional(v.id("externalOutlets")), fromDate: v.optional(v.string()), toDate: v.optional(v.string()) }`
   - Auth: validate token via `ctx.runQuery(internal.platformCredentials.queries.validateAdminToken, { token: args.token })`
   - Create sync log via `ctx.runMutation(internal.externalData.mutations.createSyncLog, { source: "grabfood", syncType: "manual", status: "started", timestamp: Date.now(), outletId: args.outletId })`
   - **Note:** `createSyncLog` internal mutation in externalData/mutations.ts may need the sourceValidator updated to include "grabfood". If it does, either update that validator to use `externalSource` from schema.ts, OR insert the sync log directly in a new internal mutation in grabfoodOrders/mutations.ts. Choose the cleaner option at implementation time.
   - Determine fromDate: if not provided, query `externalSyncLogs` for last successful sync for this outlet to get `lastSyncedAt` timestamp. Format as ISO date string. If no prior sync, default to 7 days ago.
   - Determine toDate: default to now if not provided.
   - Paginate: `let page = 1; let hasMore = true;`
   - While loop: build URL params `{ merchantID, page, fromDate, toDate }`, call `grabRequest(accessToken, "GET", endpoints.ordersList + "?" + params)`.
   - For each page: collect orders into a batch array (up to 50 per batch), then call `ctx.runMutation(internal.grabfoodOrders.mutations.upsertOrderBatch, { orders: batch, syncLogId, outletId })`.
   - Track totalOrders count.
   - When `data.more !== true`, stop pagination.
   - Update sync log: `status: "success"`, `productsCount: totalOrders`, `durationMs`.
   - On error: update sync log with `status: "error"`, `errorMessage`.
   - Return `{ success: true, ordersCount: totalOrders }` or `{ success: false, error: message }`.
