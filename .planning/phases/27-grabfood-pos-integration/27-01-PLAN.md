<task type="auto">
  <name>Task 1: API Discovery — Test All Endpoint Categories</name>
  <files>convex/integrations/grabfood/adapter.ts</files>
  <action>
Create a temporary `discoverApi` action in adapter.ts that exercises the GrabFood Partner API with current credentials. The action must:

1. **Token resolution:** Call `resolveToken(ctx)` — confirm it returns a valid Bearer token. Log the token prefix and expiry.

2. **Order list endpoint:** Call `GET /partner/v1/orders?merchantID={ID}` with a recent date range (last 7 days). Log:
   - HTTP status code
   - Number of orders returned
   - `more` field value (pagination indicator)
   - Full raw JSON of the first order (for field mapping)
   - Confirm `currency.exponent` value for IDR

3. **Store status endpoint:** Call `GET /partner/v1/merchants/{merchantID}/store/status`. Log:
   - HTTP status code
   - Full response body (status, pauseUntil, etc.)

4. **Menu batch endpoint:** Call `PUT /partner/v1/batch/menu` with an empty `menuEntities` array to test accessibility (or GET menu if PUT with empty body returns error). Log:
   - HTTP status code
   - Response body

5. **MerchantID discovery:** If the API provides a merchant listing endpoint, use it. Otherwise, test with known merchantIDs from the GrabFood developer portal. Document which merchantIDs map to Crystal, Goldfinch, Tamtem.

6. **Return structured results:** The action should return a JSON object with all findings for each endpoint category: `{ token: {...}, orders: {...}, storeStatus: {...}, menu: {...}, merchantIDs: [...] }`.

Run the action via Convex dashboard (Functions tab → integrations/grabfood:discoverApi) or via a quick test script. Log ALL raw responses to console for field mapping analysis.

**Important:** This action is temporary — it will be removed after discovery is complete. Mark it clearly with `// TEMPORARY: Remove after API discovery`.

**If credentials fail:** Stop immediately. Document the error in SUMMARY.md with "GATE: API access failed — phase deferred" and do not proceed to Task 2.
