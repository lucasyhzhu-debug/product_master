  <files></files>
  <action>
**IMPORTANT:** This task modifies git history and force-pushes. It is destructive and irreversible.

**Step 1: Create mirror clone**

Clone a mirror copy to a temporary directory. Do NOT run filter-repo on the working copy.

```bash
cd "D:/Claude/Product Manager"
git clone --mirror https://github.com/lucasyhzhu-debug/product_master.git product_master_scrub.git
cd product_master_scrub.git
```

**Step 2: Run git-filter-repo to remove env files**

Remove all three env files from every commit in history:

```bash
python -m git_filter_repo --invert-paths --path .env --path .env.local.production --path .env.local.testing --force
```

The `--force` flag is needed because git-filter-repo may warn about the mirror clone. This removes these three files from every commit where they existed.

Verify the scrub worked:
```bash
git log --all --diff-filter=A -- .env .env.local.production .env.local.testing
```
This should return empty (no commits adding these files).

**Step 3: Force-push to origin**

Push all rewritten refs back to GitHub:

```bash
git push --force --all
git push --force --tags
```

**Step 4: Clean up mirror clone**

```bash
cd "D:/Claude/Product Manager"
rm -rf product_master_scrub.git
```

**Step 5: Re-sync working copy**

The working copy's history is now diverged from remote. Reset it:

```bash
cd "D:/Claude/Product Manager/product_master"
git fetch origin
git reset --hard origin/main
```

Note: This will discard any uncommitted local changes. Plan 02-01's commits will be preserved (they were pushed before the scrub). The env files will remain on disk (they're gitignored now) but won't be in git history.

**Step 6: Verify working copy is clean**

```bash
git status
git log --oneline -5
```

Confirm working copy is on main, up to date with origin, and env files are not tracked.
