    **Schema update (convex/schema.ts):**
    - Find the `journalEntries` table `metadata` field (line ~1781)
    - Add `templateType: v.optional(v.string())` to the metadata object so it becomes:
      ```
      metadata: v.optional(v.object({
        receiptUrl: v.optional(v.string()),
        templateType: v.optional(v.string()),
      ```

    **Journal engine type update (convex/lib/journalEngine.ts):**
    - Update `CreateJournalEntryParams.metadata` type to include `templateType?: string`:
      ```
      metadata?: { receiptUrl?: string; templateType?: string };
      ```

    **Pure helpers + create mutation (convex/manualJournal/mutations.ts):**
    - Export `TEMPLATE_TYPES` array as const with 6 values: "equipment_purchase", "loan_repayment", "dividend_payment", "capital_injection", "receive_loan", "tax_payment"
    - Export `TemplateType` type derived from array
    - Export `TEMPLATES` record mapping each TemplateType to `{ debit: string; credit: string }`:
      - equipment_purchase: { debit: "1500", credit: "1100" }
      - loan_repayment: { debit: "2500", credit: "1100" }
      - dividend_payment: { debit: "3200", credit: "1100" }
      - capital_injection: { debit: "1100", credit: "3100" }
      - receive_loan: { debit: "1100", credit: "2500" }
      - tax_payment: { debit: "2400", credit: "1100" }
    - Export pure `validateTemplateType(type: string): asserts type is TemplateType` -- throws if not in TEMPLATE_TYPES
    - Export pure `validateManualJournalAmount(amount: number): void` -- throws if <= 0 or not integer
    - `create` protectedMutation with roles ["manager", "admin"], args: { templateType: v.string(), date: v.number(), amount: v.number(), description: v.string() }
      - Calls validateTemplateType and validateManualJournalAmount
      - Looks up template from TEMPLATES constant
      - Looks up debit and credit accounts via `ctx.db.query("accounts").withIndex("by_code", q => q.eq("code", template.debit)).first()`
      - Throws clear error if account not found: `System account ${code} not found. Run accounts:seedDefaults.`
      - Calls `createJournalEntryWithLines(ctx, { date: args.date, description: args.description, sourceType: "manual", createdBy: ctx.user._id, lines: [buildDebitLine(debitAccount._id, args.amount), buildCreditLine(creditAccount._id, args.amount)], metadata: { templateType: args.templateType } })`

    **listByPeriod query (convex/manualJournal/queries.ts):**
    - `listByPeriod` protectedQuery with roles ["manager", "admin"], args: { periodStart: v.number(), periodEnd: v.number() }
      - Queries `journalEntries` with `by_source` index: `eq("sourceType", "manual")`
      - Post-filters: `date >= periodStart && date < periodEnd && metadata?.templateType`
      - For each filtered entry, fetches lines via `by_journal_entry` index
      - For each line, fetches account name via `ctx.db.get(line.accountId)`
      - Returns array sorted by date descending, each entry including: _id, entryNumber, date, description, metadata.templateType, lines with account names, total amount (sum of debit amounts)

    **TDD tests (convex/manualJournal/__tests__/mutations.test.ts):**
    - Import pure functions from mutations.ts
    - Test validateTemplateType with valid types, invalid type, empty string
    - Test validateManualJournalAmount with positive integer, zero, negative, fractional
    - Test TEMPLATES has all 6 entries with expected debit/credit codes
    - Test TEMPLATE_TYPES has length 6
