# Phase 29.1: Test Suite Repair

## Goal
Fix all 56 pre-existing test failures across 15 test files (7 Convex unit test files + 8 E2E spec files) to establish a clean green baseline before Phase 30.

## Background
Test failures accumulated across phases 19-29 as backend modules were restructured/removed without updating corresponding tests. The crons were simplified, K3Mart queries were refactored, and Playwright E2E specs were incorrectly included in the Vitest runner.

## Current State
- **56 individual test failures** across 7 Convex test files
- **8 E2E suite-level errors** (Playwright tests in Vitest)
- **636 tests passing** (no regressions in working tests)
- **Root causes identified** in `.planning/debug/test-suite-failures.md`

## Failure Categories

| # | Category | Files | Failures | Root Cause |
|---|----------|-------|----------|------------|
| 1 | Deleted modules | recipes.test.ts, tags.test.ts, products.test.ts | 45 | Tests reference `convex/recipes/`, `convex/tags/`, `convex/products/`, `convex/packaging/` — all removed |
| 2 | K3Mart behavior | k3martCockpit.test.ts | 5 | Error messages changed, `getOutletStockSummary` became `getOutletStockSummaryInternal`, return shapes changed |
| 3 | Cron strings | gobizAdapter.test.ts, gofoodDepot-edge.test.ts | 2 | `crons.ts` was simplified to empty (no active crons), tests expect specific cron names |
| 4 | Voucher logic | voucherHandling.test.ts | 2-3 | 100% discount validation removed from mutation, tests still expect rejection |
| 5 | E2E in Vitest | 8 files in tests/e2e/ | 8 suites | Playwright `test.describe()` not compatible with Vitest runner |

## Success Criteria
- [ ] `npx vitest run` shows 0 failures
- [ ] `npm run build` still passes
- [ ] No passing tests removed (636 baseline maintained or increased)
- [ ] E2E tests properly excluded from Vitest (run separately with Playwright)
