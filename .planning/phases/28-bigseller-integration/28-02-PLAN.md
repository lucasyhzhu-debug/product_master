**Create `src/hooks/convex/useBigSeller.ts`**:

Follow the existing hook pattern in the project (see other hooks in `src/hooks/convex/`).

1. `useBigSellerSyncState()`: Wraps `useQuery(api.integrations.bigseller.queries.getSyncState)`. Returns `{ data: BigSellerSyncState | undefined, isLoading: boolean }`.

2. `useBigSellerOrders(filters?)`: Wraps `useQuery(api.bigsellerOrders.queries.listOrders, { token, ...filters })`. Accepts optional `startDate`, `endDate`, `platform` filters. Uses auth token from `useAuth()`. Returns `{ data, isLoading }`.

3. `useBigSellerUnmappedSkus()`: Wraps `useQuery(api.bigsellerOrders.queries.getUnmappedSkus, { token })`. Returns `{ data: UnmappedSku[], isLoading }`.

4. `useBigSellerOrderStats()`: Wraps `useQuery(api.bigsellerOrders.queries.getOrderStats, { token })`. Returns stats including `allCostFeeZero` for COGS caveat.

5. `useStartBigSellerSync()`: Wraps `useAction(api.integrations.bigseller.sync.startSync)`. Returns the action function.

**Add exports to `src/hooks/convex/index.ts`**: Export all 5 hooks from useBigSeller.
