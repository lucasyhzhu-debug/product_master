```typescript
async function computeSha256(file: File): Promise<string> {
  const buffer = await file.arrayBuffer();
  const hashBuffer = await crypto.subtle.digest("SHA-256", buffer);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map((b) => b.toString(16).padStart(2, "0")).join("");
}
```

**parseBcaXlsx.ts:** Implement the 8-step D-28 parser contract:

1. `XLSX.read(buffer, { type: "array", cellDates: false })`. Reject if `wb.SheetNames.length !== 1` → throw `Error("Expected single-sheet BCA export, got N sheets")`.
2. `sheet_to_json(sheet, { header: 1, raw: false, defval: "", blankrows: true })` → `rows: string[][]`.
3. Extract metadata via REGEX AGAINST COLUMN A of rows 2-5 (DO NOT trust header labels — D-06a BCA quirk):
   - `/^No\. rekening\s*:\s*(\S+)/` → accountNumber
   - `/^Nama\s*:\s*(.+)$/` → accountHolder (trim)
   - `/^Periode\s*:\s*(\d{2}\/\d{2}\/\d{4})\s*-\s*(\d{2}\/\d{2}\/\d{4})/` → periodStart, periodEnd (parse as UTC DD/MM/YYYY)
   - `/^Kode Mata Uang\s*:\s*(\w+)/` → currency; reject if != `"Rp"` → throw `Error("Unsupported currency: ${currency}. Only IDR (Rp) supported.")`
4. Locate header row: find index where `row[0] === "Tanggal Transaksi"`. If not found, throw `Error("BCA header row not found — unexpected file shape")`.
5. Iterate rows below header. For each row:
   - If `row[0]` AND `row[1]` both empty → end of transactions (break).
   - Parse date: strip, split `-`, get `dayStr` and `monStr`. Use `INDONESIAN_MONTHS[monStr]` to get monthIdx. Use `resolveYearForRollover` with statement periodStart/periodEnd epochs. Call `parseIndonesianDate` to produce epoch ms.
   - Parse amount: `row[2]` — strip whitespace, strip `Rp`, strip commas, parseInt. Keep as integer IDR. If NaN → skip row with diagnostic `Error("Row ${i}: cannot parse amount ${raw}")`.
   - Parse direction: `row[3] === "DB"` → "debit"; `row[3] === ""` → "credit"; else → throw `Error("Row ${i}: unknown direction flag ${row[3]}")`.
   - Parse saldo: `row[4]` — same as amount parse; null if blank.
   - Parse counterparty heuristic: regex for trailing all-caps or Title Case token sequence of 2+ words in `rawDescription`. Use `/([A-Z][A-Z0-9]+(?:\s+[A-Z][A-Z0-9]+){1,})\s*$/` — bounded quantifier (Pitfall: ReDoS — don't use unbounded). Return null if no match.
