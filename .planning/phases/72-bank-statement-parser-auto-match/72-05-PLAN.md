**StatementUploadStep.tsx (the RED-zone for security — enforce 10 MB cap BEFORE parse):**
- File input accepts `.xlsx,.xls,.csv`
- On change: validate `file.size <= 10 * 1024 * 1024` else `setError("File too large — 10 MB maximum")` and abort
- Dispatch by extension: `.xlsx`/`.xls` → `parseBcaXlsx(await file.arrayBuffer())`; `.csv` → `parseBcaCsv(await file.text())`. DO NOT use `FileReader.readAsText` for XLSX (Pitfall 6).
- Compute fileHash: `await computeSha256(file)`.
- Pass to parent via onParsed({ parsed, fileHash, fileName: file.name }) or directly via state setter.
- Catch `ReconciliationError` → transition wizard to `step: "error"` with `diff` populated.
- Catch other parse errors → `step: "error"` with `message: err.message`. Never surface stack traces.
