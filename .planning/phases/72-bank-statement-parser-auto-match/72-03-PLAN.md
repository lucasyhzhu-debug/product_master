**classifyLine (Layer A):**
Implement per RESEARCH §Code Examples #4:
1. Split rules into `nonCatchAll` (`!r.isCatchAll`) and `catchAll` (`r.isCatchAll`). Filter out `isActive=false`.
2. Sort both by `priority DESC, ruleCode ASC`.
3. For each rule in `nonCatchAll` then `catchAll`, call `matches(line, rule)`. First match returns `{ rule, hintHit }`.
4. `matches(line, rule)`:
   - Direction: if `rule.direction !== "any" && rule.direction !== line.direction` → false
   - Counterparty patterns (optional): if present, at least one must case-insensitive-substring-match `rawDescription` else false
   - Description patterns:
     - If mode `"all"`: every pattern must be substring (else false)
     - If mode `"any"`: at least one must be substring (else false)
     - If mode `"hint"`: presence not required; returns hintHit=true if any pattern matched (but match succeeds regardless)
   - Return true + hintHit
5. Test `matchType`-specific semantics:
   - `counterparty_and_keyword` requires BOTH counterpartyPatterns array is non-empty-matched AND descriptionPatterns matched per mode
   - `counterparty_or_keyword` requires counterparty matched OR description matched
   - `counterparty`, `description_contains`, `description_exact`, `description_regex` dispatch to their primary field; if `matchType="description_regex"`, compile each descriptionPattern via `new RegExp(p, "i")` BUT wrap in try/catch — if regex invalid, treat rule as no-match (log once). Bounded-quantifier check is NOT enforced in engine (seed is trusted; admin CRUD UI flags unbounded regexes — plan 05 scope)
   - `catch_all` goes into catchAll bucket (redundant with `isCatchAll=true` field — both are set by seed)

**computeConfidence:**
- If linkage.found && linkage.fuzzyScore >= 0.95 (exact description) && rule.confidence === "exact" → `"exact"`
- If linkage.found && linkage.fuzzyScore >= 0.8 → `"strong"` (overrides rule's own confidence)
- If rule.confidence === "exact" → `"exact"`
- If rule.confidence === "strong" && hintHit → `"exact"` (hint elevation per D-17b)
- If rule.confidence === "strong" → `"strong"`
- If rule.confidence === "suggested" && hintHit → `"strong"`
- If rule.confidence === "suggested" → `"suggested"`
- If no rule matched → `"none"`
