## Typography

Two weights only — `400` (normal) for body/label content, `600` (semibold) for headings and the page display title. Keeps visual noise low while preserving heading hierarchy.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (`font-normal`) | 1.5 (`leading-normal` default) | Form labels, helper text, pre-flight stat values, alert body |
| Label | 12px (`text-xs`) | 400 (`font-normal`) | 1.4 | Filename hints under inputs, "WIB timezone" suffix, "(P&L only)" qualifier |
| Heading | 16px (`text-base`) | 600 (`font-semibold`) | 1.4 | Card titles ("Export type", "Date range", "Granularity", "Preflight summary") |
| Display | 24px (`text-2xl`) | 600 (`font-semibold`) | `tracking-tight` | Page title "Financial Data Export" via `PageHeader.tsx:30` |

Tabular numerals (`tabular-nums`) required on the pre-flight stat values (N journal entries, M revenue rows, X periods) so re-renders don't shift digit columns — matches `MarginRow` convention in `FinancialStatement.tsx:89`.

Font stack: `--font-sans` from `src/index.css:6` — Inter with system fallbacks. No new fonts added.

## Accessibility

- Every form control has an associated `<Label htmlFor="...">` (Radix Checkbox + RadioGroup auto-wire when `id` is set).
- Preset chips form a labeled group: wrap in `<div role="group" aria-label="Date range presets">`.
- Disabled CTA carries an accessible `aria-disabled="true"` AND a `<Tooltip>` exposing the reason — keyboard users can read the tooltip via focus.
- Pre-flight stat panel uses `aria-live="polite"` so the number summary is announced to screen readers when dates change.
- Soft warning Alert uses `role="status"` (not `role="alert"`) — it's informational, not an error blocker.
- Color contrast: all combinations above meet WCAG AA at 14px text — verified visually against the brand teal `#0D9488` on white (≈ 4.6:1).
- Keyboard: Tab order = export-type checkboxes → preset chips → date inputs → granularity radios (when visible) → Generate. No focus traps. Pressing Enter inside a date input triggers preflight refresh, NOT the Generate action (prevents accidental submits).

## Responsive Behavior

Single-column layout at all breakpoints (form is naturally narrow). Specific adjustments:

- `< 640px` (mobile): Preset chips wrap to 2 rows via `flex flex-wrap gap-2`. Date inputs stack vertically (`flex-col` on `< sm:`). Filename preview helper truncates with `truncate` and reveals full string via `<Tooltip>` on tap.
- `≥ 640px` (sm): Preset chips one row; date inputs side-by-side via `sm:flex-row sm:items-end`.
- `≥ 1024px` (lg): No further changes — `max-w-2xl` keeps the form readable on wide screens; surrounding white space is acceptable.

Entry button on `FinancialStatement.tsx`: at narrow widths the existing PageHeader action slot already wraps; the new "Export range…" sits next to "Export CSV" and wraps below on narrow screens (matches existing `flex-wrap` on `FinancialStatement.tsx:301`).
