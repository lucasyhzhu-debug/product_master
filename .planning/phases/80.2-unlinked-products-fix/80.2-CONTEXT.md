# Phase 80.2: Unlinked Products Fix (K3Mart + Direct) - Context

**Gathered:** 2026-04-17
**Status:** Ready for execution (PLAN already drafted and staff-reviewed)
**Parent phase:** 80 Unit Economics Analytics Dashboard (completed 2026-04-15)
**Source debug session:** `.planning/debug/unlinked-products-k3mart-direct.md` (root cause CONFIRMED)

<domain>
## Phase Boundary

Unit Economics SKU Pareto and SKU Channel Matrix reports show large `(Unlinked)` buckets for K3Mart and Direct channels even though the admin UI has SKU mappings configured and Direct orders are created via menu-product picker. This phase closes the two independent bugs that funnel through the same loader-synthesis branch and produce the misattribution.

**Scope:** Backend-only data-attribution fix. No UI changes. Production data backfill required post-deployment.

**Out of scope:** Consignment "(Unlinked)" bucket is expected behavior (per user). Only K3Mart and Direct channels are in scope.

</domain>

<decisions>
## Root-Cause Evidence

### Bug 1 — K3Mart mapping cascade does not run for `source === "k3mart"`
- `applyRetroactiveProductMappingImpl` at `convex/externalData/mutations.ts:458-596` has no branch for K3Mart. Step 1 cascades by child `productName` (K3Mart has no child rows, so no-op). Step 2 is gated to `shopee | tiktok` only at line 492.
- `syncK3MartSales` at `convex/integrations/k3mart/adapter.ts:557-576` builds records without setting `linkedMenuProductId`.
- **Impact:** 737/737 K3Mart parents unlinked. Mapping a K3Mart SKU in the admin UI saves the mapping row but never patches any `externalRevenue` parent.

### Bug 2 — `syncInternalOrders` skips child-item creation for historical orders
- `convex/integrations/internal/adapter.ts:126` has `if (!isNew) continue;` BEFORE the `saveRevenueItems` call.
- `saveRevenueItems` generation was added around 2026-04-10. Any Direct parent synced before that date is permanently orphaned (no children).
- **Impact:** 219 of 262 Direct parents have no `externalRevenueItems`. All 47 existing child rows are correctly linked — the unlinked appearance is due to MISSING children, not unlinked children.

### Common funnel
Both bugs flow through `convex/reports/unitEconomics.ts:178-209` — the "no item-level detail" branch synthesizes a single unlinked item per parent, which lands in `UNLINKED_KEY` at line 759.

</decisions>

<specifics>
## Fix Architecture (4 sub-fixes)

1. **K3Mart retroactive cascade** — extend `applyRetroactiveProductMappingImpl` with a K3Mart branch after Shopee/TikTok. Additive return type (new `externalRevenueUpdated` field) so call sites are untouched.

2. **K3Mart sync-time linking** — `syncK3MartSales` pre-fetches mappings via shared helper `getK3MartMappingBySku(ctx)` and sets `linkedMenuProductId` on each record in the map step.

3. **Direct historical backfill** — new admin-only paginated mutation `backfillInternalRevenueItems` that scans orphan parents (no children) and rebuilds `externalRevenueItems` from native `orderItems`. Idempotent via `saveRevenueItems`' existing `(revenueId, externalItemId)` dedup.

4. **Direct re-sync heal** — replace unconditional `if (!isNew) continue;` in `syncInternalOrders` with child-existence check so future re-syncs backfill missing children without duplicating existing ones.

## Shared helpers introduced

- `convex/integrations/k3mart/helpers.ts` — `getK3MartMappingBySku(ctx)` returns `Map<sku, menuProductId>`. Used by both fix-1 cascade and fix-2 sync-time.
- `convex/externalData/helpers.ts` — `hasExternalRevenueItems(ctx, revenueId)` for child-existence checks. Used by fix-3 backfill and fix-4 guard.

## Schema change

- Add index `by_source_productCode` on `externalRevenue` for `[source, externalProductCode]`. Used by K3Mart cascade for efficient lookup.

## Risk mitigations

- Additive-only API changes: new `externalRevenueUpdated` field in return type does not break existing call sites (all three just spread/return the object).
- Paginated primary for backfill (default 200 per batch, up to 4000-row Convex write cap).
- Rollback path: re-run cascade with `menuProductId: undefined` to un-link; Convex export (`npx convex export --prod`) taken before prod backfill as point-in-time restore.
- Data-completeness pre-flight: confirms zero K3Mart parents have null/empty `externalProductCode` before running cascade in prod.

</specifics>
