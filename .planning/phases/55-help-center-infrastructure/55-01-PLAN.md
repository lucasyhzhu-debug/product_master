Create `src/components/help/` directory with 5 components and a barrel export.

**RoleTag.tsx:**
- Props: `{ role: "all" | "manager" | "admin" }`
- Renders a small inline Badge-like span
- Colors: "all" = gray bg + gray text ("All Staff"), "manager" = blue bg + blue text ("Manager+"), "admin" = orange bg + orange text ("Admin Only")
- Use Tailwind classes directly (no shadcn Badge needed -- just a styled span with rounded-full, px-2, py-0.5, text-xs, font-medium)
- Light/dark mode: use semantic Tailwind (e.g., `bg-gray-100 text-gray-700 dark:bg-gray-800 dark:text-gray-300`)

**CalloutBox.tsx:**
- Props: `{ type: "tip" | "warning" | "important"; children: React.ReactNode }`
- Renders a box with left border (4px), icon on top-left, children content
- Icons from lucide-react: tip = Lightbulb, warning = AlertTriangle, important = Info
- Colors per spec:
  - tip: border-green-500, bg-green-50 dark:bg-green-950, icon text-green-600
  - warning: border-amber-500, bg-amber-50 dark:bg-amber-950, icon text-amber-600
  - important: border-orange-500, bg-orange-50 dark:bg-orange-950, icon text-orange-600
- Padding: p-4, gap between icon and content

**StepCard.tsx:**
- Props: `{ step: number; title: string; description: string; icon?: ComponentType<{ className?: string }>; tip?: string; warning?: string; isLast?: boolean }`
- Layout: numbered circle (w-8 h-8, bg-primary, text-primary-foreground, rounded-full, flex center) on left, title (font-semibold) + description (text-muted-foreground) on right
- If `tip` provided: render a CalloutBox type="tip" below the description
- If `warning` provided: render a CalloutBox type="warning" below the description
- If `isLast` is NOT true: render a vertical dotted line (border-l-2 border-dashed border-muted-foreground/30) connecting to the next step. The line extends from below the number circle. Use relative positioning on the container and absolute on the line.
- Import CalloutBox from same directory

**GuideSection.tsx:**
- Props: `{ id: string; title: string; role?: "all" | "manager" | "admin"; children: React.ReactNode }`
- Renders a `<section>` with `id={id}` and `style={{ scrollMarginTop: '80px' }}`
- Title as h2 (text-xl font-bold) with RoleTag inline if role is provided
- Children below the title with mt-4 spacing
- Import RoleTag from same directory

**FaqAccordion.tsx:**
- Types: `FaqItem { question: string; answer: string | React.ReactNode }`, `FaqGroup { title: string; items: FaqItem[] }`
- Props: `{ groups: FaqGroup[] }`
- Export FaqItem and FaqGroup types
- Renders each group with a title (text-lg font-semibold, mb-3) followed by a shadcn Accordion (type="multiple")
- Each FaqItem is an AccordionItem with AccordionTrigger (question) and AccordionContent (answer)
- Use unique value keys: `${groupIndex}-${itemIndex}`
- Import from `@/components/ui/accordion`
