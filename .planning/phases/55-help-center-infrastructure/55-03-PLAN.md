**HelpCenter.tsx** (`src/pages/HelpCenter.tsx`):

Create the Help Center landing page with three sections: hero + search, guide cards grid, popular questions.

1. **Imports:** HELP_GUIDES, searchGuides, POPULAR_QUESTIONS from `@/lib/helpGuides`. Link, useNavigate from react-router-dom. motion from framer-motion. Search, BookOpen from lucide-react. useState, useRef, useEffect, useCallback from react.

2. **State:** `searchQuery` (string), `searchResults` (SearchResult[]), `showResults` (boolean). `searchInputRef` for Ctrl+K focus.

3. **Ctrl+K handler:** useEffect with keydown listener. If `(e.metaKey || e.ctrlKey) && e.key === 'k'`, prevent default and focus searchInputRef.current.

4. **Search handler:** On input change, set searchQuery, call `searchGuides(query)`, set searchResults. Show results dropdown when query is non-empty and results exist. Hide on blur (with small delay for click registration) or when query is cleared.

5. **Hero section:**
   - Centered text: "How can we help you?" as h1 (text-3xl font-bold)
   - Subtitle: "Step-by-step guides, visual walkthroughs, and answers to common questions"
   - Search bar: styled input with Search icon on left, "Ctrl K" badge on right inside the input container. Rounded-lg border, shadow-sm on focus, max-w-lg mx-auto.
   - Search results dropdown: absolute positioned below search bar, z-50, bg-background border rounded-lg shadow-lg. Each result is a Link to `/help/${result.guideId}#${result.anchor || ''}`. Results grouped by type with small headers.

6. **Guide cards grid:**
   - Section header: "Workflow Guides" (text-lg font-semibold uppercase tracking-wider text-muted-foreground)
   - Grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`
   - Each card is a `<div>` (or Link for live guides):
     - Top accent bar: h-1 with background color derived from `accentColor` (use a mapping: orange -> bg-orange-500, green -> bg-green-500, blue -> bg-blue-500, purple -> bg-purple-500, rose -> bg-rose-500, amber -> bg-amber-500). Hover animation: `transform origin-left scale-x-0 group-hover:scale-x-100 transition-transform duration-300`.
     - Icon area: card icon in a colored circle/square background
     - Title, description
     - Badge: "NEW" for isNew (green), "COMING SOON" for coming-soon status (gray)
     - Section count + read time if live
     - **Coming Soon cards:** wrapper div with `opacity-50 cursor-default pointer-events-none`. No Link wrapping. No hover effects.
     - **Live cards:** wrapped in `<Link to={"/help/" + guide.id}>` with hover shadow, slight translateY.

7. **Staggered animation (Framer Motion):**
   - Wrap the cards grid in a motion.div container with `variants` for stagger children.
   - Each card uses motion.div with fadeUp variant: `initial={{ opacity: 0, y: 20 }}`, `animate={{ opacity: 1, y: 0 }}`, stagger delay 0.08s per card.
   - Use `whileInView` or trigger on mount.

8. **Popular Questions section:**
   - Section header: "Popular Questions"
   - List of POPULAR_QUESTIONS, each rendered as a Link to `/help/${q.guideId}#${q.anchor}`.
   - Each item: bullet point (or ChevronRight icon) + question text, with hover underline.
   - Staggered fade-in animation.

Export as named export: `export function HelpCenter()`.

**GuideRouter.tsx** (`src/pages/guides/GuideRouter.tsx`):

1. Import `useParams` from react-router-dom, `HELP_GUIDES` from `@/lib/helpGuides`, Link from react-router-dom, `BookX` (or `FileQuestion`) from lucide-react.

2. Get `guideId` from useParams.

3. Find guide: `HELP_GUIDES.find(g => g.id === guideId && g.status === 'live' && g.component)`.

4. If guide found and has component: render `<guide.component />`.

5. If NOT found (invalid ID, coming-soon status, or live status without component): render "Guide not found" state:
   - Centered container (min-h-[50vh] flex items-center justify-center)
   - Large muted icon (BookX or FileQuestion, h-16 w-16, text-muted-foreground/40)
   - "Guide not found" heading (text-xl font-semibold)
   - "This guide doesn't exist or isn't available yet." subtitle
   - `<Link to="/help">` button: "Back to Help Center"

Export as named export: `export function GuideRouter()`.

Create the `src/pages/guides/` directory if it doesn't exist.

**Header.tsx modifications:**

The Help nav item has NO permission restriction. The current `NavItem` type requires `permission: PermissionKey`. Two approaches:

**Approach: Add Help as a standalone link after the filtered mainNavItems, not inside the mainNavItems array.** This is cleaner because:
- It avoids making `permission` optional on NavItem (which would require null checks everywhere)
- Help is always visible, so it doesn't need permission filtering
- It's visually distinct as the last item before dropdowns

In the desktop nav section (inside the `<nav className="hidden md:flex ...">` block), after the `visibleMainItems.map(...)` loop, add:
```tsx
{user && (

    )}
  >
    <CircleHelp className="h-4 w-4" />
    <span>Help</span>

)}
```
