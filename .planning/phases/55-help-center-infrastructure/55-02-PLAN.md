  <files>src/components/help/WorkflowDiagram.tsx</files>
  <action>
Create `src/components/help/WorkflowDiagram.tsx` implementing a fixed-layout vertical SVG flowchart renderer.

**Interfaces** (export all):
- `FlowNode { id, label, color, description? }` — color is one of "gray" | "blue" | "green" | "amber" | "red" | "orange"
- `FlowEdge { from, to, label?, style? }` — style defaults to "solid"
- `WorkflowDiagramProps { nodes, edges, title? }`

**Layout algorithm (simple, not auto-layout):**
- Nodes are arranged vertically, centered horizontally
- Each node is a rounded rectangle: width ~180px, height ~44px, rx=8
- Vertical spacing between nodes: 70px (enough for edge labels)
- SVG viewBox calculated from node count: width ~400, height = (nodeCount * 70) + padding
- The SVG should be responsive: `width="100%" viewBox="0 0 {w} {h}"` with preserveAspectRatio

**Node rendering:**
- Rounded rect with fill color based on `color` prop:
  - gray: fill="#e5e7eb" (light) / text="#374151"
  - blue: fill="#dbeafe" / text="#1d4ed8"
  - green: fill="#dcfce7" / text="#15803d"
  - amber: fill="#fef3c7" / text="#b45309"
  - red: fill="#fee2e2" / text="#dc2626"
  - orange: fill="#ffedd5" / text="#ea580c"
- Text centered inside the rect (dominant-baseline="central", text-anchor="middle")
- Font size 13px, font-weight 500

**Edge rendering:**
- SVG `<path>` from bottom center of source node to top center of target node
- Arrowhead using SVG `<marker>` definition (triangle, 8x6)
- If `label` exists: render text at midpoint of edge path, slightly offset, with small white background rect behind it
- Dashed style: `strokeDasharray="6 4"`

**Entrance animation (Framer Motion):**
- Wrap in `motion.svg` or use motion on individual elements
- Nodes: staggered fade-in (opacity 0->1, y offset -10->0), stagger 0.1s per node
- Edges: after all nodes are visible (delay = nodes.length * 0.1 + 0.2), draw edges using stroke-dashoffset animation (from total path length to 0)
- Total animation duration should be under 1.5s

**Important:** This is NOT a general-purpose graph layout engine. Nodes are arranged in a simple vertical list. Each guide will define its own node/edge data. The component just renders them. For complex layouts (branching), the consuming code can provide multiple columns by adjusting node positions in a future enhancement, but for v1 a simple vertical stack is sufficient.

Add `role="img"` and `aria-label={title || "Workflow diagram"}` to the SVG element for accessibility.

<task type="auto">
  <name>Task 2: GuideLayout with sidebar TOC and active section tracking</name>
  <files>src/components/help/GuideLayout.tsx</files>
  <action>
Create `src/components/help/GuideLayout.tsx` implementing the shared layout for all guide pages.

**Props interface:**
```typescript
interface GuideLayoutProps {
  title: string;
  description?: string;
  sections: { id: string; title: string }[];
  readTimeMinutes?: number;
  children: React.ReactNode;
}
```

**Layout structure:**
1. **Back link** at top: `<Link to="/help">` with ArrowLeft icon + "Back to Help Center" text. Use react-router-dom Link.
2. **Title area**: guide title as h1 (text-2xl font-bold), optional description (text-muted-foreground), section count + read time (e.g., "8 sections -- 15 min read")
3. **Two-column layout on desktop** (breakpoint: lg/1024px):
   - Left: Sticky sidebar TOC (width ~220px, `position: sticky; top: 80px` to account for header)
   - Right: Content area (flex-1, max-w-3xl / ~720px)
4. **Mobile layout**: Horizontal scrollable tabs replacing sidebar. Use a `<nav>` with `overflow-x-auto whitespace-nowrap` containing section links as inline-flex items.

**Sidebar TOC:**
- List of section links, each an `<a href={"#" + section.id}>` with `onClick` that also calls `document.getElementById(id)?.scrollIntoView({ behavior: 'smooth' })`
- Active section highlighted: `font-medium text-foreground` vs inactive `text-muted-foreground`
- Subtle left border indicator on active item (2px border-l-2 border-primary)
- Smooth transitions on active state changes

**Active section tracking (Intersection Observer):**
- In a `useEffect`, create an IntersectionObserver observing all section elements (by their `id` attribute)
- Options: `{ rootMargin: '-80px 0px -60% 0px', threshold: 0 }` — the -80px accounts for sticky header, -60% means a section becomes "active" when its top 40% is in view
- When an entry `isIntersecting`, set `activeSection` state to that entry's target id
- Clean up observer on unmount
- Use `useRef` for the observer and `useState` for `activeSection`

**Mobile tabs:**
- On screens below lg breakpoint, render horizontal tabs instead of sidebar
- Each tab is a button/link with the section title
- Active tab gets `border-b-2 border-primary text-foreground` styling
- Container uses `overflow-x-auto` with `scrollbar-hide` or `-webkit-overflow-scrolling: touch`
- When active section changes, auto-scroll the tab into view using `scrollIntoView({ behavior: 'smooth', inline: 'center' })`

**Responsive hiding:**
- Sidebar: `hidden lg:block`
- Mobile tabs: `lg:hidden`

**Content area:**
- Children rendered inside `<main>` with `prose-like` spacing (space-y-12 for section separation)
- Max width constrained: `max-w-3xl` (~720px per spec)

Import ArrowLeft from lucide-react. Import Link from react-router-dom.
