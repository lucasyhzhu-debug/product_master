**Step 2: Add revenue items creation to `syncInternalOrders`**

After the existing batch loop that creates externalRevenue records (after `const insertedIds = await ctx.runMutation(...)` at line ~103), add a second pass that creates externalRevenueItems for each order.

Create a new internal mutation `syncRevenueItemsForOrder` in the same file (or a separate helper). Since `syncInternalOrders` is an action (cannot directly call `ctx.db`), it must use `ctx.runMutation` for DB writes.

Option: Create a new internalMutation in `convex/integrations/internal/adapter.ts`:

```typescript
import { internalMutation } from "../../_generated/server";

export const createRevenueItemsForOrder = internalMutation({
  args: {
    orderId: v.id("orders"),
    revenueId: v.id("externalRevenue"),
    orderNumber: v.string(),
  },
  handler: async (ctx, args) => {
    // Delete existing items for this revenue (idempotent refresh)
    const existingItems = await ctx.db
      .query("externalRevenueItems")
      .withIndex("by_revenue", (q) => q.eq("revenueId", args.revenueId))
      .collect();
    for (const item of existingItems) {
      await ctx.db.delete(item._id);
    }

    // Fetch order items
    const orderItems = await ctx.db
      .query("orderItems")
      .withIndex("by_order", (q) => q.eq("orderId", args.orderId))
      .filter((q) => q.neq(q.field("isCancelled"), true))
      .collect();

    let totalQuantity = 0;
    for (const item of orderItems) {
      totalQuantity += item.quantity;
      await ctx.db.insert("externalRevenueItems", {
        revenueId: args.revenueId,
        source: "internal",
        externalItemId: `${args.orderNumber}-${item._id}`,
        productName: item.productName,
        unitPrice: item.unitPrice,
        quantity: item.quantity,
        totalPrice: item.lineTotal,
        linkedMenuProductId: item.menuProductId,
        isAutoMatched: true,
        matchConfidence: item.menuProductId ? "exact" : "none",
        createdAt: Date.now(),
      });
    }

    // Update quantity on parent record
    await ctx.db.patch(args.revenueId, { quantitySold: totalQuantity });

    return { itemCount: orderItems.length };
  },
});
```
