# Plan 68-01: Backend — priceChangeLog Table and Bulk Update Mutations

<objective>
Add a `priceChangeLog` schema table for audit trail, then create `bulkUpdatePrices` mutations for both ingredients and packaging materials. Each mutation accepts an array of item changes, recalculates `costPerBaseUnit`, writes price change log entries, and triggers the existing cost invalidation cascade.
</objective>

<must_haves>
- `priceChangeLog` table in schema with entityType, entityId, field, oldValue, newValue, changedBy, changedAt
- `bulkUpdateIngredientPrices` mutation that accepts array of {id, priceExclShipping?, volumePurchased?, shippingCost?} and updates all changed items in one call
- `bulkUpdateMaterialPrices` mutation with identical pattern for packaging materials
- Both mutations recalculate `costPerBaseUnit` using existing `calculateCostPerBaseUnit()` from `convex/lib/costCalculator.ts`
- Both mutations write to `priceChangeLog` for every changed field (before/after values)
- Ingredient bulk update triggers `invalidateProductionComponentCosts` for each changed ingredient (existing cascade)
- Auth: both mutations require manager or admin role via `protectedMutation`
</must_haves>

```typescript
/**
 * Bulk update ingredient prices.
 * Accepts array of changes. Only fields provided are updated.
 * Recalculates costPerBaseUnit, writes priceChangeLog entries, triggers cost cascade.
 * Requires manager or admin role.
 */
export const bulkUpdatePrices = protectedMutation({
  roles: ["manager", "admin"],
  args: {
    changes: v.array(
      v.object({
        id: v.id("ingredients"),
        priceExclShipping: v.optional(v.number()),
        volumePurchased: v.optional(v.number()),
        shippingCost: v.optional(v.number()),
      })
    ),
  },
  handler: async (ctx, args) => {
    const now = Date.now();
    const changedBy = ctx.user.name;
    let updatedCount = 0;

    for (const change of args.changes) {
      const current = await ctx.db.get(change.id);
      if (!current) continue;

      // Determine which fields actually changed
      const fieldsToLog: Array<{ field: string; oldValue: number; newValue: number }> = [];

      if (change.priceExclShipping !== undefined && change.priceExclShipping !== current.priceExclShipping) {
        fieldsToLog.push({ field: "priceExclShipping", oldValue: current.priceExclShipping, newValue: change.priceExclShipping });
      }
      if (change.volumePurchased !== undefined && change.volumePurchased !== current.volumePurchased) {
        fieldsToLog.push({ field: "volumePurchased", oldValue: current.volumePurchased, newValue: change.volumePurchased });
      }
      if (change.shippingCost !== undefined && change.shippingCost !== current.shippingCost) {
        fieldsToLog.push({ field: "shippingCost", oldValue: current.shippingCost, newValue: change.shippingCost });
      }

      // Skip if nothing actually changed
      if (fieldsToLog.length === 0) continue;

      // Merge with current values
      const merged = {
        priceExclShipping: change.priceExclShipping ?? current.priceExclShipping,
        volumePurchased: change.volumePurchased ?? current.volumePurchased,
        shippingCost: change.shippingCost ?? current.shippingCost,
      };

      // Recalculate cost per base unit
      const { costPerUnit, baseUnit } = calculateCostPerBaseUnit(
        merged.priceExclShipping,
        merged.shippingCost,
        merged.volumePurchased,
        current.unitType
      );

      // Update the ingredient
      await ctx.db.patch(change.id, {
        ...merged,
        costPerBaseUnit: costPerUnit,
        baseUnit: baseUnit,
      });

      // Write price change log entries
      for (const log of fieldsToLog) {
        await ctx.db.insert("priceChangeLog", {
          entityType: "ingredient",
          entityId: change.id,
          field: log.field,
          oldValue: log.oldValue,
          newValue: log.newValue,
          changedBy,
          changedAt: now,
        });
      }

      // Trigger cost cascade (same as single update)
      await ctx.scheduler.runAfter(0, internal.lib.costInvalidation.invalidateProductionComponentCosts, {
        ingredientId: change.id,
      });

      updatedCount++;
    }

    return { updatedCount };
  },
});
```

Also ensure `internal` is imported at the top of the file. Check existing imports — it should already be imported from `"../_generated/api"`.
</action>

/**
 * List all ingredients for bulk price editing, sorted by name.
 * Returns all items (no pagination limit) with cost-relevant fields.

export const listForBulkEdit = query({
  args: {},

    const items = await ctx.db.query("ingredients").collect();
