<task type="auto">
  <name>Task 2: Replace showJumbo with enabledProductionComponents in kitchenConfig</name>
  <files>convex/schema.ts, convex/kitchenConfig/mutations.ts, convex/kitchenConfig/queries.ts</files>
  <action>
**Schema change (`convex/schema.ts`):**
In the `kitchenConfig` table definition, keep the existing `showJumbo` field for backward compatibility but add a new field:
```
// Phase 21-08: Per-component visibility toggles (replaces showJumbo)
// Array of enabled production component codes, e.g. ["BIG_BALL", "MID_BALL"]
// When unset, defaults to all active production component codes
enabledProductionComponents: v.optional(v.array(v.string())),
```
Do NOT remove `showJumbo` — it stays for migration safety. The new field takes precedence.

**Query changes (`convex/kitchenConfig/queries.ts`):**

In `getConfig`, update the return to include `enabledProductionComponents`:

For the config-exists branch:
```
enabledProductionComponents: config.enabledProductionComponents ?? null,
```

For the no-config branch (defaults):
```
enabledProductionComponents: null,  // null means "all enabled" — frontend resolves from componentTypes
```

Also, keep returning `showJumbo` for backward compatibility:
```
showJumbo: config?.enabledProductionComponents
  ? config.enabledProductionComponents.includes("BIG_BALL")
  : (config?.showJumbo ?? true),
```
This way, if `enabledProductionComponents` is set, derive `showJumbo` from it. Otherwise fall back to the legacy field. This ensures existing code that reads `showJumbo` still works during migration.

**Mutation changes (`convex/kitchenConfig/mutations.ts`):**

In `updateConfig` args, add:
```
enabledProductionComponents: v.optional(v.array(v.string())),
```

In the update/insert logic, persist the field:
```
...(args.enabledProductionComponents !== undefined
  ? { enabledProductionComponents: args.enabledProductionComponents }
  : {}),
```

When `enabledProductionComponents` is provided, also sync the legacy `showJumbo` field:
```
...(args.enabledProductionComponents !== undefined
  ? { showJumbo: args.enabledProductionComponents.includes("BIG_BALL") }
  : args.showJumbo !== undefined ? { showJumbo: args.showJumbo } : {}),
```
