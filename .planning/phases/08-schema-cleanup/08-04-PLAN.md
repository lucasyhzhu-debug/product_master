**2. src/lib/types.ts:**

- `MenuProduct` interface with `productionType?: string`

Remove these fields from the TypeScript interfaces. They no longer exist in the schema.

Also update any type that references `isFixed?: boolean` -- remove it.

Iterate until `npm run type-check` returns 0 errors.
