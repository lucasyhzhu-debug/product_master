      - Looks up debit and credit accounts via `ctx.db.query("accounts").withIndex("by_code", q => q.eq("code", template.debit)).first()`

      - Calls `createJournalEntryWithLines(ctx, { date: args.date, description: args.description, sourceType: "manual", createdBy: ctx.user._id, lines: [buildDebitLine(debitAccount._id, args.amount), buildCreditLine(creditAccount._id, args.amount)], metadata: { templateType: args.templateType } })`

    **isTemplateEntry filter predicate (convex/manualJournal/queries.ts):**
    - Export pure function `isTemplateEntry(entry: { sourceType: string; metadata?: { templateType?: string } | null }): boolean`
      - Returns `entry.sourceType === "manual" && !!entry.metadata?.templateType`
      - This is the core differentiator between template-based manual entries and CSV bulk imports (which also use sourceType "manual" but lack metadata.templateType)

    **listByPeriod query (convex/manualJournal/queries.ts):**
    - `listByPeriod` protectedQuery with roles ["manager", "admin"], args: { periodStart: v.number(), periodEnd: v.number() }
      - **CRITICAL: Use `by_date` index with range bounds, NOT `by_source` index.** The `by_source` index would load ALL manual entries (including potentially hundreds of CSV bulk imports) across ALL time periods, then post-filter. The `by_date` index narrows to the requested period first, which is far more scalable.
      - Query: `ctx.db.query("journalEntries").withIndex("by_date", q => q.gte("date", args.periodStart).lt("date", args.periodEnd)).collect()`
      - Post-filter using `isTemplateEntry(entry)` to keep only `sourceType === "manual"` entries with `metadata?.templateType` present (this excludes expense JEs, CSV imports, and other non-template entries)
      - For each filtered entry, fetches lines via `by_journal_entry` index
      - For each line, fetches account name via `ctx.db.get(line.accountId)`
      - Returns array sorted by date descending, each entry including: _id, entryNumber, date, description, metadata.templateType, lines with account names, total amount (sum of debit amounts)
