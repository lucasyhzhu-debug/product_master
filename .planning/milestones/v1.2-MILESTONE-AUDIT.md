### Integration Issues

**Issue 1 (Medium):** Tamtem depot deduction silent skip
- File: `convex/productInventory/mutations.ts`, `processGofoodSales` outlet lookup
- When outlet has no `linkedStorageLocationId`, deduction silently skips with `console.log` only
- No admin-visible alert; inventory accuracy silently compromised until seed is run
- Mitigation: Run `seedFinishedGoodsLocations` before Tamtem GoFood sales begin

**Issue 2 (Low):** Ingredient simulation name-match fragility
- File: `convex/dispatchPlanner/queries.ts` lines 939-944
- `ct.name.toLowerCase() === ingInfo.name.toLowerCase()` — if names diverge (e.g., bilingual), simulation shows 0 available stock
- Non-blocking; produces conservative (false-high shortage) warnings, not dangerous data
