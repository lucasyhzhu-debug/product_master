**Fix double toast (Issue 1):**
In `src/pages/IngredientsManager.tsx` line ~226: the `onUpdate` callback does not return the promise from `update.mutate(...)`. This causes `EntityManager.handleFormSubmit` to resolve immediately (await undefined) and show its own "Ingredient updated" toast, while `createMutationHook` also fires a second success toast.

Fix: change the callback to return the promise:
```
onUpdate={async (id, data) => {
  await update.mutateAsync({ id: id as Id<"ingredients">, ...data });
}}
```
Use `mutateAsync` (not `mutate`) so the promise resolves/rejects properly. This lets EntityManager await the actual mutation result and show ONE toast.

ALSO: Check the `createMutationHook` config in `src/hooks/convex/useIngredients.ts` for the update hook. If it has a `successMessage` that would produce a second toast, remove it (let EntityManager handle the success toast). OR if EntityManager does NOT show a toast on success, keep the hook toast. The goal is exactly ONE success toast, not zero or two.

**Add unlink mutation (Issue 2 — backend):**
In `convex/ingredients/mutations.ts`: add a new mutation `unlinkIngredientFromComponentType`:
- Uses `protectedMutation` pattern (same as `linkIngredientToComponentType`)
- Args: `ingredientId: v.id("ingredients")`
- Auth: admin role only (same as link mutation)
- Handler: `await ctx.db.patch(args.ingredientId, { ingredientComponentTypeId: undefined })`
- Return `{ success: true }`

**Add unlink hook (Issue 2 — hook):**
In `src/hooks/convex/useIngredients.ts`: add a hook for the new unlink mutation using the same `createMutationHook` pattern. Export it from the hooks barrel.

**Add Untrack button (Issue 2 — frontend):**

- Keep the green "Tracked" badge
- Add an "Untrack" button next to it (small, ghost/outline variant, with X icon or Unlink icon from Lucide)
- Clicking Untrack calls the unlink mutation with a confirmation (use the existing ConfirmDialog pattern or inline confirm)
- After unlinking, the badge disappears and the "Enable Tracking" / "Link existing" buttons reappear

Style the Untrack button subtly (text-muted-foreground, small size) so it doesn't compete visually with the Tracked badge.
