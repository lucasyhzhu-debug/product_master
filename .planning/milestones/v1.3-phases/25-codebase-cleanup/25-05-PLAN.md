## Frontend Migration Pattern

useSessionMutation from convex-helpers/react/sessions auto-injects sessionId for protectedMutation backends:

```typescript
// BEFORE (raw useMutation — does NOT inject sessionId)
import { useMutation } from "convex/react";
const createOrder = useMutation(api.orders.mutations.orderCrud.create);
// Called as: await createOrder({ token: authToken, ...data })

// AFTER (useSessionMutation — auto-injects sessionId)
import { useSessionMutation } from "convex-helpers/react/sessions";
const createOrder = useSessionMutation(api.orders.mutations.orderCrud.create);
// Called as: await createOrder({ ...data })  — no token, no sessionId manual passing
```

OR use createMutationHook (wraps useSessionMutation + adds toast notifications):
```typescript
import { createMutationHook } from "src/hooks/convex/createMutationHook";
export const useCreateOrder = createMutationHook(
  api.orders.mutations.orderCrud.create,
  { successMessage: "Order created", errorMessage: "Failed to create order" }
);
```

CRITICAL: Only update hooks for mutations that were migrated to protectedMutation in plan 25-03.
- Public mutations (createDraft, updateDraft) that stayed as bare mutation() keep raw useMutation
- Role-protected mutations (createOrder, updateOrder, etc.) need useSessionMutation

Read 25-03-SUMMARY.md to see the exact list of which mutations were migrated.

## Query Factory Pattern

```typescript
// convex/lib/queryHelpers.ts exports:
// listAll(ctx, "tableName", options?) — list all rows, optional filter
// getById(ctx, id) — get single row by ID (with typed return)
// textSearch(ctx, "tableName", query, fields) — in-memory search

// BEFORE
export const list = query({ args: {}, handler: async (ctx) => {
  return await ctx.db.query("menuProducts").collect();
}});
export const getById = query({ args: { id: v.id("menuProducts") }, handler: async (ctx, args) => {
  return await ctx.db.get(args.id);
}});

// AFTER
import { listAll, getById as getByIdHelper } from "../lib/queryHelpers";
export const list = query({ args: {}, handler: async (ctx) => {
  return await listAll(ctx, "menuProducts");
}});
export const getById = query({ args: { id: v.id("menuProducts") }, handler: async (ctx, args) => {
  return await getByIdHelper(ctx, args.id);
}});
```

DO NOT apply to: orders/queries.ts (1,254 lines, complex indexed queries), productionRecipes/queries.ts (complex joins), inventory/queries.ts (FIFO/batch logic).
