**A) Create `src/components/kitchen/ManagerTargetSettings.tsx`:**

Manager-only settings section rendered on the kitchen page. Two sub-sections:

**Sub-section 1: Default Targets (KIT-09)**
- "Default Daily Targets" heading with Settings icon
- Number inputs for: "Original balls" (default 110) and "Jumbo balls" (default 0)
- Packaging mix editor: list of `(menuProduct, quantity)` pairs. Use the active menu products from a `useQuery(api.menuProducts.queries.list)` call (or pass as prop). Each row has a product selector (dropdown of active menuProducts) and a quantity input. Add/remove rows.
- "Save Defaults" button → calls `useProtectedMutation(api.kitchenConfig.mutations.updateConfig)` with the form data including `defaultPackagingMix`.
- Pre-populate from current `kitchenConfig` data (passed as prop or queried).

**Sub-section 2: Today's Override (KIT-18)**
- "Override Today's Targets" heading
- Same input fields as defaults: Original balls, Jumbo balls, optional packaging overrides.
- "Apply Override" button → calls `useProtectedMutation(api.kitchenDailyOverrides.mutations.setDailyOverride)` with today's date + override values.
- "Clear Override" button (visible only if an override exists for today) → calls `clearDailyOverride`.
- Show current override status: "Override active for today" badge if one exists, or "Using dispatch plan/defaults" if not.

Use shadcn Card for each sub-section. Use shadcn Input for number fields. Use shadcn Select for product dropdowns. Use Sonner toast for save confirmation.

**B) Create `src/components/kitchen/ShiftHistoryList.tsx`:**

Manager-only shift history panel (KIT-16). Shows past shift records.

- Query: `useQuery(api.kitchenShiftRecords.queries.getShiftHistory, { token })` — pass token from useAuth.
- Default: show last 7 days. Optional date range selector (two date inputs).
- Display as a list grouped by date:
  - Date heading: "Feb 22, 2026"
  - Under each date: cards for each shift record showing:
    - Submitted by + time: "Kitchen Staff at 4:30 PM"
    - Produced summary: "80x Original Singles, 25x Triples"
    - Waste summary (if any): "5x Singles (QA)"
    - Edit indicator: if record has `editedAt`, show "(edited by Manager at 5:00 PM)"
    - "Edit" button (only for manager role) → opens ShiftEditDialog
- If no records: "No shift records found" empty state.

**C) Create `src/components/kitchen/ShiftEditDialog.tsx`:**

Edit dialog for a past shift record (KIT-17). Uses shadcn Dialog.

- Pre-populate form with existing record's produced and waste values.
- Same input structure as EndOfShiftForm's input step (produced quantities + waste entries).
- Optional "Edit note" text field for the reason of edit.
- On "Save Changes" click, compute the inventory impact BEFORE submitting:
  - For each product: `oldNet = oldProduced - oldWaste`, `newNet = newProduced - newWaste`, `delta = newNet - oldNet`
  - Show confirmation dialog:
    - If delta > 0: "This will ADD {delta} units of {productName} to inventory"
    - If delta < 0: "This will REDUCE inventory by {|delta|} units of {productName}"
    - If delta === 0: "No inventory change for {productName}"
  - List ALL products with non-zero deltas.
  - "Confirm Edit" and "Cancel" buttons.
- On confirm: call `useProtectedMutation(api.kitchenShiftRecords.mutations.updateShiftRecord)`.
- On success: toast "Shift record updated", close dialog.
- On error: toast error message, keep dialog open.

Props: `record: ShiftRecord, open: boolean, onClose: () => void`
