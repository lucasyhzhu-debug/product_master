The cleanest approach without circular imports: import the PreloadableComponent type and expose a `preload` function on each NavItem object.

Update `NavItem` type in Header.tsx to add an optional preload field:
```typescript
type NavItem = {
  path: string;
  label: string;
  icon: React.ComponentType<{ className?: string }>;
  permission: PermissionKey;
  preload?: () => void;  // add this
};
```

Then import the lazy components at the top of Header.tsx using direct `lazy` imports (NOT lazyWithPreload — we just need the preload function, not a component to render):

```typescript
// Import lazy page factories for hover prefetching

import { lazy } from 'react';
```
