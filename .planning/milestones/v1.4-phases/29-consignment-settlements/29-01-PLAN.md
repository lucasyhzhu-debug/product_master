**Step 2: Create convex/consignment/mutations.ts**

Create the new backend module with these mutations using `requireRole` pattern (admin + manager — consignment is manager-level financial data per CONTEXT.md):

```typescript
import { mutation } from "../_generated/server";
import { v } from "convex/values";
import { requireRole } from "../lib/auth";
```

**2a. `createOutlet` mutation:**
- Args: `token: v.string(), name: v.string(), revSharePercent: v.number(), type: v.union(v.literal("cafe"), v.literal("retail"), v.literal("event")), address: v.optional(v.string()), contactName: v.optional(v.string()), notes: v.optional(v.string())`
- Auth: `requireRole(ctx, args.token, ["admin", "manager"])`
- Create `consignmentOutlets` record FIRST: all args + `isActive: true`, `createdBy: user.name`, `createdAt: Date.now()` — get back outletId
- Create `externalOutlets` record: `source: "consignment"`, `externalId: "consignment-" + outletId` (uses Convex ID for guaranteed uniqueness), `name: args.name`, `address: args.address`, `isActive: true`, `createdBy: user.name`, `createdAt: Date.now()`
- Patch `consignmentOutlets` with `externalOutletId` linking to the externalOutlets record
- Also set dispatch planner fields: `channelKey: "consignment"`, `isEnabled: true`, `productMappings: []`
- Return `{ status: "created", outletId, externalOutletId }`

**2b. `updateOutlet` mutation:**
- Args: `token: v.string(), outletId: v.id("consignmentOutlets"), name: v.optional(v.string()), revSharePercent: v.optional(v.number()), type: v.optional(v.union(...)), address: v.optional(v.string()), contactName: v.optional(v.string()), notes: v.optional(v.string()), isActive: v.optional(v.boolean()), productMappings: v.optional(v.array(...))`
- Auth: admin + manager (`requireRole(ctx, args.token, ["admin", "manager"])`)
- Patch consignmentOutlets record
- Also patch linked externalOutlets record if name or address changed (keep in sync)
- Return `{ status: "updated" }`

**2c. `createSettlement` mutation:**
- Args: `token: v.string(), outletId: v.id("consignmentOutlets"), periodStart: v.number(), periodEnd: v.number(), totalRevenue: v.number(), notes: v.optional(v.string())`
- Auth: admin + manager (`requireRole(ctx, args.token, ["admin", "manager"])`)
- Fetch outlet to get `revSharePercent` and `externalOutletId`
- **Input validation:** throw if `totalRevenue < 0`, throw if `periodStart > periodEnd`
- Compute: `revShareAmount = totalRevenue * outlet.revSharePercent / 100`, `frolliePayment = totalRevenue - revShareAmount`
- Create `externalRevenue` record: `source: "consignment"`, `outletId: outlet.externalOutletId`, `revenueGross: totalRevenue`, `revenueNet: frolliePayment`, `periodStart`, `periodEnd`, `dataOrigin: "manual_entry"`, `confidence: "manual"`, `transactionType: "sales"`
- Create `consignmentSettlements` record with all computed fields + `linkedRevenueId` + `status: "pending"` + `createdBy: user.name`, `createdAt: Date.now()`
- Return `{ status: "created", settlementId, revenueId }`

**2d. `updateSettlement` mutation:**
- Args: `token: v.string(), settlementId: v.id("consignmentSettlements"), totalRevenue: v.optional(v.number()), periodStart: v.optional(v.number()), periodEnd: v.optional(v.number()), notes: v.optional(v.string())`
- Auth: admin + manager (`requireRole(ctx, args.token, ["admin", "manager"])`)
- Guard: throw if `settlement.status === "paid"` (locked after payment)
- If `totalRevenue` changed: re-fetch outlet, recompute `revShareAmount` and `frolliePayment`
- Patch settlement
- Patch linked `externalRevenue` if `linkedRevenueId` exists and revenue/period changed (sync analytics)
- Return `{ status: "updated" }`

**2e. `markAsPaid` mutation:**
- Args: `token: v.string(), settlementId: v.id("consignmentSettlements")`
- Auth: admin + manager (`requireRole(ctx, args.token, ["admin", "manager"])`)
- Guard: throw if already paid
- Patch settlement: `status: "paid"`, `paidAt: Date.now()`, `updatedBy: user.name`, `updatedAt: Date.now()`
- **Event auto-archive:** fetch outlet, if `outlet.type === "event"`, patch outlet `isActive: false`
- Return `{ status: "paid", autoArchived: outlet.type === "event" }`

**2f. `deleteSettlement` mutation:**
- Args: `token: v.string(), settlementId: v.id("consignmentSettlements")`
- Auth: admin + manager (`requireRole(ctx, args.token, ["admin", "manager"])`)
- Guard: throw if `settlement.status === "paid"` (can't delete paid settlements)
- Delete linked `externalRevenue` record if `linkedRevenueId` exists
- Delete settlement
- Return `{ status: "deleted" }`
