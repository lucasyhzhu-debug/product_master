## Decisions Made
- Edit mode uses `?draft=orderId` query param rather than a separate /orders/edit/:id route, keeping routing simple
- Customer section shows read-only display in edit mode (CustomerSearch lacks defaultValue prop; would require additional component work)
- Draft auto-creation fires only on customer select (not page load) to avoid creating orphaned empty drafts
- Submit flow syncs all form state to the Draft (updateDraft + replaceItems) before transitioning to AwaitingPayment
