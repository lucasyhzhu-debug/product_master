**SyncHealthBanner component:**
Create a persistent banner that appears at the top of the Dashboard when any API sync has failed for 6+ hours. Uses the `getSyncHealthAlert` query from Plan 01.

Design (per locked decisions):
- Persistent red/amber banner at top of dashboard
- Cannot be dismissed -- stays until sync succeeds again
- Red if sync has failed with errors, amber if sync is simply stale (no recent success)
- Content: Icon (AlertTriangle) + "GoFood sync failed 8 hours ago: {error message}" or "K3 Mart has not synced in 12 hours"
- If multiple platforms failing, show one line per platform
- Link to Settings tab: "Go to Settings" button/link that navigates to `/sales-analytics?tab=settings`
- Chain break notification: If GoBiz credential status shows token expired AND no refresh token, show additional red badge text: "Manual token paste required"

```tsx
function SyncHealthBanner() {
  const alert = useConvexSyncHealthAlert();
  if (alert === undefined) return null; // loading
  if (!alert.hasAlert) return null; // no alerts

  return (
    <div className="rounded-lg border border-destructive/50 bg-destructive/10 p-3 mb-4">
      {alert.alerts.map(a => (
        <div key={a.platform} className="flex items-center gap-2 text-sm">
          <AlertTriangle className="h-4 w-4 text-destructive" />
          <span>{a.platformName} {a.lastError ? `sync failed: ${a.lastError}` : `has not synced in ${formatDuration(a.staleSinceMs)}`}</span>
        </div>
      ))}
      <Link to="/sales-analytics?tab=settings" className="text-xs text-brand underline mt-1 block">
        Go to Settings
      </Link>
    </div>
  );
}
```

**Backend: Retroactive mapping mutation (externalData/mutations.ts):**
Add `updateProductMapping` mutation:
```typescript
export const updateProductMapping = mutation({
  args: {
    token: v.string(),
    mappingId: v.id("externalProductMappings"),
    menuProductId: v.optional(v.id("menuProducts")),
  },
  handler: async (ctx, args) => {
    await requireRole(ctx, args.token, ["admin"]);
    const mapping = await ctx.db.get(args.mappingId);
    if (!mapping) throw new Error("Mapping not found");

    // Update the mapping
    await ctx.db.patch(args.mappingId, {
      menuProductId: args.menuProductId,
      isAutoMapped: false,
      createdAt: Date.now(),
    });

    // Retroactively update all revenue items with this external product
    const items = await ctx.db.query("externalRevenueItems")
      .withIndex("by_product_name", q =>
        q.eq("source", mapping.source).eq("productName", mapping.externalProductName)
      )
      .collect();

    for (const item of items) {
      await ctx.db.patch(item._id, {
        linkedMenuProductId: args.menuProductId,
        isAutoMatched: false,
        matchConfidence: "exact",
      });
    }

    return { updatedItems: items.length };
  },
});
```

Also add `countMappingImpact` query to preview impact:
```typescript
export const countMappingImpact = query({
  args: {
    source: sourceValidator,
    externalProductName: v.string(),
  },
  handler: async (ctx, args) => {
    const items = await ctx.db.query("externalRevenueItems")
      .withIndex("by_product_name", q =>
        q.eq("source", args.source).eq("productName", args.externalProductName)
      )
      .collect();
    return { count: items.length };
  },
});
```
