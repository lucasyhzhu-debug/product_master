2. **Create `src/components/kitchen/DashboardHeader.tsx`:**
Props:
```typescript
interface DashboardHeaderProps {
  minTargetToday: { totalBalls: number; bigBalls: number; midBalls: number; orderCount: number } | undefined;
  maxTarget: { total: number; big: number; mid: number };
  remainingBalls: { total: number; big: number; mid: number };
  ordersLeft: number;
  hasOverdueOrders: boolean;
  onOpenConfig: () => void;
  canConfigure: boolean;
}
```

Layout:
- Outer div: `sticky z-20 bg-card border-b shadow-sm` -- sits below the page header (which is z-30 sticky top-0). Use `top: 56px` (existing header height) or calculate dynamically.
- Inner: `grid grid-cols-2 lg:grid-cols-4 gap-2 p-3` -- 2x2 on mobile, 4-across on desktop.
- Per user decision: NEVER collapsible, always visible.

4 StatCards:
a) **Min Target Today**: value = `minTargetToday.totalBalls`, subtitle = `(${minTargetToday.orderCount} orders)`, label = "Min Target"
b) **Max Target**: value = `maxTarget.total`, label = "Max Target". If `canConfigure`, show Settings icon from lucide-react that calls `onOpenConfig`.
c) **Remaining Balls**: value = `remainingBalls.total`, label = "Remaining". Color-coded urgency per user decision:
   - Green: `remainingBalls.total <= maxTarget.total && !hasOverdueOrders`
   - Red: `hasOverdueOrders` (overdue orders exist)
   - Amber: everything else (behind but no overdue)
   - On tap: toggle local state `showBreakdown` to show "Big: X / Mid: Y" instead of combined total
d) **Orders Left**: value = `ordersLeft`, label = "Orders Left"

Loading state: When `minTargetToday` is undefined, show 4 skeleton stat cards using Tailwind `animate-pulse bg-muted rounded` placeholders.
