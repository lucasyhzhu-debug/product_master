**1. Create `src/contexts/ThemeContext.tsx`:**

Create a ThemeProvider that manages light/dark/system theme preference:
- Type: `Theme = 'light' | 'dark' | 'system'`
- Interface: `ThemeContextType { theme: Theme; setTheme: (t: Theme) => void; resolvedTheme: 'light' | 'dark' }`
- Read saved preference from `localStorage.getItem('frollie-theme')`, default to `'system'`
- On theme change: toggle `.dark` class on `document.documentElement`, save to localStorage
- For `'system'`: listen to `window.matchMedia('(prefers-color-scheme: dark)')` changes
- Export `useTheme()` hook that throws if used outside provider

Follow the exact code pattern from 09-RESEARCH.md "Theme Provider Context" section.

Create `docs/UI_BRAND_REFERENCE.md` — the definitive brand/UI reference for the app. This document formalizes decisions from CONTEXT.md and research findings into an enforceable standard.

**Document structure:**

```markdown
# Frollie Recipe Master — UI Brand Reference

## Visual Identity
- Brand tone: Friendly, warm, approachable (Notion-style warm)
- Not: Clinical SaaS, cold enterprise, heavy decoration

## Color Palette

### Brand Accent (Teal)
| Token | Value (Light) | Value (Dark) | Usage |
|-------|---------------|--------------|-------|
| --color-brand | #0D9488 | #14B8A6 | Primary buttons, links, active states |
| --color-brand-dark | #0F766E | #0D9488 | Hover states |
| --color-brand-darker | #115E59 | #0F766E | Active/pressed states |
| --color-brand-light | rgba(13,148,136,0.1) | rgba(20,184,166,0.15) | Tinted backgrounds |
| --color-brand-muted | rgba(13,148,136,0.05) | rgba(20,184,166,0.08) | Subtle tints |

### Semantic Colors (shadcn)
Document all --color-background, foreground, card, muted, accent, destructive, border, input, ring values for both light and dark.

### Semantic Colors (Kitchen/Domain)
List kitchen station colors, GoFood, K3Mart — note these are domain-specific and NOT changed by dark mode (they retain their semantic meaning).

## Typography
- **Font family:** Inter (single font family for everything)
- **Headings:** Inter 700-800 weight, tracking-tight
- **Body:** Inter 400-500 weight
- **Small text:** Inter 400, text-sm
- **Monospace:** System default (order numbers, inventory codes)
- **No Playfair Display** — removed in Phase 9

## Spacing Scale
| Size | Tailwind | Pixels | Usage |
|------|----------|--------|-------|
| 1 | gap-1, p-1 | 4px | Tight element gaps |
| 2 | gap-2, p-2 | 8px | Inline element spacing |
| 3 | gap-3, p-3 | 12px | Compact section gaps |
| 4 | gap-4, p-4 | 16px | Standard element gaps |
| 6 | gap-6, space-y-6 | 24px | Section spacing within page |
| 8 | gap-8 | 32px | Major section spacing |
| 12 | py-12 | 48px | Page-level vertical rhythm |

Standard page content gap: `space-y-6` (24px) — all pages.

## Border Radius
| Token | Value | Usage |
|-------|-------|-------|
| --radius-lg | 12px | Cards, modals, large containers |
| --radius-md | 8px | Buttons, inputs, smaller cards |
| --radius-sm | 6px | Badges, chips, small elements |

## Shadows
- Cards: `shadow-sm` (subtle)
- Modals/dialogs: `shadow-lg`
- Hover states: `shadow-md` transition
- NO heavy shadows. Light, warm feel.

## Page Layout

### Container
- Max width: `max-w-[1400px]` (centered with `mx-auto`)
- Horizontal padding: `px-4 sm:px-6 lg:px-8`
- Vertical padding: `py-6`
- Applied by `PageContainer` component in Layout — NOT by individual pages

### Full-Width Exceptions
- KitchenViewV2 — swipeable 4-panel layout needs viewport width
- OrderManager — split-pane desktop layout
- Use route-level opt-out mechanism (not per-page wrapper)

### Header
- Fixed position (not sticky)
- Hide on scroll down, show on scroll up
- Height: h-14 (56px)
- Main content has `pt-14` to compensate

### Footer
- Desktop only (`hidden md:block`)
- Navigation links, copyright, helpful info
- Not shown on mobile (bottom tab bar used instead)

### Mobile Bottom Tab Bar
- Fixed bottom, `md:hidden`
- Role-based items (see Access Control section)
- Safe area bottom padding
- Max 5 items

### Page Transitions
- `AnimatePresence` wrapper around `<Outlet />`
- Fade in: `opacity: 0 -> 1`, duration 0.15s
- Key by `location.pathname` for proper exit animations

## Component Patterns

### PageHeader
All pages MUST use `<PageHeader>` component. No custom inline headers.
- Title: `text-2xl font-bold tracking-tight`
- Description: `text-sm text-muted-foreground`
- Action slot for buttons
- Back button with `backTo` prop

### Cards
- Use `<Card>` from shadcn
- `rounded-lg` (12px) with `shadow-sm`
- Background: `bg-card`

### Tables
- Comfortable density: `py-3 px-4` cells
- Header: `bg-muted/50` with `text-muted-foreground text-sm font-medium`
- Borders: `border-border`
- Hover rows: `hover:bg-muted/30`

### Buttons
- Primary: teal brand (shadcn default with teal primary)
- Secondary: `bg-secondary`
- Destructive: `bg-destructive`
- Ghost: `hover:bg-accent`
- Size: default `h-10`, sm `h-9`, lg `h-11`
- All with `rounded-md` (8px)

### Modals/Dialogs
- Use shadcn `Dialog` or `Sheet`
- `rounded-lg` (12px)
- `shadow-lg`
- Overlay: `bg-black/50`

### Toast Notifications
- Position: contextual (existing `actionToast.ts` system)
- Theme-aware via Sonner `theme` prop

### Loading States
- Skeleton screens: `Skeleton` component with `animate-pulse`
- Page-level: `TablePageSkeleton`, `EditorPageSkeleton`, `DashboardSkeleton`
- Color: `bg-muted` (warm gray in light, dark gray in dark)

### Empty States
- Icon: Lucide at 48px inside 96px circle
- Circle bg: `bg-muted/50`
- Icon opacity: `opacity-60`
- Always include CTA button
- Warm, friendly messaging

### Icons
- Library: Lucide React
- Standard size: 24px (h-6 w-6)
- Navigation: 20px (h-5 w-5)
- Inline/small: 16px (h-4 w-4)

## Dark Mode
- Toggle: system preference with manual override
- Storage: `localStorage('frollie-theme')`
- Mechanism: `.dark` class on `<html>`, Tailwind `@custom-variant`
- All colors use CSS variables — automatic switching
- Kitchen station/domain colors: keep as-is (semantic, not theme-dependent)

## Responsive Breakpoints
- Mobile: < 768px (`md:` prefix)
- Tablet: 768-1024px (`lg:` prefix)
- Desktop: > 1024px
- Use Tailwind responsive prefixes ONLY — no `window.innerWidth` checks

## Animations (Framer Motion)
- Page transitions: fade, 150ms
- List item stagger: 50ms delay per item
- Button hover: scale(1.02), 100ms
- Modal enter: opacity + translateY, 200ms
- Modal exit: opacity, 150ms
```

Adapt the above into a complete, well-formatted document. Include ALL details from CONTEXT.md locked decisions. This is the source of truth for all UI work going forward.
