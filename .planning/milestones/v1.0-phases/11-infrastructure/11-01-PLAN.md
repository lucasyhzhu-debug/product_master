**Schema additions in `convex/schema.ts`:**

Add 2 new tables after the existing `productionLog` table section:

1. `integrityCheckLogs` table:
   - `timestamp: v.number()`
   - `type: v.string()` — check type (e.g. "production_counts")
   - `status: v.union(v.literal("pass"), v.literal("fail"))`
   - `mismatchCount: v.number()`
   - `mismatches: v.optional(v.string())` — JSON string of mismatch details
   - Index: `.index("by_timestamp", ["timestamp"])`

2. `productionResets` table:
   - `menuProductId: v.id("menuProducts")`
   - `lastResetAt: v.number()` — timestamp of last reset
   - `lastResetBy: v.string()` — username who reset
   - Index: `.index("by_menu_product", ["menuProductId"])`

**Also update productionLog action union** in schema to include new action types for GoFood tracking:
Change the action field from:
```
v.literal("box"), v.literal("unbox"),
v.literal("sticker"), v.literal("unsticker"),
v.literal("pack"), v.literal("unpack")
```
To:
```
v.literal("box"), v.literal("unbox"),
v.literal("sticker"), v.literal("unsticker"),
v.literal("pack"), v.literal("unpack"),
v.literal("ship_goldfinch"), v.literal("return_goldfinch")
```

**Cron addition in `convex/crons.ts`:**

Add one new cron job after the existing ones:

**INFRA-02: Full dependency audit.**

1. Run `npm outdated` to identify all packages with current vs latest versions.
2. Run `npm audit` to identify security vulnerabilities.
3. For each upgradeable package, attempt the upgrade and run `npm run build`:
   - If build passes: keep the upgrade, document as "Upgraded"
   - If build fails: revert (`npm install package@previous-version`), document as "Skipped" with rationale
4. Run `npm run build` one final time to confirm everything passes.

Create `docs/DEPENDENCY_AUDIT.md` with sections:
- **Header**: Audit date, auditor, Node/npm versions
- **Core Stack Compatibility**: Table confirming React 19 + Vite 7 + Convex 1.31 + TypeScript 5.9 work together
- **Package Inventory**: Table of ALL packages (dependencies + devDependencies) with columns: Package, Current Version, Latest Available, Status (current/upgraded/skipped), Notes
- **Upgrades Applied**: List of packages that were successfully upgraded with before/after versions
- **Upgrades Skipped**: List of packages NOT upgraded, with specific rationale (breaking change, peer dep conflict, etc.)
- **Security Audit**: Output summary from `npm audit` — vulnerabilities found, severity, affected packages
- **Future Recommendations**: 3-6 month timeline items — packages approaching EOL, upcoming major versions to watch, deprecated packages to plan replacing
- **Verification**: Confirm `npm run build` passes after all changes

Per user decision: skip breaking upgrades — only apply upgrades where `npm run build` still passes.
