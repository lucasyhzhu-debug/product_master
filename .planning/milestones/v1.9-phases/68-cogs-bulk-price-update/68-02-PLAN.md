# Plan 68-02: Frontend — COGS Bulk Update Page

<objective>
Create a COGS Bulk Update page with two tabs (Ingredients and Packaging Materials). Each tab displays an editable grid where managers can inline-edit priceExclShipping, volumePurchased, and shippingCost for multiple items. costPerBaseUnit recalculates live in the browser as inputs change. A save-all button submits only changed rows via the bulk mutations from plan 68-01. Add the page to routing and navigation.
</objective>

<must_haves>
- New `COGSUpdate.tsx` page with two tabs: "Ingredients" and "Packaging Materials"
- Editable grid rows showing: item name (read-only), unit (read-only), priceExclShipping (editable), volumePurchased (editable), shippingCost (editable), costPerBaseUnit (read-only, live-calculated)
- Dirty tracking: only rows with actual changes are submitted on save
- Live costPerBaseUnit preview: recalculates in browser as user types (using same formula as backend)
- Save-all button calls `bulkUpdateIngredientPrices` / `bulkUpdateMaterialPrices` mutation
- Change count badge on save button showing how many items are modified
- Route at `/cogs-update` with `canAccessIngredients` permission guard
- Navigation link in Header.tsx configItems array
- Hook file `useCOGSUpdate.ts` with query + mutation hooks
</must_haves>

```typescript
/**
 * COGS Bulk Price Update page.
 * Two tabs: Ingredients and Packaging Materials.
 * Editable grid with live costPerBaseUnit preview and batch save.
 */
import { useState, useMemo, useCallback } from 'react';
import { PageHeader } from '@/components/layout/PageHeader';
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@/components/ui/tabs';
import { Input } from '@/components/ui/input';
import { Button } from '@/components/ui/button';
import { Save, Loader2, Undo2 } from 'lucide-react';
import { formatCurrency, cn } from '@/lib/utils';
import {
  useIngredientsForBulkEdit,
  useMaterialsForBulkEdit,
  useBulkUpdateIngredientPrices,
  useBulkUpdateMaterialPrices,
} from '@/hooks/convex/useCOGSUpdate';
import type { Id } from '../../convex/_generated/dataModel';

// --- Cost calculation (mirrors backend costCalculator.ts) ---

function normalizeToBaseUnit(quantity: number, unit: string): number {
  if (unit === 'kg' || unit === 'l') return quantity * 1000;
  if (unit === 'm') return quantity * 100;
  return quantity;
}

function getBaseUnit(unitType: string): string {
  if (unitType === 'kg' || unitType === 'g') return 'g';
  if (unitType === 'l' || unitType === 'ml') return 'ml';
  if (unitType === 'm' || unitType === 'cm') return 'cm';
  return unitType;
}

function calcCostPerBaseUnit(
  priceExclShipping: number,
  shippingCost: number,
  volumePurchased: number,
  unitType: string
): number {
  const totalCost = priceExclShipping + shippingCost;
  const baseVolume = normalizeToBaseUnit(volumePurchased, unitType);
  if (baseVolume <= 0) return 0;
  return totalCost / baseVolume;
}

// --- Types ---

interface PriceEdit {
  priceExclShipping?: number;
  volumePurchased?: number;
  shippingCost?: number;
}

type EditMap = Record<string, PriceEdit>;

// --- Editable Grid Component ---

interface GridItem {
  _id: string;
  name: string;
  unitType: string;
  baseUnit: string;
  priceExclShipping: number;
  volumePurchased: number;
  shippingCost: number;
  costPerBaseUnit: number;
}

function BulkEditGrid({
  items,
  edits,
  onEdit,
  isLoading,
}: {
  items: GridItem[];
  edits: EditMap;
  onEdit: (id: string, field: keyof PriceEdit, value: number) => void;
  isLoading: boolean;
}) {
  return (
    <div className="overflow-x-auto">
      <table className="w-full text-sm">
        <thead>
          <tr className="border-b text-left text-muted-foreground">
            <th className="py-2 pr-3 font-medium">Name</th>
            <th className="py-2 pr-3 font-medium w-16">Unit</th>
            <th className="py-2 pr-3 font-medium w-36 text-right">Price (excl. ship)</th>
            <th className="py-2 pr-3 font-medium w-28 text-right">Volume</th>
            <th className="py-2 pr-3 font-medium w-32 text-right">Shipping</th>
            <th className="py-2 font-medium w-36 text-right">Cost/Base Unit</th>
          </tr>
        </thead>
        <tbody>
          {items.map((item) => {
            const edit = edits[item._id];
            const currentPrice = edit?.priceExclShipping ?? item.priceExclShipping;
            const currentVolume = edit?.volumePurchased ?? item.volumePurchased;
            const currentShipping = edit?.shippingCost ?? item.shippingCost;
            const liveCost = calcCostPerBaseUnit(currentPrice, currentShipping, currentVolume, item.unitType);
            const isDirty = !!edit;
            const costChanged = Math.abs(liveCost - item.costPerBaseUnit) > 0.001;

            return (
              <tr
                key={item._id}
                className={cn(
                  'border-b transition-colors',
                  isDirty && 'bg-amber-50 dark:bg-amber-950/20'
                )}
              >
                <td className="py-2 pr-3 font-medium">{item.name}</td>
                <td className="py-2 pr-3 text-muted-foreground">{item.unitType}</td>
                <td className="py-2 pr-3">
                  <Input
                    type="number"
                    min={0}
                    step="any"
                    value={currentPrice}
                    onChange={(e) => onEdit(item._id, 'priceExclShipping', parseFloat(e.target.value) || 0)}
                    className="h-8 text-right tabular-nums w-full"
                    disabled={isLoading}
                  />
                </td>
                <td className="py-2 pr-3">
                  <Input
                    type="number"
                    min={0}
                    step="any"
                    value={currentVolume}
                    onChange={(e) => onEdit(item._id, 'volumePurchased', parseFloat(e.target.value) || 0)}
                    className="h-8 text-right tabular-nums w-full"
                    disabled={isLoading}
                  />
                </td>
                <td className="py-2 pr-3">
                  <Input
                    type="number"
                    min={0}
                    step="any"
                    value={currentShipping}
                    onChange={(e) => onEdit(item._id, 'shippingCost', parseFloat(e.target.value) || 0)}
                    className="h-8 text-right tabular-nums w-full"
                    disabled={isLoading}
                  />
                </td>
                <td className={cn(
                  'py-2 text-right tabular-nums font-mono text-xs',
                  costChanged && 'text-amber-600 dark:text-amber-400 font-semibold'
                )}>
                  {formatCurrency(liveCost)}/{getBaseUnit(item.unitType)}
                </td>
              </tr>
            );
          })}
        </tbody>
      </table>
    </div>
  );
}

// --- Main Page ---

export function COGSUpdate() {
  const ingredients = useIngredientsForBulkEdit();
  const materials = useMaterialsForBulkEdit();
  const { mutate: bulkUpdateIngredients } = useBulkUpdateIngredientPrices();
  const { mutate: bulkUpdateMaterials } = useBulkUpdateMaterialPrices();

  const [activeTab, setActiveTab] = useState<'ingredients' | 'materials'>('ingredients');
  const [ingredientEdits, setIngredientEdits] = useState<EditMap>({});
  const [materialEdits, setMaterialEdits] = useState<EditMap>({});
  const [isSaving, setIsSaving] = useState(false);

  const handleEdit = useCallback(
    (editMap: EditMap, setEditMap: React.Dispatch<React.SetStateAction<EditMap>>, sourceItems: GridItem[] | undefined) =>
      (id: string, field: keyof PriceEdit, value: number) => {
        const source = sourceItems?.find((i) => i._id === id);
        if (!source) return;

        setEditMap((prev) => {
          const existing = prev[id] ?? {};
          const updated = { ...existing, [field]: value };

          // Check if all edited fields match the original — if so, remove the edit entry
          const isStillDirty = (
            (updated.priceExclShipping !== undefined && updated.priceExclShipping !== source.priceExclShipping) ||
            (updated.volumePurchased !== undefined && updated.volumePurchased !== source.volumePurchased) ||
            (updated.shippingCost !== undefined && updated.shippingCost !== source.shippingCost)
          );

          if (!isStillDirty) {
            const { [id]: _, ...rest } = prev;
            return rest;
          }

          return { ...prev, [id]: updated };
        });
      },
    []
  );

  const ingredientEditHandler = useMemo(
    () => handleEdit(ingredientEdits, setIngredientEdits, ingredients as GridItem[] | undefined),
    [handleEdit, ingredientEdits, ingredients]
  );

  const materialEditHandler = useMemo(
    () => handleEdit(materialEdits, setMaterialEdits, materials as GridItem[] | undefined),
    [handleEdit, materialEdits, materials]
  );

  const ingredientChangeCount = Object.keys(ingredientEdits).length;
  const materialChangeCount = Object.keys(materialEdits).length;
  const currentChangeCount = activeTab === 'ingredients' ? ingredientChangeCount : materialChangeCount;

  const handleSave = useCallback(async () => {
    setIsSaving(true);
    try {
      if (activeTab === 'ingredients' && ingredientChangeCount > 0) {
        const changes = Object.entries(ingredientEdits).map(([id, edit]) => ({
          id: id as Id<"ingredients">,
          ...edit,
        }));
        await bulkUpdateIngredients({ changes });
        setIngredientEdits({});
      } else if (activeTab === 'materials' && materialChangeCount > 0) {
        const changes = Object.entries(materialEdits).map(([id, edit]) => ({
          id: id as Id<"packagingMaterials">,
          ...edit,
        }));
        await bulkUpdateMaterials({ changes });
        setMaterialEdits({});
      }
    } finally {
      setIsSaving(false);
    }
  }, [activeTab, ingredientEdits, materialEdits, ingredientChangeCount, materialChangeCount, bulkUpdateIngredients, bulkUpdateMaterials]);

  const handleReset = useCallback(() => {
    if (activeTab === 'ingredients') {
      setIngredientEdits({});
    } else {
      setMaterialEdits({});
    }
  }, [activeTab]);

  const isLoading = ingredients === undefined || materials === undefined;

  return (
    <div className="space-y-4">
      <PageHeader
        title="COGS Update"
        description="Bulk edit ingredient and packaging material costs"
      />

      <Tabs value={activeTab} onValueChange={(v) => setActiveTab(v as 'ingredients' | 'materials')}>
        <div className="flex items-center justify-between gap-4 flex-wrap">
          <TabsList>
            <TabsTrigger value="ingredients">
              Ingredients
              {ingredientChangeCount > 0 && (
                <span className="ml-1.5 inline-flex items-center justify-center rounded-full bg-amber-500 text-white text-xs font-medium h-5 min-w-5 px-1">
                  {ingredientChangeCount}
                </span>
              )}
            </TabsTrigger>
            <TabsTrigger value="materials">
              Packaging Materials
              {materialChangeCount > 0 && (
                <span className="ml-1.5 inline-flex items-center justify-center rounded-full bg-amber-500 text-white text-xs font-medium h-5 min-w-5 px-1">
                  {materialChangeCount}
                </span>
              )}
            </TabsTrigger>
          </TabsList>

          <div className="flex items-center gap-2">
            {currentChangeCount > 0 && (
              <Button variant="outline" size="sm" onClick={handleReset} disabled={isSaving}>
                <Undo2 className="h-4 w-4 mr-1" />
                Reset
              </Button>
            )}
            <Button
              size="sm"
              onClick={handleSave}
              disabled={currentChangeCount === 0 || isSaving}
            >
              {isSaving ? (
                <Loader2 className="h-4 w-4 mr-1 animate-spin" />
              ) : (
                <Save className="h-4 w-4 mr-1" />
              )}
              Save {currentChangeCount > 0 ? `(${currentChangeCount})` : ''}
            </Button>
          </div>
        </div>

        {isLoading ? (
          <div className="flex items-center justify-center py-12 text-muted-foreground">
            <Loader2 className="h-5 w-5 animate-spin mr-2" />
            Loading...
          </div>
        ) : (
          <>
            <TabsContent value="ingredients" className="mt-4">
              <BulkEditGrid
                items={ingredients as GridItem[]}
                edits={ingredientEdits}
                onEdit={ingredientEditHandler}
                isLoading={isSaving}
              />
              {ingredients.length === 0 && (
                <p className="text-center text-muted-foreground py-8">No ingredients found.</p>
              )}
            </TabsContent>

            <TabsContent value="materials" className="mt-4">
              <BulkEditGrid
                items={materials as GridItem[]}
                edits={materialEdits}
                onEdit={materialEditHandler}
                isLoading={isSaving}
              />
              {materials.length === 0 && (
                <p className="text-center text-muted-foreground py-8">No packaging materials found.</p>
              )}
            </TabsContent>
          </>
        )}
      </Tabs>
    </div>
  );
}
```

Key design decisions:
- Live cost preview: `calcCostPerBaseUnit()` mirrors the backend formula exactly (same unit conversions)
- Dirty tracking: editing a value back to its original removes it from the edit map (auto-revert)
- Amber highlight on changed rows for visual feedback
- Change count badge on both tab triggers and save button
- Reset button to discard all changes on the active tab
- Saving only submits the active tab's changes
