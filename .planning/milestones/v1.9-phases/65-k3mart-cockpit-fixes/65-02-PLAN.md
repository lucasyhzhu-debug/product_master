# Plan 65-02: Frontend — Wire price, remove history UI, clean hooks

<objective>
Four frontend changes:
1. (K3M-01) Pass `price` from the product data through to the `submitStockFlow` call in `K3MartCockpit.tsx`, so the backend receives the correct product price.
2. (K3M-01) Add an editable price field to `StockFlowForm.tsx` so users can see and override the price before submission. Pre-populate from product data (which comes from K3MART_CONFIG.productMap).
3. (K3M-02) Remove `StockMovementHistory.tsx` component, strip it from `ExpandedOutletPanel.tsx`, `OutletCardGrid.tsx`, barrel index, and remove the `useFetchStockFlowHistory`, `useFetchStockFlowDetail`, and `useStockMovementHistory` hooks.
4. (K3M-03) No frontend changes needed — outlets are filtered by `isActive` in backend queries already. Running the `deactivateStaleOutlets` mutation (from Plan 65-01) will automatically hide stale outlets.
</objective>

```typescript
// Editable price field
const renderPriceField = (idSuffix: string) => {
  const currentPrice = priceOverride ?? selectedProduct?.price ?? 0;
  return (
    <div className="space-y-1.5">
      <Label htmlFor={`price-${idSuffix}`} className="text-xs text-muted-foreground">
        Price per unit (IDR)
      </Label>
      <Input
        id={`price-${idSuffix}`}
        type="number"
        min="0"
        step="1000"
        value={currentPrice}
        onChange={(e) => {
          const val = parseInt(e.target.value) || 0;
          setPriceOverride(val);
        }}
        className="h-9 text-sm tabular-nums"
        disabled={isSubmitting}
      />
      {currentPrice <= 0 && (
        <p className="text-xs text-red-500">
          Price cannot be 0. Set the correct price before submitting.
        </p>
      )}
    </div>
  );
};
```
