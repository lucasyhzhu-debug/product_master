Create `src/components/dispatchPlanner/ChannelSettingsDialog.tsx` -- a Dialog component opened via gear icon.

**Layout:** shadcn Dialog with Tabs or sections:

**Section 1: Channel Priorities**
- List of channels (Direct Sales, GoFood, K3Mart, Other Consignment)
- Each row: color swatch, channel name, up/down arrow buttons to reorder (simpler than drag-and-drop per research recommendation -- 4 items don't need full DnD)
- Top of list = highest priority (priority 1)
- When user clicks up/down, call `useDispatchReorderPriorities` with the new ordered array
- Show current priority number next to each channel

**Section 2: Channel Settings**
- For each channel, show:
  - Enable/disable toggle (Switch component)
  - Commission rate input (number, percentage, e.g., 19%)
  - Display name (editable text input)
- Save on blur or with a Save button per row
- Use `useDispatchUpdateChannelConfig` for each change

**Section 3: Consignment Outlets**
- List of existing consignment outlets with name, enabled toggle
- "Add Outlet" button opens inline form:
  - Name input
  - Commission rate override (optional number input)
  - Product mapping table: rows of [Menu Product dropdown] -> [External Name input] + [External Price input]
  - Menu product dropdown populated from `useQuery(api.menuProducts.list)` or equivalent existing hook
- Edit existing outlet: click to expand, same fields as add
- Delete outlet: trash icon with ConfirmDialog
- Use `useDispatchAddConsignmentOutlet`, `useDispatchUpdateConsignmentOutlet`, `useDispatchRemoveConsignmentOutlet`

**Section 4: Daily Capacity**
- Single number input for daily capacity (default 200)
- Save button
- Use `useDispatchUpdateSettings`

**Component props:**
```typescript
interface ChannelSettingsDialogProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
}
```
