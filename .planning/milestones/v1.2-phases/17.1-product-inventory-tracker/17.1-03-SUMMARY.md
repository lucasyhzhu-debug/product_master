# Phase 17.1 Plan 03: Finished Goods Inventory UI Summary

**One-liner:** 3-tab InventoryManager with FinishedGoodsTab, per-product stock cards, FG add/adjust dialogs, paginated transaction log, and collapsible settings panel.

## What Was Built

### Task 1: useProductInventory Hook + InventoryManager 3-Tab Layout

Created `src/hooks/convex/useProductInventory.ts` with two hooks:

- **`useProductInventory(locationId?)`** — wraps `getStockOverview`, `getLowStockAlerts`, `getSettings`, `addStock`, `adjustStock`, `updateSettings`
- **`useProductInventoryTransactions(filters)`** — paginated query via `usePaginatedQuery` with `initialNumItems: 20`, filters for `menuProductId`, `locationId`, `transactionType`

Exported `ProductStockRow`, `ProductLowStockAlert`, `ProductInventorySettings`, `ProductStockGroup` types from the hook file, and all from the barrel `src/hooks/convex/index.ts`.

Updated `src/pages/InventoryManager.tsx` from a 2-level tab system (category sub-tabs only) to a 3-tab top-level layout:
- **Packaging** — existing packaging inventory view unchanged
- **Ingredients** — existing production/ingredient inventory view unchanged
- **Finished Goods** — new `<FinishedGoodsTab />` component

Loading state guard now skips for the `finished_goods` tab (it fetches its own data internally). The "New Stock Type" button in PageHeader is hidden when on the finished_goods tab.

### Task 2: FinishedGoodsTab + Supporting UI Components

**`FinishedGoodsTab.tsx`**
- Low-stock alert banner (red bg, AlertTriangle icon, product pills)
- Action bar: "Add Stock" button (all roles), "Settings" toggle (manager/admin)
- Product stock grid: 2-col desktop, 1-col mobile — renders `ProductStockCard` per product group
- Inline settings Card: global low-stock threshold, default add-stock location, auto-advance toggle (admin), alert mode select (admin)
- Collapsible "Recent Transactions" section using `TransactionLogPanel`
- Empty state with prompt to add first stock

Client-side grouping logic: `stockOverview` rows grouped by `menuProductId` into `ProductStockGroup[]`, sorted low-stock-first then alphabetically.

**`FGAddStockDialog.tsx`**
- Staff-friendly: product selector (skipped if preselected), "How many boxes?" quantity input, location selector
- Calls `addStock({ token, menuProductId, locationId, quantity })`
- Success toast: "Added {qty} x {productName} to {locationName}"

**`FGAdjustStockDialog.tsx`**
- Manager-only: product (preselected or selector), location, Add/Remove toggle buttons, quantity, required reason textarea
- Positive quantity for add, negative for remove
- Calls `adjustStock({ token, menuProductId, locationId, quantity: signed, reason })`
- Destructive variant button for Remove mode

**`ProductStockCard.tsx`**
- Header: product name + total stock Badge (red/amber/emerald based on negative/low/ok)
- Per-location rows with quantity, "(low)" and "(neg)" inline labels
- "Negative stock" warning paragraph when total < 0
- Action buttons: "Add Stock" (all), "Adjust" (manager/admin only), "History" (expand toggle)
- Collapsible per-product transaction history via `TransactionLogPanel`
- Border/background color-coded: red-400/red-50 for negative, amber-300/amber-50 for low-stock

**`TransactionLogPanel.tsx`**
- TX_CONFIG record: add (emerald), drawdown (blue), gofood_sale (purple), adjust (amber)
- Each row: type icon, type badge, signed quantity (green +/red -), location, reason/gofood ref, performer (system:gobiz_sync displayed as "sync"), formatted timestamp
- "Load more" button when `status === "CanLoadMore"`
- Loading skeleton and empty state
