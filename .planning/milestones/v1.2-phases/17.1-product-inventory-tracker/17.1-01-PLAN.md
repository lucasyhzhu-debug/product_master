  <action>
Add 3 new tables to convex/schema.ts:

**1. productInventory** — Simple aggregate stock per product per location (NOT FIFO batch tracking):
```
productInventory: defineTable({
  menuProductId: v.id("menuProducts"),
  locationId: v.id("storageLocations"),
  quantity: v.number(),           // Current stock count (boxes). Can go negative for GoFood.
  lowStockThreshold: v.optional(v.number()),  // Per-product-location override (null = use global)
  lastUpdated: v.number(),
})
  .index("by_menu_product", ["menuProductId"])
  .index("by_location", ["locationId"])
  .index("by_product_location", ["menuProductId", "locationId"])
```

**2. productInventoryTransactions** — Full audit trail:
```
productInventoryTransactions: defineTable({
  menuProductId: v.id("menuProducts"),
  locationId: v.id("storageLocations"),
  transactionType: v.union(
    v.literal("add"),            // Kitchen adds stock
    v.literal("drawdown"),       // Order fulfilment drawdown
    v.literal("gofood_sale"),    // GoFood sync auto-deduction
    v.literal("adjust"),         // Manager adjustment (spoilage, correction, transfer)
  ),
  quantity: v.number(),           // + for add/adjust-up, - for drawdown/adjust-down
  previousQuantity: v.number(),
  newQuantity: v.number(),
  orderId: v.optional(v.id("orders")),
  gofoodOrderRef: v.optional(v.string()),
  reason: v.optional(v.string()),  // For adjustments
  performedBy: v.string(),
  createdAt: v.number(),
})
  .index("by_product_location", ["menuProductId", "locationId", "createdAt"])
  .index("by_location", ["locationId", "createdAt"])
  .index("by_order", ["orderId"])
  .index("by_type", ["transactionType", "createdAt"])
```

**3. productInventorySettings** — Global config (single-row pattern):
```
productInventorySettings: defineTable({
  globalLowStockThreshold: v.number(),    // Default 5
  defaultAddLocationId: v.optional(v.id("storageLocations")),
  autoAdvanceOnDrawdown: v.boolean(),     // Default true
  alertMode: v.union(v.literal("toast"), v.literal("toast_and_badge")),
  updatedBy: v.string(),
  updatedAt: v.number(),
})
```

**Create `convex/productInventory/mutations.ts`** with these mutations:

1. **addStock** — Kitchen/staff adds finished goods to a location:
   - Args: `token: v.string(), menuProductId: v.id("menuProducts"), locationId: v.id("storageLocations"), quantity: v.number()`
   - Auth: requireRole with ["kitchen", "order_staff", "manager", "admin"]
   - Behavior: Upsert productInventory row (create if not exists, increment quantity if exists). Log transaction with type "add", previousQuantity, newQuantity. Return { newQuantity }.
   - Validate: quantity > 0, menuProduct exists, location exists and isActive.

2. **adjustStock** — Manager adjustment (spoilage, correction, transfer):
   - Args: `token: v.string(), menuProductId: v.id("menuProducts"), locationId: v.id("storageLocations"), quantity: v.number(), reason: v.string()`
   - Auth: requireRole with ["manager", "admin"] only
   - Behavior: quantity can be positive (add) or negative (subtract). Update productInventory row. Log transaction with type "adjust", reason field populated. Return { newQuantity }.
   - Validate: reason is non-empty string. If quantity is negative and would cause stock < 0, allow it (manager override) but include a note in the transaction.

3. **initializeSettings** — Creates the settings row if none exists (internal mutation):
   - No auth (internal only — `internalMutation`)
   - Defaults: globalLowStockThreshold = 5, autoAdvanceOnDrawdown = true, alertMode = "toast"
   - Only inserts if no row exists. Returns the settings row.

4. **updateSettings** — Update config:
   - Args: `token: v.string(), globalLowStockThreshold: v.optional(v.number()), defaultAddLocationId: v.optional(v.id("storageLocations")), autoAdvanceOnDrawdown: v.optional(v.boolean()), alertMode: v.optional(v.union(v.literal("toast"), v.literal("toast_and_badge")))`
   - Auth: requireRole with ["admin"]
   - Behavior: Patch the single settings row. If no row exists, create with defaults then patch.

<task type="auto">
  <name>Task 3: Stock overview and transaction log queries</name>
  <files>convex/productInventory/queries.ts</files>
  <action>
**Create `convex/productInventory/queries.ts`** with these queries:

1. **getStockOverview** — Returns all product inventory rows with joined menuProduct and location data:
   - Args: `locationId: v.optional(v.id("storageLocations"))` (optional filter)
   - Returns array of `{ _id, menuProduct: { _id, name, posSlot, ... }, location: { _id, name, locationType }, quantity, lowStockThreshold, isLowStock: boolean, lastUpdated }`
   - isLowStock: quantity <= (row.lowStockThreshold ?? globalThreshold ?? 5)
   - Load the global threshold from productInventorySettings first. If no settings row, default to 5.
   - Sort by menuProduct.name alphabetically.

2. **getTransactions** — Transaction log with pagination:
   - Args: `menuProductId: v.optional(v.id("menuProducts")), locationId: v.optional(v.id("storageLocations")), transactionType: v.optional(v.string()), paginationOpts: paginationOptsValidator`
   - Use Convex `.paginate()` pattern (see existing `getLocationTransactionsPaginated` in `convex/inventory/queries.ts` for reference)
   - Join menuProduct name and location name into each result.
   - Order by createdAt descending (most recent first).

3. **getLowStockAlerts** — Returns all product-location pairs below threshold:
   - No args (loads all)
   - Returns only rows where isLowStock is true (same logic as getStockOverview)
   - Includes menuProduct name and location name in results.

4. **getSettings** — Returns the productInventorySettings row (or null):
   - No args.
   - Returns the first (and only) row from productInventorySettings, or null if not initialized.

5. **getStockForOrder** — Given an orderId and locationId, returns availability for each order item:
   - Args: `orderId: v.id("orders"), locationId: v.id("storageLocations")`
   - Loads order items, for each with a menuProductId, queries productInventory for stock at that location.
   - Returns array of `{ orderItemId, menuProductId, productName, quantityNeeded, quantityAvailable, isSufficient }`
   - This powers the drawdown UI showing what's available before confirming.
  </action>
