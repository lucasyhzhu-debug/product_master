**Create `src/components/orders/FulfillFromInventoryButton.tsx`:**

This component encapsulates the entire drawdown flow:

**Props:**
- `orderId: Id<"orders">`
- `orderStatus: string`
- `token: string`

**Visibility:** Only renders when orderStatus === "PaymentReceived". Otherwise returns null.
> **Status mapping:** CONTEXT.md says "status = Confirmed" — the user-facing name. Phase 14 renamed the enum value to `PaymentReceived` (`convex/schema.ts` line 306: `// Was "Confirmed"`). Always check against `"PaymentReceived"` in code.

**States:**
- `showPanel: boolean` — toggles the InventoryAvailabilityPanel
- `selectedLocationId: Id<"storageLocations"> | null`
- `isSubmitting: boolean`

**UI Flow:**
1. **Initial state**: A prominent button: "Use Available Inventory" with Package icon (from lucide-react). Styled with variant="outline" or a distinctive secondary style so it doesn't compete with the primary status action buttons. Place it in a Card below the status actions section.

2. **On click**: Sets showPanel = true, revealing the InventoryAvailabilityPanel.

3. **Panel shows**:
   - Location selector (shadcn Select) listing active storageLocations with stock. Default to the system default location (from productInventorySettings).
   - InventoryAvailabilityPanel below showing per-item availability.
   - "Confirm Fulfillment" button (disabled if any item is insufficient or no location selected).
   - "Cancel" button to hide the panel.

4. **On confirm**: Call fulfillFromInventory mutation. Handle:
   - **Success**: Toast "Order fulfilled from inventory! Status: Awaiting Delivery". Hide panel. (The backend advances to AwaitingDelivery regardless of deliveryType — Phase 14 unified WaitingShipment/WaitingPickup into this single status.)
   - **Error (insufficient_stock)**: Parse the ConvexError, show red alert with per-item shortages (productName: need X, have Y).
   - **Error (other)**: Toast error message.

**Create `src/components/orders/InventoryAvailabilityPanel.tsx`:**

**Props:**
- `orderId: Id<"orders">`
- `locationId: Id<"storageLocations"> | null`

Uses `useQuery(api.productInventory.queries.getStockForOrder, locationId ? { orderId, locationId } : "skip")`.

**Renders:**
- Loading skeleton while query loads.
- If no location selected: "Select a location to check availability" message.
- Table/list of order items with columns: Product Name | Needed | Available | Status
- Status column: green checkmark + "OK" if available >= needed, red X + "Short by {diff}" if not.
- Summary at bottom: "All items available" (green) or "X items short" (red).
