## Decisions Made
- **Component location**: Placed in `src/components/inventory/` not `src/components/orders/` — the button is about inventory operations triggered from the order page, not an order management concern
- **Inner component pattern**: `FulfillFromInventoryButton` outer component returns null for non-PaymentReceived orders; `FulfillFromInventoryPanel` inner component contains all hooks — this avoids React hooks ordering violation from conditional early return
- **Pre-mutation availability check**: Confirm button is disabled when any item is short based on getStockForOrder query result, avoiding a doomed mutation call
- **ConvexError handling**: Catch ConvexError, parse `.data.type === 'insufficient_stock'` and `.data.shortages` array for per-item display; fall through to generic toast for other errors
