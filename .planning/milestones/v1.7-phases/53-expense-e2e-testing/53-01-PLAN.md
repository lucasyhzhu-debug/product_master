**Part B: Add loginAsRole to helpers.ts**

Add a `TestRole` type and `loginAsRole` function:

```typescript
export type TestRole = 'admin' | 'manager' | 'kitchen' | 'order_staff';

const ROLE_USER_NAMES: Record<TestRole, string> = {
  admin: 'E2E-Admin',
  manager: 'E2E-Manager',
  kitchen: 'E2E-Kitchen',
  order_staff: 'E2E-OrderStaff',
```

`loginAsRole(page, role)` implementation:
1. Navigate to /login with waitUntil: "networkidle"
2. Wait for avatar grid: `button:has(.rounded-full)` with 15s timeout
3. Find the button matching ROLE_USER_NAMES[role] using `page.locator("button").filter({ hasText: targetName }).first()`
4. Click the user button
5. Wait for PIN pad: `button:has-text('Sign In')` with 5s timeout
6. Enter PIN "999999" digit by digit using `.grid.grid-cols-3 button` filter
7. Click "Sign In"
8. Wait for URL to leave /login (15s timeout)
9. Call waitForAppReady(page)

Keep existing `loginAsManager` function unchanged for backward compat with 12 existing spec files.

**Part C: Add logout helper**

`logout(page)` implementation:
1. Clear localStorage and sessionStorage: `page.evaluate(() => { localStorage.clear(); sessionStorage.clear(); })`
2. Navigate to /login with waitUntil: "networkidle"
3. Wait for avatar grid to appear (confirms we're on login page): `button:has(.rounded-full)` with 10s timeout

This is the simplest reliable approach per research findings (no /logout route exists).

**Part D: Add fillExpenseForm helper**

```typescript
export async function fillExpenseForm(page: Page, data: {
  description: string;
  amount: string;
  vendorName: string;
  glCategory?: string; // text to match in select, e.g., "Office & Supplies"
  paymentMethod?: string; // "personal" or "company_card"
}) {
  await page.locator("#description").fill(data.description);
  await page.locator("#amount").fill(data.amount);
  await page.locator("#vendorName").fill(data.vendorName);

  if (data.glCategory) {
    await page.locator("#accountId").click();
    await page.locator('[role="option"]').filter({ hasText: data.glCategory }).click();
  }

  if (data.paymentMethod) {
    await page.locator("#paymentMethod").click();
    await page.locator('[role="option"]').filter({ hasText: new RegExp(data.paymentMethod, 'i') }).click();
  }
}
```
