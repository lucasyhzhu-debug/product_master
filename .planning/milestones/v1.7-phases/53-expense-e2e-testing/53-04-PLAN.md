**IMPORTANT: Use relative date calculation, not hardcoded dates.** This ensures the test works regardless of when it runs.

```typescript
// Calculate a date that is guaranteed to be > 14 days ago
const now = new Date();
const lateDate = new Date(now.getTime() - 20 * 24 * 60 * 60 * 1000); // 20 days ago

```
