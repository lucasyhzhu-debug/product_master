<objective>
Add backward-compatible metadata support to the journal engine for storing receipt URLs from historical CSV imports.

Purpose: The journal engine is the single gate for all JE creation (JE-06). Extending it to accept optional metadata enables the historical import mutation (Plan 02) to persist Google Drive receipt links from employee expense forms without polluting the description field.

Output: Schema with `metadata` optional field on `journalEntries`, and `CreateJournalEntryParams` extended to accept and spread it into the DB insert.
</objective>
