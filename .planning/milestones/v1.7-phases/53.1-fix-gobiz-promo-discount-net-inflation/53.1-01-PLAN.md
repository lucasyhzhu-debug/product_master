<objective>
Fix the two backend bugs causing GoFood promo discount net revenue inflation in Sales Analytics.

Bug 1 (P0): `aggregatePlatformChannel` in dashboardHelpers.ts recalculates net from `gross - commission - adBurn - promoBurn` instead of using the stored `revenueNet` field. Fix to sum `revenueNet` directly, with fallback to `revenueGross` for records where `revenueNet` is null.

Bug 2 (P1): `extractJournalMetrics` in gobiz/helpers.ts does not extract `variables.voucher_amount` from journal API responses. Add `promoDiscount` to `JournalMetrics`, extract it during sync, and pass it through the adapter to store as `promoBurn` on `externalRevenue`.

Purpose: GoFood promo orders (Legato Gelato campaign 596f5dc6) overstate net revenue by 29-66% per order. This fix corrects all GoFood net values immediately (Bug 1) and enables promo discount visibility for future synced records (Bug 2).

Output: Fixed backend aggregation + extraction, new test file for dashboardHelpers, extended test cases for gobiz helpers.
</objective>
