# Requirements: Frollie Recipe Master

**Defined:** 2026-04-08
**Core Value:** Production reliability -- single source of truth for recipes, orders, kitchen production, and inventory

## v2.0 Requirements

Requirements for milestone v2.0 Financial Management & Data Quality. Each maps to roadmap phases.

### Data Accuracy Foundation

- [x] **DA-01**: Direct sales orders flow into `externalRevenue` bridge so P&L includes all revenue sources (Revenue Recognition Fix)
- [x] **DA-02**: Historical direct sales orders are backfilled into revenue bridge for accurate past-period P&L
- [x] **DA-03**: Manager can set a flat COGS override per menu product that bypasses BOM calculation
- [x] **DA-04**: Employee profile includes hire date, base rate, and bank account holder name fields

### Financial Reporting

- [x] **FIN-01**: Income Statement extends from Net Income through Depreciation/Amortization, CapEx, to Free Cash Flow
- [x] **FIN-02**: Per-channel breakdown continues through the full P&L flow (Revenue -> FCF)
- [x] **FIN-03**: User can export raw financial transactions (revenue + journal entries) as CSV for a date range
- [x] **FIN-04**: User can export P&L summary as CSV for weekly/monthly/custom range

### Expense Management

- [x] **EXP-01**: User can bulk upload expenses via CSV that creates actual expense records (not raw journal entries)
- [x] **EXP-02**: Bulk upload supports auto-approve mode (expenses created as recorded with JEs) for trusted batches
- [x] **EXP-03**: Bulk upload supports submit-for-approval mode (expenses created as submitted, routed through approval queue)
- [x] **EXP-04**: Fixed asset disposal supports "Reclassify to Expense" type that reverses capitalization and books as operating expense

### Bank Reconciliation

- [x] **BANK-01**: User can upload BCA or Mandiri bank statement CSV with format auto-detection
- [x] **BANK-02**: System auto-matches bank lines to expenses/revenue/reimbursements by amount + date + description
- [x] **BANK-03**: User can manually match/unmatch bank lines to system records via split-view UI
- [x] **BANK-04**: Reconciliation status tracked per statement (matched/unmatched/suggested counts)

### Staff Attendance

- [x] **ATT-01**: Kitchen staff can clock in/out via one-tap PIN-authenticated interface
- [x] **ATT-02**: Per-staff production tracking shows balls by type and grams from shift records
- [x] **ATT-03**: Monthly attendance summary with hours worked and production output per staff member
- [x] **ATT-04**: Manager can correct missed clock-outs with audit trail

### Data Health (DEFERRED to v2.1 — Phase 77)

Per v2.0 closeout decision (2026-05-10), Phase 77 (Data Health Dashboard) deferred to v2.1. Phase 76's deferred-items file punts orphan-JE detection to Phase 77 — the most concrete starting point. Phase 81's `resolvePlatform` + `confidence` return is the per-row primitive Phase 77 will consume.

- [ ] **DH-01**: Centralized data health page showing automated integrity checks across all data pipelines (deferred to v2.1)
- [ ] **DH-02**: Revenue completeness check (all active channels have data for current period) (deferred to v2.1)
- [ ] **DH-03**: COGS coverage check (percentage of products with non-zero COGS) (deferred to v2.1)
- [ ] **DH-04**: Journal balance validation (sum debits = sum credits across all entries) (deferred to v2.1)
- [ ] **DH-05**: Orphaned record detection (expenses without journals, orders without revenue) (deferred to v2.1)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Full payroll calculation engine | Indonesian labor law (BPJS, PPh 21, THR) too complex; manual payroll entry sufficient |
| Automated bank statement import via API | Requires corporate banking agreements; CSV upload sufficient for weekly reconciliation |
| AI-powered transaction categorization | Overkill for ~50-100 monthly transactions; rule-based matching sufficient |
| Multi-currency support | All operations in IDR; no foreign suppliers/customers |
| Budget vs. actual comparison | No budget input system exists; future milestone |
| Real-time bank balance tracking | Bank apps provide this; reconciliation shows discrepancies |
| Overtime/leave management | Clock-in/out sufficient for production tracking; HR features deferred |
| Monthly/quarterly P&L auto-generation | Custom date range export covers immediate need |
