<task id="33-05-01" title="Fix colSpan mismatch on desktop" priority="critical" consensus="3/5">

**Problem:** `SectionHeaderRow` and `ChannelRow` COGS sub-row use `colSpan={showComparison ? 4 : 2}`. On desktop, comparison columns are always visible via `md:table-cell` regardless of `showComparison`, so `colSpan=2` leaves 2 empty cells. Visually broken table layout on every desktop render.

**Files:**
- `src/lib/financialHelpers.tsx` line 173 — `SectionHeaderRow`
- `src/components/financials/ChannelRow.tsx` line 205 — COGS sub-row

**Changes:**
1. In `financialHelpers.tsx` `SectionHeaderRow`: change `colSpan={showComparison ? 4 : 2}` to `colSpan={4}`
2. In `ChannelRow.tsx` COGS sub-row: change `colSpan={showComparison ? 4 : 2}` to `colSpan={4}`
3. Remove `showComparison` prop from `SectionHeaderRow` if it was only used for colSpan

**Why safe:** HTML spec allows colSpan to exceed visible columns when some have `display: none`. Extra span is harmless when comparison columns are hidden.

</task>

<task id="33-05-02" title="Add CSV formula injection protection" priority="critical" consensus="1/5">

**Problem:** CSV escaping handles commas/quotes/newlines but not formula injection. Product names from user-editable data starting with `=`, `+`, `-`, `@` would execute as formulas in Excel/Google Sheets.

**File:** `src/lib/csvExport.ts` lines 383-397

**Changes:**
1. In the CSV cell escaping function, add formula prefix sanitization BEFORE the existing escaping logic:
```typescript
const sanitized = /^[=+\-@\t\r]/.test(str) ? "'" + str : str;
```
2. Use `sanitized` instead of `str` for the rest of the escaping logic

</task>

<task id="33-05-06" title="Add error handling to CSV export" priority="important" consensus="1/5">

**Problem:** CSV export onClick has no try/catch. Silent failure if generation throws. Also, `downloadCSV` doesn't append `<a>` to DOM, which may fail in Firefox.

**Files:**
- `src/pages/FinancialStatement.tsx` lines 106-111
- `src/lib/csvExport.ts` `downloadCSV` function

**Changes in FinancialStatement.tsx:**
1. Wrap CSV export onClick in try/catch:
   ```typescript
   onClick={() => {
     if (!data) return;
     try {
       const csv = generateIncomeStatementCSV(data, weekLabel);
       const wibDate = new Date(weekStart + WIB_OFFSET_MS);
       const dateStr = wibDate.toISOString().slice(0, 10);
       downloadCSV(csv, `frollie-income-statement-${dateStr}.csv`);
     } catch {
       toast.error("Failed to export CSV");
     }
   }}
   ```
2. Add `toast` import from `sonner` if not already imported

**Changes in csvExport.ts downloadCSV:**
1. Append link to DOM before click, remove after:
   ```typescript
   document.body.appendChild(link);
   link.click();
   document.body.removeChild(link);
   ```

</task>
