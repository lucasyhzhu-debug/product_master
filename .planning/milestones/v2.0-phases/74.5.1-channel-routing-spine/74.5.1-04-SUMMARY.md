## Decisions Made

- **Phase 78 helper reuse is NON-NEGOTIABLE.** SPEC Constraint 1 + RESEARCH §Don't Hand-Roll mandate verbatim reuse of `resolveSubstitutionPlan` and `createStockTracker`. Zero new stock-math logic was written. Pattern mirrors `processGofoodSales` at `convex/productInventory/mutations.ts:716-867`.
- **externalSource validator imported from `../schema`, not `../lib/externalSource`.** Convention followed across the codebase (see `convex/bankStatements/mutations.ts:35`, `convex/externalData/mutations.ts:5`). The lib module exports types + runtime guards; the schema module exports the Convex validator.
- **Helper queries in channelAudit.ts are ALL `internalQuery`, never `query`.** Invoked via `ctx.runQuery(internal.*)`. Public/admin-facing lists live in channelAuditMutations.ts behind `requireRole`. Avoids accidental client exposure of detail strings.
- **runFullAudit is `internalAction` not `internalMutation`.** A full-DB scan can exceed the 1-second mutation time limit. Action runs paginated loop; each page + issue-record call is a separate short mutation via `ctx.runMutation`.
