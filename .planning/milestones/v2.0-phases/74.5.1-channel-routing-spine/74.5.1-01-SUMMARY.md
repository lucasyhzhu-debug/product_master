# Phase 74.5.1 Plan 01: Schema Additions for Unified Channel Routing Spine — Summary

**One-liner:** Additive schema migration — 3 new tables (`channelRouting`, `channelAuditReports`, `channelAuditIssues`) + 3 modified tables (`productInventoryTransactions`, `productInventorySettings`, `externalRevenueItems`, `externalSyncLogs`) providing storage substrate for downstream 74.5.1 plans without any behavior change; existing `gofood_sale` literal fully preserved.

## What Shipped

### New Tables (3)

**1. `channelRouting`** — Admin-configurable storage-location routing per `(source, outlet?, product?)`. Backs `resolveChannelRoute()` 5-tier precedence (R2).

- Fields: `source`, `outletId?`, `menuProductId?`, `storageLocationId`, `isDefault`, `notes?`, `updatedBy`, `updatedAt`
- Indexes (4): `by_source`, `by_source_outlet`, `by_source_product`, `by_source_outlet_product`

**2. `channelAuditReports`** — Batch audit-scan result metadata; one row per `runFullAudit` invocation (R6).

- Fields: `status` ("pending"|"resolved"|"archived"), `totalItemsScanned`, `issuesFound`, `issuesByType` (5-key object), `startedAt`, `completedAt?`, `triggeredBy`
- Indexes (2): `by_status`, `by_startedAt`

**3. `channelAuditIssues`** — Per-item audit findings (R6). Each row = one detected issue.

- Fields: `reportId?`, `source`, `itemId?`, `revenueId?`, `issueType` (5 literals), `severity` ("warn"|"block"), `detail`, `detectedAt`, `resolvedAt?`, `resolvedBy?`, `resolution?`
- Indexes (4): `by_report`, `by_source_open`, `by_type_open`, `by_item`

### Modified Tables (3)

**4. `productInventoryTransactions`** — Added `channel_sale` literal + 2 new optional fields + 1 new index.

- NEW literal: `"channel_sale"` (alongside preserved `"gofood_sale"`)
- NEW fields: `source?: externalSource`, `externalRef?: string`
- NEW index: `by_source_externalRef` — duplicate-transaction audit key
- Existing 4 indexes preserved verbatim

**5. `productInventorySettings`** — Added `channelDeductionEnabled` optional 8-key flag map.

- All 8 keys: `bigseller`, `consignment`, `gobiz`, `grabfood`, `internal`, `k3mart`, `shopee`, `tiktok`
- Missing field coerces to all-false at read-time (per CONTEXT).

**6. `externalRevenueItems`** — Added `inventoryDeductedAt?: number` idempotency key (R3). Preserves 5 existing indexes.

**7. `externalSyncLogs`** — Added `itemsDeducted?: number` + `itemsSkipped?: number` deduction counters (R9).
