## What Changed

### `convex/externalData/mutations.ts`

**New imports (static, per Convex Pitfall #8):**
- `processChannelSaleInternal`, `buildEventFromRow` from `../productInventory/channelSale`
- `detectAuditIssuesForItem` from `../productInventory/channelAudit`

**`saveRevenueItemsImpl` (grown from ~40 LOC → ~120 LOC):**
1. Reads `productInventorySettings` ONCE at call start (single-row pattern).
2. Derives `dedupEnabled = flagMap?.[revenue.source] === true` — absent settings / absent field / absent key → `false`. This is the "ship-dark" contract: every flag defaults off until 74.5.2 flips them.
3. Preserves (revenueId, externalItemId) dedup guard verbatim.
4. Inserts `externalRevenueItems` with `inventoryDeductedAt: undefined` as a set-once idempotency marker.
5. Runs cheap audit detection inline (`detectAuditIssuesForItem`) — emits `unmapped_sku` + `malformed_item` issues with `reportId: undefined` (inline = no batch parent). Expensive checks (`stale_mapping`, `duplicate_transaction`, `orphan_item`) stay in `runFullAudit`.
6. Gates dispatch: flag ON → `linkedMenuProductId` set → `quantity > 0` → re-fetch item doc → build event → call `processChannelSaleInternal(ctx, event)`.
7. No try/catch. Atomicity contract: `CHANNEL_ROUTING_NOT_CONFIGURED` (or any throw) rolls back the ENTIRE mutation, including the revenue-item insert.
8. On `result.deducted === true`: patch `inventoryDeductedAt = Date.now()`, `deducted++`. Else `skipped++`.
9. Returns `{ids, inserted, deducted, skipped}` — four-field shape.

**`saveRevenueItems` internalMutation (handler line only):**
- Wraps the impl. STILL returns `result.ids: Id[]` only, for backward compat with existing callers (`bigsellerOrders/mutations.ts:288-292` destructures `.length`).
- Args validator UNCHANGED.

**`saveRevenueItemsWithCounts` internalMutation (NEW):**
- Identical args validator duplicated inline (Convex validators not reusable).
- Returns the full impl shape `{ids, inserted, deducted, skipped}`.
- Plan 06 Task 6.1 calls this EXCLUSIVELY for R9 counter wiring. Option A locked — no estimation path exists.

**1. [Rule 3 - Blocking] Wave 0 RED test file referenced `api.*` for an `internalMutation`**

**2. [Rule 3 - Blocking] Extraneous `source: "shopee"` top-level test arg rejected by strict Convex validator**

- **Issue:** Wave 0 RED tests passed `{ revenueId, source: "shopee", items: [...] }`. The plan explicitly locks the args validator to `{ revenueId, items }` only (impl derives source from the parent row). Convex's strict object validator rejects unknown fields → every test would throw `ArgumentValidationError`.

- **Files modified:** `convex/productInventory/__tests__/saveRevenueItemsHook.test.ts`
- **Commit:** `06acab42`
