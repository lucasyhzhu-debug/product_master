## Verification Criteria

### Backend (convex/expenses/queries.ts)
- `listAllExpenses` query exists and is role-restricted to `["admin"]`
- Status filter uses `by_status` index
- `submitterName` field populated via nameMap join
- Non-admin roles are rejected

### Frontend (src/pages/MyExpenses.tsx)
- Admin sees all expenses (not just own)
- Own expenses sorted to top
- Blue ring highlight (`ring-2 ring-blue-400`) applied to own expenses
- Toggle checkbox controls highlight
- Title changes to "All Expenses" for admin
- ApprovalActions shown in timeline panel for admin

### Component (src/components/expenses/ExpenseCard.tsx)
- Optional `submitterName`, `isMine`, `highlightMine` props accepted
- Backward compatible (no props = existing behavior)
- Highlight class applied when `isMine && highlightMine`

### Non-regression
- Non-admin users see only their own expenses (unchanged)
- Existing E2E tests pass: expense-approval, expense-lifecycle
- `npm run build` succeeds
