## Decisions Made

- **Internal-query wrapper over action-to-mutation refactor** — `syncK3MartSales` is an action (needs `fetch()` for K3Mart API). Keeping it as an action and bridging through `internalQuery` via `ctx.runQuery` preserves the existing sync architecture.
- **Record<string, string> serialization** — Convex cannot serialize `Map` across function boundaries. Converting to Record on the query side and rebuilding the Map in the action is the canonical pattern.
- **Did NOT inline `"k3mart"` literal in a new validator** (CLAUDE.md pitfall #11). The `args.source === "k3mart"` check in the cascade compares against the already-validated `sourceValidator` enum value — safe.
- **Import only `attachLinkedMenuProductId` in adapter, not `getK3MartMappingBySku`** — the adapter cannot call `getK3MartMappingBySku` directly (no `ctx.db` in actions). Importing it would be dead code; using `ctx.runQuery` is the required path.
