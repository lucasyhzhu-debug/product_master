# Phase 74.5.2 Plan 04: GoFood-Sale → Channel-Sale Migration Summary

Forward-only paginated migration action that rewrites every `productInventoryTransactions` row with `transactionType: "gofood_sale"` to `transactionType: "channel_sale"` + `source: "gobiz"`, preserving `gofoodOrderRef` and synthesizing `externalRef` for legacy compatibility; self-healing via `by_type` index filter narrowing, admin-gated through scheduler.

## Accomplishments

- **3 exports added to `convex/migrations/gofoodSaleToChannelSale.ts`:**
  - `migrateOnePage` (`internalMutation`) — 500-row chunked worker using `paginationOptsValidator`; patches `transactionType` → `"channel_sale"`, `source` → `"gobiz"`, `externalRef` → `gofoodOrderRef ?? "legacy-${_id}"`; returns `{migrated, isDone, continueCursor}`.
  - `migrateGofoodSaleToChannelSale` (`internalAction`) — cursor-loop runner; `MAX_PAGES=1000` safety cap (500K row ceiling); returns `{totalMigrated, pagesProcessed}`.
  - `runGofoodSaleToChannelSaleMigration` (`mutation`, admin-gated) — scheduler trigger, returns `{scheduled: true}` immediately; passes `user.name` as `triggeredBy`.
- **Self-healing idempotency:** the `by_type` index on `productInventoryTransactions` narrows to `transactionType === "gofood_sale"`, so patched rows (now `"channel_sale"`) fall out of the filter on re-run. Cross-invocation idempotency is filter-based, NOT cursor-persistence — documented inline with a "Self-heal invariant" comment (acceptance C3).
- **Critical landmine avoided:** `source: "gobiz"` (integration literal in `externalSource` union at `convex/lib/externalSource.ts:11`) is written — NOT `"gofood"` (surface name that does NOT exist in the union, would fail type-check). Three ASCII matches of `"gobiz"` (header doc + header doc + the actual patch call) confirm no drift.
- **Legacy compatibility preserved:** `gofoodOrderRef` field is NOT cleared on patched rows. `TransactionLogPanel.tsx` at lines 194–198 reads `tx.gofoodOrderRef` directly for its legacy display branch — preserving this keeps the reader fully functional after migration.
- **Strip-before-drop discipline:** the `"gofood_sale"` literal in the `productInventoryTransactions.transactionType` union at `convex/schema.ts:1015` is INTENTIONALLY RETAINED this phase. D74.5.2-L6 + D74.5.2-L8 mandate the drop is a separate follow-up phase (74.5.3) after the migration runs to zero remaining rows + 72h soak.
- **Admin-gated trigger:** `runGofoodSaleToChannelSaleMigration` calls `requireRole(ctx, args.token, ["admin"])` before scheduling the action (same shape as `runRoutingSeed` from 74.5.1).
