<objective>
Fix the Tamtem depot deduction silent failure by implementing auto-seed logic.

Purpose: `processGofoodSales` currently silently skips inventory deductions when an outlet has no `linkedStorageLocationId`. This means GoFood sales at Tamtem and Goldfinch outlets don't decrement product inventory, creating data integrity gaps. The fix auto-creates the depot storage location (and links it to the outlet) when missing, following the same pattern as `convex/migrations/seedFinishedGoodsLocations.ts`.

Output: Modified `processGofoodSales` mutation that auto-seeds depot locations instead of skipping, plus a shared helper and unit test.
</objective>

  if (!linkedLocationId) {
    // Auto-seed: create depot location and link outlet

      continue;

    linkedLocationId = autoSeeded;
    outletLocationCache.set(outletIdStr, linkedLocationId);
  }
