# Skill: /handover

## Purpose

Generate a structured handover document that allows a new Claude session to seamlessly continue work. Use this at the end of long implementation phases or when context is running low.

## When to Use

- Context window is getting full (you notice summarization happening)
- Completing a major implementation phase
- Before switching to a different area of work
- User explicitly requests a handover

## Workflow

### Step 1: Gather Context

1. **Get current branch name:**
   ```bash
   git branch --show-current
   ```

2. **Find the master plan** - Search for recent plan files:
   ```bash
   # Look in docs/plans/, docs/, and root for .md files with "plan", "prd", "spec" in name
   ```

3. **Get recent commits on this branch:**
   ```bash
   git log --oneline -10
   ```

4. **Check modified files:**
   ```bash
   git status
   git diff --name-only main...HEAD
   ```

### Step 2: Create Handover Document

**Location:** `docs/handover/handover-{branch-name}.md`

**Template:**

```markdown
# Handover: {Branch Name}

**Date:** {YYYY-MM-DD}
**Branch:** `{branch-name}`
**Session:** Ending due to {context limit / phase complete / user request}

---

## Master Plan Reference

> **Plan:** [Link to plan file](../plans/{plan-file}.md)
>
> **Current Phase:** {Phase X - Name}

---

## What Was Completed

### Summary
{2-3 sentence summary of what was accomplished}

### Files Created/Modified
| File | Change Type | Purpose |
|------|-------------|---------|
| `path/to/file.ts` | Created | Description |
| `path/to/other.ts` | Modified | Description |

### Key Commits
- `{hash}` - {message}
- `{hash}` - {message}

---

## What's Next

### Immediate Next Steps
1. [ ] {First actionable task}
2. [ ] {Second actionable task}
3. [ ] {Third actionable task}

### Remaining in Current Phase
- [ ] {Remaining item 1}
- [ ] {Remaining item 2}

---

## Context for New Session

### Key Decisions Made
- **{Decision 1}:** {Rationale}
- **{Decision 2}:** {Rationale}

### Gotchas / Watch Out For
- {Warning or non-obvious thing 1}
- {Warning or non-obvious thing 2}

### Recommended Agents
| Task | Agent | Why |
|------|-------|-----|
| {Task type} | {agent-name} | {Brief reason} |

---

## How to Continue

1. Read this handover document
2. Review the master plan: `{link}`
3. Check current branch: `git switch {branch-name}`
4. Run `git status` to see current state
5. Start with the first item in "Immediate Next Steps"

---

*Generated by /handover skill*
```

### Step 3: Ensure Directory Exists

Create `docs/handover/` if it doesn't exist.

### Step 4: Save and Confirm

1. Write the handover document
2. Show the user a summary of what was captured
3. Suggest: "New session can start with: 'Continue from docs/handover/handover-{branch}.md'"

## Output

After running this skill, the user should have:
- A handover document at `docs/handover/handover-{branch-name}.md`
- Clear next steps for a new session
- Link to the relevant master plan

4. Reports: "Handover created. New session can continue from docs/handover/..."
